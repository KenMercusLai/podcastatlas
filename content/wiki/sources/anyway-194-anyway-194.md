# №194: 赛博冲浪太快，我想回 MacRabbit 的兔子洞里坐一会

## Summary
This [[AnywayFM|Anyway.FM 设计杂谈]] episode uses [[MacRabbit]], [[CSSEdit|CSS Edit]], [[EspressoCodeEditor|Espresso]], and [[Slicy]] to connect early Mac independent-app craft with the current [[VibeCoding]] and [[CodingDemocratization]] moment. The hosts argue that [[Codex]], [[Cursor]], and similar AI coding agents sharply lower the cost of turning design intent into working personal tools, while the move from a usable 0.5 prototype to a reliable 1.0 public product still depends on engineering detail, testing, compatibility, and user trust. The episode adds [[DesignerAICodingWorkflow]], [[IndependentMacAppCraft]], [[MarkedownApp]], and [[MomoTimeApp]] while extending [[AICodingVerification]], [[AIAssistedLightCoding]], and [[OnePersonCompany]].

## Key Claims
- MacRabbit is presented as a small, low-profile independent Mac studio whose CSS Edit, Espresso, and Slicy showed that one person or a tiny team could make tools with unusually strong functional and emotional finish.
- Espresso's appeal is not only code-editor capability; the hosts remember its visual language, naming details such as Sugar skins, bundled typography, FTP/browser-preview workflow, and ability to make web programming feel inviting.
- Slicy is treated as a design-workflow breakthrough because Photoshop layer naming and PSD drag-and-drop could automate asset export without forcing designers into a heavy plugin or separate process.
- The episode frames current AI coding agents as a new route for designers to build: sketches, Figma files, screenshots, photos, MCP context, and natural language can become implementation instructions.
- The hosts separate self-use tools from public products: AI makes 0-to-0.5 or 0-to-0.9 work fast, but compatibility, bugs, privacy, support, and user-facing polish make the last mile difficult.
- Human-in-the-loop preference remains central: one host wants AI help while preserving direct participation in code and detail-level control, rather than treating software creation as fully delegated.

## Key Quotes
> "漂亮到让人想去编程" - the hosts' description of Espresso's emotional pull.

> "从 0 到 0.5 非常快" - the episode's shorthand for AI coding's prototype advantage.

> "Human in the loop" - the preferred boundary for keeping human craft inside AI-assisted building.
