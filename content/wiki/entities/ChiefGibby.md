# Chief Gibby

Chief Gibby appears in [[the-skyscrapers-that-nimbys-and-zoning-couldnt-stop]] as a former [[SquamishNation|Squamish]] leader describing both the forced 1913 removal from [[SinakVillageSite|Sinak]] and the later return of Squamish presence through high-rise housing. The source uses his memory and development goals to link dispossession, land recovery, and revenue generation.

His first development frame was pragmatic: build a signature project that would function like a recurring-income asset for the nation. By the end of the episode, his "we're back" framing turns that same asset into [[IndigenousDevelopmentVisibility]], because the towers mark a Squamish return to land from which residents had been removed.
