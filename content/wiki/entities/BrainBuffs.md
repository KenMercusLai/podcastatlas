# Brain Buffs

Brain Buffs is [[SandyDininger]]'s adaptive learning platform in [[advice-line-strategy-sessions-4962a0d6-36bc-4797-8002-3bd8b748a89a]]. The source describes it as combining standardized-test practice with real-time misconception diagnosis, giving students adaptive practice while giving teachers class-level recommendations and districts curriculum-level gap data.

The episode frames Brain Buffs' core value as [[EdtechDataValue]] rather than generic test-prep content. [[GuyRaz]] contrasts it with free SAT-prep resources and summarizes the value proposition as a data set that helps schools adjust what and how they teach; [[ShaziVisram]] adds that teacher and district versions should be different enough that low teacher access does not cheapen district pricing.
