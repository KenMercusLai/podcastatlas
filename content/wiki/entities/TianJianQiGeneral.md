# 田间 / Tian Jian (Qi General)

田间 / Tian Jian (Qi General) enters the wiki through [[zizhi-tongjian-qinji-130-3-weihe-li-mutong-wei-chuwang-limian-dayou-wenzhang-lmcuvrxer-cou6gmlppqwhb3n4vz|Qinji 130-3]] as the general appointed after Qi officials install [[TianJia|田假]] as king. He is part of the emergency Qi restoration arrangement after [[TianDanQinRebel|田儋]] dies fighting [[ZhangHanQin|章邯]].

When [[TianRong|田荣]] returns and drives Tian Jia from [[QiState|齐国]], Tian Jian remains in [[ZhaoState|赵国]] with [[TianJiao|田角]]. Tian Rong later demands that Zhao kill both men before Qi will join [[XiangLiang|项梁]] against Zhang Han.

This page uses the semantic suffix "Qi General" because 田间 shares a common pinyin route with the different late-Warring-States figure [[QiWangJian|齐王建 / 田建]]. The two should not be merged.
