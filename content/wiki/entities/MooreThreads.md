# Moore Threads / 摩尔线程

Moore Threads / 摩尔线程 is named in [[guochan-ai-suanli-neng-ping-chaojiedian-wandao-chaoche-ma-waic-shendu-guancha-s10e23-a6c6ab3e-72b2-470b-aefd-04b19679d37f]] as one of the Chinese AI-chip vendors with its own [[ScaleUpAIInterconnect|Scale Up]] approach. The source does not benchmark Moore Threads directly; it uses the company to illustrate [[ProprietaryAIInterconnectFragmentation]] inside the domestic supernode market.

The page should be read as a source-scoped marker. Moore Threads matters here because cloud customers and large model teams may not want to learn too many separate software ecosystems, so vendors need strong proof beyond launch announcements.

[[xiangjie-kimi-k3-qiangdao-chongji-anthropic-guzhi-de-moxing-shenmeyang-1-177-1]] adds a more concrete adaptation signal. [[ZhaoChenyang]] says Moore Threads quickly supported [[KimiK3|Kimi K3]] through a MUSA/SGLang-style ecosystem and uses the example to argue that [[KernelDevelopmentAgents]] can help alternative accelerator vendors adapt faster, though not necessarily overturn [[Nvidia]]'s lead.
