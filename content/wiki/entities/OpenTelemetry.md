# OpenTelemetry

OpenTelemetry is the telemetry standard and learning resource named by [[EdFerron]] in [[ep-14-what-is-observability]]. The source presents it as becoming a standard way to create and ingest data that can later be queried, modeled, and used for alerting in [[Observability]] systems.

The episode uses OpenTelemetry as a bridge between raw application instrumentation and business-facing observability. Its wiki role is not to document the specification, but to mark the practical standard layer behind metrics, events, traces, logs, spans, and [[RealTimeOperationalAnalytics]].
