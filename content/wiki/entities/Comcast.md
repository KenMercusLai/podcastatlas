# Comcast

Comcast appears in [[tech-20260731-0731-mp-tech-pod-128-tech-20260731-0731-mp-tech-pod-128]] as [[NBCUniversal]]'s parent company. [[AnitaRamaswamy]] says Comcast had announced a plan to spin off NBC a few weeks before the episode, and she reads the [[YouTube]] deal as potentially helping set up NBCUniversal or NBC for more independent success.

The source uses Comcast mainly as corporate context for [[StreamingPlatformBundling]]. It is not a broad analysis of Comcast's cable or broadband strategy; the relevant point is that media assets may need stronger platform distribution when linear television and standalone streaming apps face attention pressure.
