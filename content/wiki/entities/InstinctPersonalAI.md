# Instinct Personal AI

## Overview
[[InstinctPersonalAI]] is described in the episode as a private-beta personal AI service. The source presents it as part of a shift from general chatbots toward user-specific agents that need access to personal data, workflows, and sometimes human support to execute tasks reliably.

## Current Profile
The service is significant because it makes the tradeoff around personal AI explicit: the more useful the assistant becomes, the more it may need permissioned access to messages, calendars, accounts, preferences, and task history. The hosts discuss whether a human-in-the-loop layer might be necessary for completion of real-world tasks, which places Instinct near the boundary between software agent, concierge service, and delegated workflow operator. The wiki currently has no corroborating source beyond the episode.

## Key Characteristics
- It is presented as private beta rather than a mature public product.
- Its usefulness depends on broad personal context and user-data access.
- It raises trust and privacy questions because personal AI products need both memory and operational permissions.
- It may rely on human-in-the-loop completion for tasks that current AI agents cannot reliably finish unaided.
