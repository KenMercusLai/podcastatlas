# Kagi

Kagi appears in [[tech-20260123-0123-mp-tech-pod-128-tech-20260123-0123-mp-tech-pod-128]] as a small search engine asking users to report [[AISlop|AI slop]] so it can build a database for detection work. The source uses Kagi as a contrast to [[YouTube]]: large platforms can rely on scale and raters, while smaller search services may need explicit user reports to gather examples of low-quality synthetic content.

The page mainly anchors a detection-data point. Kagi is not analyzed as a full search-business case here; it is used to show that [[AISlopDetection]] may depend on labeled examples, user feedback, and human judgment about what feels like slop.
