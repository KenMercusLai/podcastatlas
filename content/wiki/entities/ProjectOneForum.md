# Project One论坛

Project One论坛 is named in [[ep242-duli-youxi-shi-yitiao-gaoqian-hao-saidao-ma-lrqbzrceumbuggzuero5qb4jv3zu]] as the later form of the [[SixtySixRPG|66RPG]] community. In the episode, it represents the forum-era infrastructure for hobbyist game makers before small-team publishing on [[Steam]] became a more visible commercial path.

The community is useful to the wiki as an example of [[MakerCommunity|maker community]] before AI-era coding tools. The key mechanism is not only software access, but shared examples, project files, feedback, and the confidence that a simple game could be made by an ordinary participant.
