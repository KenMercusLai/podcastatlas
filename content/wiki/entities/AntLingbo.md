# 蚂蚁灵波 / Ant Lingbo

## Overview
Ant Lingbo / 蚂蚁灵波 is the [[AntGroup|蚂蚁集团]]-incubated embodied-intelligence company represented by [[ShenYujun]] in the wiki. Its route is robot-brain-first: build [[EmbodiedNativeFoundationModels]] that can run across bodies while learning from physical sensors, real-world execution, and cross-embodiment data.

## Current Profile
The new four-company debate strengthens Lingbo's real-world-data and continuous-input stance. Shen does not reject simulation, but argues that true robot deployment must handle sensor noise, tactile-signal variation, physical imperfection, and real-time strategy changes while the robot is acting.

## Key Characteristics
- Builds the robot brain before committing to a single universal robot body.
- Treats embodied-native models as distinct from simply attaching a language or video model to a robot.
- Prioritizes real sensors, spatial perception, video time, action, and execution feedback.
- Values simulation for some task-specific and evaluation uses while emphasizing real physical imperfections.
- Frames embodied models as possible tools for higher-level models and as future data sources for broader AI systems.

## Qualifications
The wiki has not yet seen independent benchmarks showing how Lingbo's robot brain compares with other VLA, world-model, or full-stack manipulation routes. The company's emphasis on real data is also in productive tension with simulation-heavy routes such as Sudu's.
