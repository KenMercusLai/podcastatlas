# Yondr

## Overview
Yondr is the phone-pouch system used in the episode's concert segment to create device-restricted live events.

## Current Profile
In [[brazil-rut-lula-v-bolsonaro-again-6abb8653ed4e198024b38eb5]], attendees keep possession of their phones but seal them in magnetically locked pouches during performances. The product converts an artist's attention norm into physical [[ScreenTimeFriction]] rather than relying on a voluntary request alone.

## Key Characteristics
- Physical device-control system used at live events.
- Keeps the phone with the attendee while restricting immediate access.
- Turns a social rule into venue-level enforcement.
- Supports an attention and anti-recording goal but introduces unexamined access tradeoffs.

## Evidence
- Use case: [[brazil-rut-lula-v-bolsonaro-again-6abb8653ed4e198024b38eb5]] says [[PhoebeBridgers]] requires Yondr pouches on tour.
- Mechanism: [[brazil-rut-lula-v-bolsonaro-again-6abb8653ed4e198024b38eb5]] describes the pouches as magnetically locked.
- Intended effect: [[brazil-rut-lula-v-bolsonaro-again-6abb8653ed4e198024b38eb5]] links device restriction to more attentive faces, intimacy, and event ephemerality.

## Qualifications
The source does not evaluate the company's operations, pouch reliability, accessibility procedures, emergency release, privacy, cost, or attendee response. This page therefore records only the described concert use case.
