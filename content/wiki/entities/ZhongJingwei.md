# 钟静伟 / Zhong Jingwei

## Current Profile

His contribution is the product-harness critique of [[DoubaoWork|Doubao Work]]. He treats the product as broad in capability coverage but uneven in execution, focusing on skills, context use, file handling, tool parallelism, multi-agent delegation, and missing harness optimizations rather than only user-facing UI.

He also contributes the longer-term office-entry view: work may become more project-centered, with humans coordinating context, visual output, and multiple agent loops while synchronous human-to-human communication becomes less central.

## Key Characteristics

- Evaluates Doubao Work through hands-on task tests and harness behavior.
- Highlights hidden context and skill-selection risks when many built-in skills are loaded or truncated.
- Critiques multi-agent architecture when an extra planning agent adds cost, latency, and information loss.
- Frames future work around project-centered context and multiple agent loops.
