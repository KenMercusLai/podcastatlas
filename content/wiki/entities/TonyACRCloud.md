# Tony / ACR Cloud

## Overview
Tony is the [[ACRCloud|ACR Cloud]] co-founder interviewed in [[shuo-de-hao-ting-ep56-dang-ai-xiege-buzai-shi-jishu-qiguan-women-haiyao-taolun-shenme-6c1b89cdfc157b23f26fac509d36d7fc]] about audio fingerprinting, AI-music detection, and platform payout questions.

## Current Profile
Tony supplies the detection and downstream-platform perspective. He describes ACR Cloud as an enterprise API service that recognizes audio and can detect copyright issues or model-like AI-music patterns. On settlement, he argues from user value and DSP outcomes: if generated music delivers the same value to a platform and listener, it could warrant the same payout, while training-data compensation remains a separate problem.

## Key Characteristics
- He represents the audio-recognition and fingerprinting side of the episode.
- He treats AI-music identification as a pattern-recognition task rather than a need to define AI music philosophically.
- He expects AI assistance to appear widely in future music workflows, including local samples or partial elements.
- He argues that equal downstream value can justify equal platform settlement for AI-generated tracks.
