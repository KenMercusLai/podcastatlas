# Seraphic Security

Seraphic Security appears in [[all-in-with-chamath-jason-sacks-friedberg-the-future-of-everything-what-ceos-of-circle-crowdstrike-more-see-coming-in-2026-39870920]] as the browser-layer security company acquired by [[CrowdStrike]]. [[GeorgeKurtz|George Kurtz]] describes the browser as a major front door for work and for adversaries, making protection beneath existing browsers part of enterprise security.

The source connects Seraphic to the shift from endpoint-only defense toward [[AIDetectionAndResponse|AI detection and response]]. If AI agents, employees, SaaS apps, and web sessions all meet in the browser, browser security becomes part of [[AgentIdentityAndAuthentication]] and session-token protection rather than only web filtering.
