# The Relevance of Algorithms

The Relevance of Algorithms is the [[TarletonGillespie]] paper that anchors [[159-suanfa-de-liufu-miankong-ta-shi-ruhe-cong-chuli-shuju-biancheng-dingyi-women-shi-shui-de-lh5ng5mbvkworfxlq9l-coscepc7]]. The episode treats it as an algorithm-sociology foundation because it asks how algorithms become public knowledge infrastructure rather than only how they compute an answer.

The paper's six dimensions become the source's "six faces": [[AlgorithmicInclusionPatterns]], [[AlgorithmicPredictionLoop]], [[AlgorithmicRelevanceAssessment]], [[AlgorithmicObjectivityPromise]], [[AlgorithmicEntanglement]], and [[CalculatedPublics]]. In the episode's reading, these faces trace a chain from data intake to social identity: what gets counted, how a user is predicted, which result is ranked, how the result is legitimated, how users adapt, and how publics are computed.

## Key Claims
- The source uses the paper to define [[PublicRelevanceAlgorithms]] as algorithms that decide and certify what counts as publicly relevant knowledge.
- Its strongest contribution to the wiki is a vocabulary for seeing recommendation, search, and platform feeds as media power.
- The source pairs the paper with [[Filterworld]] so the abstract framework has everyday examples from travel, music, creators, and social feeds.
