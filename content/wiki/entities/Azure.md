# Azure

Azure is [[Microsoft]]'s cloud platform and, in [[all-in-with-chamath-jason-sacks-friedberg-microsoft-ceo-satya-nadella-on-ais-business-revolution-what-happens-to-saas-openai-and-microsoft-live-from-davos-39818140]], [[SatyaNadella|Satya Nadella]] describes it as a kind of AI "token factory." The point is not only capacity ownership; Nadella emphasizes heterogeneous infrastructure, utilization, total cost of ownership, and the ability to serve many model and agent workloads efficiently.

In the source, Azure is also the infrastructure base under [[MicrosoftFoundry|Microsoft Foundry]], [[AIModelOrchestration]], and enterprise agents. That makes Azure a bridge between [[OpenAI]] partnership strategy, [[AIInferenceCostStructure]], [[TokenFactoryAIInfrastructure]], and [[AIEconomicDiffusion]].
