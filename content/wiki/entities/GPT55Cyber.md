# GPT 5.5 Cyber

## Overview
GPT 5.5 Cyber appears in the episode as an [[OpenAI]] cyber-capable model release discussed by [[DavidSacks|David Sacks]] in comparison with Anthropic's Mythos.

## Current Profile
The source presents GPT 5.5 Cyber as a specialist cyber model whose importance is not that it invents new vulnerabilities, but that it can discover existing vulnerabilities and complete multi-step cyber simulations. In the hosts' framing, this capability can help defenders patch systems first, while the same class of capability also raises attacker-use and access-control questions.

## Key Characteristics
- OpenAI-linked cyber model discussed as a specialist release rather than a general chatbot.
- Framed as capable of finding existing software vulnerabilities.
- Used as evidence that frontier cyber models can complete more complex attack simulations.
- Treated as dual-use: useful to defenders and potentially useful to attackers.
- Requires supervision, access control, and patching capacity to produce net defensive value.
