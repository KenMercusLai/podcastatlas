# Photon Agent Communication

## Overview
Photon is presented as a communication layer that lets long-running agents reach users through familiar messaging and voice channels.

## Current Profile
The source positions Photon between background execution and meaningful human oversight. An agent can use iMessage, WhatsApp, phone, Slack, Telegram, and planned email to ask about ambiguity, report progress, deliver summaries, or escalate an urgent decision rather than silently guessing or requiring the user to watch a dedicated dashboard.

Its durable value proposition is not another chat front end. It is a control path for [[LongHorizonAgentReliability]] and [[HumanInLoopAgentGovernance]] when tasks outlast one session. The source does not establish Photon's architecture, customers, security model, delivery reliability, pricing, or adoption.

## Key Characteristics
- Connects background agents to users through existing communication habits.
- Supports status updates, questions, urgent confirmation, and final handoff.
- Treats text and phone contact as operational escalation channels.
- Sits alongside memory, state, permissions, compliance, and recovery rather than replacing them.
- Depends on correct identity, routing, consent, and urgency handling across third-party platforms.
