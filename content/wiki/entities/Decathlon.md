# Decathlon / 迪卡侬

## Overview
Decathlon is the sporting-goods retailer named in a source-reported U.S. trademark dispute over the K-shaped mark used by its professional running brand Keep Run.

## Current Profile
The available source covers Decathlon only through [[NewBalance|New Balance]]'s allegation that Keep Run's mark is close enough to New Balance's N mark to imply an affiliation. It says Decathlon declined to stop using the mark after discussions, but it does not provide Decathlon's legal response or a court ruling.

## Key Characteristics
- Operates the Keep Run professional running brand discussed in the dispute.
- Uses a K-shaped mark described as inspired by a track starting block.
- Faces a source-reported consumer-confusion claim from New Balance.
