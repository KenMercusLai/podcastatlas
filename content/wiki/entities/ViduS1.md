# Vidu S1

Vidu S1 is the [[ShengshuTechnology]] product discussed by [[ZhangJintao]] in [[kuai-yidian-zai-kuai-yidian-kuai-dao-shijie-neng-shishi-shengcheng-he-shengshu-keji-zhang-jintao-liao-vidu-s1-tuili-jiasu-shishi-jiaohu-shipin-lsb53bqrjojiadnlq2qe4sta-b13]]. The source presents it as a [[RealTimeInteractiveVideoGeneration]] product: a user can upload a character image, choose or clone a voice, and speak with the generated character while facial expression, motion, and body language respond live.

The source-scoped technical claim is that S1 supports long streaming generation at 540P and roughly 25 to 42 FPS, with the team prioritizing real-time response before maximum image quality. Zhang says S1 can also use video understanding, including camera, game-screen, desktop, or coding-screen input, so a virtual character can react to what the user is seeing.
