# AFK

## Overview
AFK is [[HeJiachen|何嘉琛]]'s enterprise-Agent company, presented in the source as building a continuously learning agentic system for organization-wide work.

## Current Profile
AFK's claimed product form is one highly concurrent enterprise agent that can operate across channels and tools while maintaining separate user memories and runtimes. Its proposed advantage is not merely task execution but shared learning: reuse prior context, identify effective employee practices, distill recurring trajectories, and connect AI cost to business outcomes. These are founder-reported architecture and strategy claims rather than independently measured product results.

## Key Characteristics
- Enterprise-wide shared Agent rather than isolated personal assistants.
- Individualized memory and runtime separation within a common organizational system.
- Cross-environment operation through chat, collaboration tools, phone, browser, CLI, MCP, and operating systems.
- Continuous learning from work traces, tool calls, results, and preferences.
- Small-model strategy for routing repeated tasks and serving enterprise-specific work.

## Evidence
- **Product architecture:** [[ljfjtmoafzywi-agbwi1wzpghcax-ljfjtmoafzywi-agbwi1wzpghcax]] describes AFK as always online, proactive, highly concurrent, and accessible beyond one interface.
- **Learning strategy:** [[ljfjtmoafzywi-agbwi1wzpghcax-ljfjtmoafzywi-agbwi1wzpghcax]] says company-wide experience can be shared while retaining person-specific memory and execution context.
- **Model strategy:** [[ljfjtmoafzywi-agbwi1wzpghcax-ljfjtmoafzywi-agbwi1wzpghcax]] describes a task-routing model and a roughly 20B–40B internal work model.

## Qualifications
The source provides no audited customer metrics, security design, benchmark results, model-training details, cost curves, or deployment case studies. Product scope, model sizes, and benefits are first-party descriptions.
