# Kernel

Kernel is the brain-measurement company named in [[all-in-with-chamath-jason-sacks-friedberg-bryan-johnson-i-just-took-the-most-powerful-dose-of-dmt-in-the-world-heres-what-it-was-like-40626165]]. [[BryanJohnson|Bryan Johnson]] says prior psychedelic and ketamine work used Kernel-style measurement before, during, and after intervention, and says the 5-MeO-DMT experiment included structural MRI, functional MRI, Kernel optical-interface data, and real-time EEG.

The page should stay distinct from [[KernelDevelopmentAgents]], which is an AI-infrastructure concept about low-level code optimization. Here Kernel is relevant to [[SelfExperimentation]] because it shows Johnson trying to surround subjective experience with instrumentation, while the source still warns that measurement collection is not the same as completed evidence.
