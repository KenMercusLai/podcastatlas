# 刘晓微 / Liu Xiaowei

## Overview
刘晓微 / Liu Xiaowei is the [[Kuaishou]] marketing-science and business-development guest interviewed by [[LiuFei|刘飞]] in the [[SanWuHuan|三五环]] episode on content seeding and brand-performance integration.

## Current Profile
The current wiki profile is source-scoped to one episode. Liu Xiaowei presents content seeding as a measurable but not perfectly provable marketing path: platforms should reconstruct how users move from content to search, livestreams, store visits, comparison, purchase, repurchase, and sometimes off-platform transactions.

Her practitioner stance is that brands and platforms should stop treating users as people to be educated into a fixed funnel. Instead, they should observe where real user paths break, then build bridges between brand advertising, creator content, ecommerce traffic, search, and live-room explanation.

## Key Characteristics

- Defines seeding broadly enough to include delayed and cross-channel buying, not only instant purchase.
- Uses Kuaishou's R3 seeded-audience frame to distinguish deeper mental availability from shallow exposure.
- Treats brand-performance integration as path construction between brand and transaction traffic.
- Uses AI as a tool for reconstructing complex user behavior, while keeping final interpretation tied to user-path evidence.
