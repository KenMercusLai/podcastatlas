# Kai (Airwallex)

Kai is the [[Airwallex]] AI assistant described by [[WuKai]] in [[11-nian-110-yi-meijin-ranhou-ne-duihua-airwallex-wu-kai-ai-shidai-xiayizhan-1000-yi-lr4tvdrq25by7fugoqkqojw6vwdk]]. The source says Kai is embedded in the Airwallex web application and uses natural-language interaction to help with financial policies, liquidity, expenses, workflow creation, and error analysis.

Kai is the human-facing side of the source's [[IntelligentFinance]] thesis. Unlike a generic [[FinancialAIAgents|financial AI agent]] that mainly explains information, Kai is tied to accounts, payments, policies, and workflow actions inside Airwallex's transaction layer.

## Key Points
- Presented as an embedded natural-language assistant rather than a separate standalone app.
- Can help analyze policies, optimize working capital, control expenses, build workflows, and inspect errors, according to the source.
- The source says users can create payments through Kai and upload finance, reimbursement, or approval policies for workflow generation.
- Wu describes early retention as promising, while keeping those claims source-scoped.
