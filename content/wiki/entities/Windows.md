# Windows

Windows is [[Microsoft]]'s PC operating system and appears in [[all-in-with-chamath-jason-sacks-friedberg-microsoft-ceo-satya-nadella-on-ais-business-revolution-what-happens-to-saas-openai-and-microsoft-live-from-davos-39818140]] through [[SatyaNadella|Satya Nadella]]'s local AI strategy. Nadella says Microsoft wants the PC to be a good place for local models, prompt processing, and hybrid local-cloud AI work.

The source adds Windows to the wiki's agent and infrastructure branches rather than only the older PC or mobile-platform story. If local models such as [[PhiSilica|Phi Silica]] and workstation-class GPUs become more useful, Windows can become a runtime surface for [[LocalAgentExecution]], [[ComputerUseAgent]] workflows, and [[LocalAIWorkstation]] patterns.
