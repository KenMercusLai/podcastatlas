# Charles Fan

## Overview
Charles Fan is presented in [[lsh8sdro6i9mkt5nug4zkibv95tn]] as CEO of [[MemVerge]] and a long-time practitioner in AI infrastructure, memory management, and storage.

## Current Profile
Fan argues that AI differentiation is shifting from model capability toward private-data and memory management. He frames memory as the organization of private data for AI use, not merely storage, and advocates a [[MemoryCenteredAI|memory-centered]] stack that can select among local and remote models while leaving control of personal or enterprise data with its owner.

## Key Characteristics
- Connects earlier memory-management and storage work to AI memory infrastructure.
- Advocates shared memory for agents through [[MemoryMachine]].
- Advocates local-and-hybrid personal AI through [[MemoryBox]].
- Treats data sovereignty, memory correctness, and ownership as product-level concerns.
