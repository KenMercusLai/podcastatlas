# Ray Dalio

Ray Dalio appears in [[vol-110-touzi-jiushi-dui-shijieguan-de-toupiao-maichu-zichan-peizhi-di-yi-bu-wanjiepian-lk5jkgnzvzerymcixylsdqdtn7f8]] as one of the episode's examples of [[InvestmentWorldviewFit]]. The host treats Dalio's all-weather style as an investing method that makes sense for a particular way of seeing cycles, risk, and uncertainty rather than as a universal recipe for every household investor.

For the wiki, Dalio links this episode's personal-worldview argument back to the existing [[BridgewaterAssociates]] and [[RiskParity]] branch. The point is not biographical detail; it is that a portfolio method can embody a worldview about macro balance, diversification, and survivability.
