# Nvidia GB200 NVL72

Nvidia GB200 NVL72 is the rack-scale [[NvidiaBlackwellPlatform|Blackwell]] system used as the main incumbent comparison in [[guochan-ai-suanli-neng-ping-chaojiedian-wandao-chaoche-ma-waic-shendu-guancha-s10e23-a6c6ab3e-72b2-470b-aefd-04b19679d37f]]. The source describes it as 72 B200 accelerators connected in one cabinet-scale domain, with NVSwitch trays and high rack power.

The existing [[e230-1-wan-yi-shouru-yuqi-beihou-yingweida-de-dianfeng-yu-ruanlei-d97446f1-d6e3-4894-89d1-dca0a362b10b]] source treats NVL72 as part of Nvidia's platform shift from chip sales toward full AI infrastructure. The WAIC source adds the China comparison: [[HuaweiCM384]] can exceed NVL72 in cited aggregate compute by using more chips, but that does not erase Nvidia's efficiency, [[CUDA]], reference architecture, and ecosystem advantages.
