# Qwen Tablet / 千问平板

## Overview
Qwen Tablet is the source-reported [[Alibaba]] device experiment positioned as an "agent-native computer" built around [[Qwen]].

## Current Profile
The product represents a system-level AI route: the model is meant to coordinate tasks from the operating layer rather than remain one standalone app. The source's main qualification is ecosystem compatibility. A system agent has limited practical value if it can call only Alibaba-owned tools and cannot work with the software, files, and services users already depend on.

## Key Characteristics
- Tablet-computer experiment centered on Qwen.
- Positioned as an agent-native rather than app-first device.
- Intended to move AI into the system layer.
- Depends on cross-application compatibility and useful action authority.

## Evidence
- Product positioning: [[yuebing-shichang-chixu-jiangwen-doubao-suojian-duihua-yewu-tuandui-1017879242]] describes Qwen Tablet as an "agent-native computer."
- Ecosystem boundary: [[yuebing-shichang-chixu-jiangwen-doubao-suojian-duihua-yewu-tuandui-1017879242]] questions its value if it cannot interoperate with existing user software.

## Qualifications
The source does not provide shipping status, specifications, operating-system architecture, app compatibility, pricing, or independent testing. The product name and positioning remain source-reported.
