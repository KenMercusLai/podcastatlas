# Memory Machine

## Overview
Memory Machine is [[MemVerge]]'s open developer-facing memory layer, as described by [[CharlesFan]] in [[lsh8sdro6i9mkt5nug4zkibv95tn]].

## Current Profile
The source positions Memory Machine as infrastructure that can sit inside one agent or provide shared memory to several agents and applications. It is the lower layer beneath [[MemoryBox]] and part of the broader claim that durable context should be managed independently from whichever model performs a task.

## Key Characteristics
- Designed as an embeddable or shared memory layer for agents and AI applications.
- Released as an open-source developer project in the source's account.
- Intended to expose memory capabilities to applications rather than function only as a user-facing assistant.
- Serves as the technical base for [[MemoryBox]] and possible hardware integrations.
