# Trigg

## Overview

Trigg is an early-stage agent-facing marketplace described as a unified access and billing layer for real-time data, professional APIs, and generative-media tools.

## Current Profile

The company positions itself as a neutral tool layer across [[ClaudeCode]], [[Codex]], and custom agents rather than another full [[AgentHarness]]. It emerged from the data and API routing infrastructure built for [[Coolit]] and uses one key, metered billing, cross-platform access, and agent feedback to reduce integration and selection friction.

## Key Characteristics

- Aggregates data providers, APIs, and media-generation models for agent use.
- Charges by usage rather than a fixed monthly subscription in the source account.
- Aims to preserve tool access when users switch agent harnesses.
- Uses anonymous agent feedback to compare effectiveness, accuracy, and value.
- Focuses on growth, SEO, AEO, social media, lead generation, image, and video workflows.
