# 商汤 / Shang Tang

商汤 / Shang Tang appears in [[zizhi-tongjian-zhouji-49-mengzi-yue-wo-jiao-ni-zhiguo-ni-que-ba-wo-dang-huaping-lhy14pbf9thcfdiaulcmf8dwcef8]] as [[Mengzi|孟子 / Mencius]]'s positive conquest example. Mencius uses Tang to argue that punitive war can be legitimate when it removes a cruel ruler and relieves suffering people.

The episode uses the example to sharpen the contrast with [[QiState|齐国]] in [[YanState|燕国]]. If an army claims to rescue people but then kills relatives, imprisons children, destroys institutions, and seizes treasure, it no longer resembles Tang's moralized campaign. Shang Tang therefore supports the episode's link between [[MencianPeopleBasedLegitimacy|孟子的民本合法性]] and post-conquest conduct.
