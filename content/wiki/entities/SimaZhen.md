# 司马贞 / Sima Zhen

司马贞 / Sima Zhen enters the wiki through [[zizhi-tongjian-qinji-114-3-jingke-ciqin-weihe-jiujiu-bu-xingdong-zai-deng-shui-liihe-kgwigu3bggxmyofgvotged]] as the Tang historian cited for the note that [[XuFuren|徐夫人]] is a male name in the [[JingKe|荆轲]] dagger story. The episode uses the note to prevent a mistaken gender reading and to connect Xu Furen with an especially sharp dagger.

In this source, Sima Zhen's role is not an independent argument about [[Shiji|《史记》]]; it is a clarifying commentator note inside the assassination-preparation narrative.
