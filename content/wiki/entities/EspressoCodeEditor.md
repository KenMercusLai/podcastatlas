# Espresso

## Overview
Espresso is the MacRabbit web code editor discussed in [[anyway-194-anyway-194]] as a polished independent Mac app that made programming feel visually and emotionally inviting.

## Current Profile
The episode presents Espresso as MacRabbit's most substantial product: a web-development code editor with FTP upload, browser preview, inherited CSS Edit strengths, and a long period of personal use for one host. Its durable wiki role is as a craft example: the hosts remember its beauty, Sugar skin naming, typography, and integrated preview workflow as evidence that software tools can create desire to work, not only perform tasks.

## Key Characteristics
- It is represented as a full-featured Mac code editor for web development.
- Its appeal is tied to visual finish, naming, typography, and emotional affordance.
- It integrated web-development conveniences such as FTP upload and browser preview in the host's account.
- It serves as the episode's clearest contrast with more utilitarian modern coding environments.

## Evidence
- Function - [[anyway-194-anyway-194]] describes Espresso as a full-featured code editor mainly aimed at web development.
- Workflow - [[anyway-194-anyway-194]] says it included FTP upload, browser preview, and CSS Edit lineage.
- Emotional design - [[anyway-194-anyway-194]] records the hosts' claim that Espresso was beautiful enough to make someone want to program.
- Naming and typography - [[anyway-194-anyway-194]] highlights Sugar skins and the host's affection for Espresso's bundled monospace font.
