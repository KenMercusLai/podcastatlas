# CSS Edit

## Overview
CSS Edit is a MacRabbit CSS editing application discussed in [[anyway-194-anyway-194]] as an early influential Mac web-design tool.

## Current Profile
In this source, CSS Edit functions as the precursor and foundation for [[EspressoCodeEditor|Espresso]]. The hosts remember it as one of MacRabbit's compact but consequential products, important both for its Apple Design Award recognition and for helping define expectations around polished Mac code tools.

## Key Characteristics
- It is presented as an early MacRabbit product focused on CSS and web-design work.
- It is described as influential beyond its narrow feature scope.
- It is treated as part of the lineage that led to Espresso.

## Evidence
- Product role - [[anyway-194-anyway-194]] names CSS Edit as one of MacRabbit's main products.
- Recognition - [[anyway-194-anyway-194]] says CSS Edit helped MacRabbit win an Apple Design Award.
- Tool lineage - [[anyway-194-anyway-194]] frames CSS Edit as part of Espresso's foundation.
