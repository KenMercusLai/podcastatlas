# Ambi Personal AI

## Overview
Ambi is a personal-agent startup or product presented by founder [[ZihaoAmbiFounder|子皓]] as combining software and hardware to make AI continuously available in daily physical settings.

## Current Profile
Ambi's stated differentiation is not a unique browser or [[ComputerUseAgent|computer-use]] capability. It is the attempt to combine ambient context, a low-friction spoken entry point, user memory, and real-world task execution so the user does not repeatedly open an app and reconstruct what the system has already observed. The source describes a near-term App Store release and a possible invitation requirement, but supplies no independent evidence for architecture, privacy implementation, reliability, adoption, or product-market fit.

## Key Characteristics
- Treats physical-world context and continuous availability as the core product surface.
- Combines hardware and software rather than competing only through a chat or cloud-computer interface.
- Seeks to reduce repeated briefing and action overhead for ordinary life tasks.
- Prefers environmental changes over periodic connector scans as the basis for initiative.
- Frames private raw audio, biometric, or identity data as information the application provider ideally should not receive.
- Treats work and life context as jointly useful for understanding one person.
