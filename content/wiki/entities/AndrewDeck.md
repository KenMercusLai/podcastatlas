# Andrew Deck

Andrew Deck is the [[NiemanLab]] journalist interviewed in [[tech-20260421-0421-mp-tech-pod-128-tech-20260421-0421-mp-tech-pod-128]] about news publishers blocking the [[WaybackMachine|Wayback Machine]]. His reporting supplies the episode's key caveat: publishers are worried about AI companies using the archive as a proxy route, but the source says they did not identify direct evidence that this had already happened through the Wayback Machine.

Deck frames the issue as an AI-era revision of an older publishing tradeoff. Publishers had long tolerated some [[WaybackMachine|Wayback Machine]] access despite paywall-bypass concerns because [[PublicWebArchiving]] served a public good. [[AIProxyScrapingRisk]] changes that balance by making an archive copy look like a possible input into commercial model training.
