# Velvet Revolution / 天鹅绒革命

[[VelvetRevolution|Velvet Revolution / 天鹅绒革命]] appears in [[12-man-dang-milan-kundela-yi-ju-zhengjing-meiyou-549335675]] as the 1989 turning point after which the Czech entomologist in [[SlowKundera|《慢》]] regains academic status, while [[MilanKundera|Milan Kundera]] still does not simply return to [[CzechRepublic|Czech]] belonging.

The source uses the post-1989 contrast to make exile more complicated than a regime-change problem. Political liberalization can restore institutions and reputations, but it does not automatically repair home, privacy, memory, or the public image attached to a writer.
