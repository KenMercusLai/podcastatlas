# 《四库全书》 / Siku Quanshu

## Overview
《四库全书》 / Siku Quanshu appears across two [[BowuzhiPodcast|博物志]] episodes as both the collection behind imperial library pavilions and a later Qing compilation project that reused [[YongleDadian|《永乐大典》]].

## Current Profile
The Hangzhou source treats Siku Quanshu mainly as the institutional background for [[WenlanPavilion|文澜阁]]. The writing-traditions source distinguishes it from *Yongle Dadian*: Siku Quanshu is a collected edition of whole works rather than a classified extraction system, and its compilers used the earlier compilation for textual recovery. Together the sources make it both a distributed preservation project and a reminder that imperial collection involves selection, editing, and access choices.

## Key Characteristics
- Connected to a named set of Qing imperial library pavilions.
- Gives [[WenlanPavilion]] its book-heritage significance in the source.
- Functions as a bridge between ancient-book exhibition discussion and Hangzhou site travel.
- Differs structurally from a classified book by collecting and editing books as books.
- Used surviving *Yongle Dadian* material to recover works no longer available independently.

- Exhibition route - [[246-hangzhou-bowuguan-yiwei-hangzhi-haojiu-mei-kan-guo-zheme-tuijian-de-zhanlan-le-8217911423-973793]] uses the Siku Quanshu branch after the ancient-book exhibition.
