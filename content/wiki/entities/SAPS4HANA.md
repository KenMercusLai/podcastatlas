# SAP S/4HANA

SAP S/4HANA is referenced in [[ai-chongji-qiye-ruanjian-jutou-yu-sap-yuanxin-liao-damoxing-to-b-de-dianfu-yu-bianjie-1-174-1]] as the kind of large enterprise system whose value cannot be reduced to source code. The episode uses SAP S/4-style systems to argue that code generation can lower implementation and customization cost, but the embedded business logic, standard processes, data model, and trust obligations remain difficult to reproduce.
