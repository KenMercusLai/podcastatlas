# Data Ready

## Overview
Data Ready is the AI readiness system described in [[ep-43-the-outsiders-advantage-how-diverse-perspectives-unlock-enterprise-ai-success]]. The source says [[SumayyaShravani]] built it as a four-agent system for auditing AI readiness in data environments before copilot testing.

## Current Profile
The source positions Data Ready as a technical readiness tool that checks semantic layers, documentation, model quality, and governance posture. Its role in the episode is partly diagnostic and partly cautionary: Sumayya says it helped answer whether the data environment was ready, but her later insight was that adoption also requires asking whether people are ready.

That makes Data Ready a bridge between [[AIDataReadiness]] and [[InstitutionalTrustAIAdoption]]. It captures the technical foundation while exposing the missing human and institutional layer needed for [[BusinessLedAITransformation]].

## Key Characteristics
- Uses a four-agent system frame to audit AI readiness in data environments.
- Checks semantic layers, documentation, model quality, and governance posture before copilot testing.
- Supports [[AIDataReadiness]] but does not by itself prove user readiness or adoption.
- Shows why governance and data quality are necessary but insufficient for enterprise AI value.
- Connects technical readiness audits with later behavioral metrics such as [[AIOverwriteRate]] and [[QuietAIAdoptionDeparture]].

## Evidence
- Tool identity: [[ep-43-the-outsiders-advantage-how-diverse-perspectives-unlock-enterprise-ai-success]] identifies Data Ready as a four-agent AI readiness system built by [[SumayyaShravani]].
- Audit scope: [[ep-43-the-outsiders-advantage-how-diverse-perspectives-unlock-enterprise-ai-success]] says it checks semantic layers, documentation, model quality, and governance posture.
- Limitation: [[ep-43-the-outsiders-advantage-how-diverse-perspectives-unlock-enterprise-ai-success]] reports Sumayya's later view that the tool measured data readiness but missed people readiness.

## Qualifications
The source does not provide Data Ready's product status, public availability, codebase, customer evidence, accuracy, or implementation architecture. The wiki should therefore treat Data Ready as a source-described project and adoption example, not as an independently evaluated platform.
