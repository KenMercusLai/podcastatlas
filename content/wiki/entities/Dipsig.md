# Dipsig

Dipsig appears in [[kafeidou-liangci-zaoyu-pingguo-chongji-yundong-shoubiao-jiaming-weihe-hai-neng-zengzhang-1006272684]] as the source-spelled name of an AI model/product line whose V4 Pro version launched on 2026-08-13. The episode says V4 Pro improves agent capability, costs about three times V4 Flash, remains priced below [[KimiK3|Kimi K3]], and ranked second behind Kimi K3 on some open-model benchmarks cited by the source.

The same source says a Dipsig Harness team registered a WeChat public account and describes Harness internally as an agent execution framework for tool scheduling, task-state management, and execution closure. The wiki should treat the name and claims as source-scoped until another source clarifies whether Dipsig is a distinct brand, a transcription variant, or a renamed product.
