# Google Apps Script

Google Apps Script appears in [[ep-17-ais-impact-on-creativity-a-consumers-perspective]] as the JavaScript-like automation environment [[MarkDataScienceWithSam|Mark]] uses around Google Apps spreadsheets. Mark describes himself as not being a computer professional, so [[ChatGPT]] helps him generate code snippets that he can paste, test, and adapt for forms, spreadsheet inputs, and spreadsheet-change workflows.

In the wiki, this is a low-stakes example of [[AIAssistedLightCoding]]. It sits next to broader [[AIAssistedSoftwareDevelopmentRisk]] because generated code can save time, but the user still needs context, testing, and responsibility for the spreadsheet behavior.
