# 戴冠兰 / Dai Guanlan

戴冠兰 / Dai Guanlan is the founder of [[Runta]] in [[moxing-nengli-yijing-goule-yao-juan-jiu-juan-infra-duitan-daiguanlan-runta-chuangshiren-lmjsnpp7d75yhqh7bovj1bv6yhbk]]. The episode positions him as an AI-infrastructure founder translating prior work at [[Cloudflare]] and Kong into a new [[AgentRuntimeExecutionLayer|agent runtime / execution layer]] thesis.

His core argument is that AI agents change the software execution premise. If the lowest execution unit becomes probabilistic, then isolation, rollback, migration, audit, permissions, scheduling, and cost control have to become part of the platform rather than external compliance afterthoughts. He therefore frames [[Runta]] as infrastructure that adds enough deterministic control around [[ProbabilisticSoftware]] for companies to hand agents production work.

Dai also represents a pragmatic AI-engineering stance. He encourages young engineers to use AI tools aggressively, but warns that useful judgment still depends on lower-level architecture, API design, system decomposition, and respect for existing infrastructure. The source uses his [[Cloudflare]] and Kong background to connect agent-infra entrepreneurship to earlier waves such as edge computing, microservices, serverless, virtualization, and cloud-native operations.
