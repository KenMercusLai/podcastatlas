# Keras

Keras appears in [[ep-8-implementation-of-ai-in-scientific-research]] as a practical deep-learning tool used by [[LucasSimon|Lucas Simon]]'s group. The source describes it as [[TensorFlow]]-based and available through both Python implementation and an R wrapper.

The wiki role of Keras here is not framework history. It marks the applied-software layer for [[BiomedicalDeepLearning]], where researchers build models for [[SingleCellRNASequencing]] data and then still need visualization, output analysis, and biological interpretation before model structure becomes scientific insight.
