# Public First Action

## Overview

Public First Action is an AI-linked political spending group described by [[MarketplaceTech]] as connected to [[Anthropic]] and supportive of a more pro-regulation position.

## Current Profile

The source uses Public First as the counterweight to [[LeadingTheFuture]]. In the New York primary example, Public First reportedly supported [[AlexBores]] while Leading the Future-linked spending opposed him, turning one candidate's AI-regulation record into a contest between rival industry-linked networks.

## Key Characteristics

- Uses outside spending to support selected candidates.
- Is described as connected to Anthropic and more regulation-oriented.
- Demonstrates that AI-industry political spending does not represent a single policy position.

## Evidence

- **Regulatory and affiliation profile:** [[tech-20261007-1007-mp-tech-pod-128-tech-20261007-1007-mp-tech-pod-128]] supplies the Anthropic connection and more-regulatory characterization.
- **Candidate intervention:** [[tech-20261007-1007-mp-tech-pod-128-tech-20261007-1007-mp-tech-pod-128]] says Public First supported Alex Bores in the New York primary.

## Qualifications

The source alternates between “Public First” and “Public First Action”; this page uses the fuller name from the episode overview. Its affiliation, spending, policy position, and candidate support remain episode-attributed, and a connection to Anthropic does not establish company control.
