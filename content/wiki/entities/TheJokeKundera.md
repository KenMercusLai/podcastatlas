# 《玩笑》 / The Joke

[[TheJokeKundera|《玩笑》 / The Joke]] appears in [[12-man-dang-milan-kundela-yi-ju-zhengjing-meiyou-549335675]] as part of [[MilanKundera|Milan Kundera]]'s earlier Czech-language and more visibly political writing. The source uses it mainly as contrast for [[SlowKundera|《慢》 / Slowness]], which the host chooses because it makes Kundera's comic and absurd side harder to ignore.

The page is source-scoped: this ingest does not yet supply an independent reading of the novel's plot or full publication history. Its current wiki value is to mark the better-known political-Kundera frame that [[SlowKundera|《慢》]] complicates.
