# Neo Tango

Neo Tango is the tango shoe store in [[currency-chaos-in-argentina-summer-school]] that shows how [[MonetaryVolatility]] reaches retail operations. The shop assembles shoes in [[Argentina]] but uses some imported materials, so peso depreciation raises input costs.

The episode uses Neo Tango as its most concrete [[MenuCosts]] case. The store accepts multiple currencies, handles purchases that can require large stacks of pesos, and changes prices repeatedly because the cost base is moving too quickly for stable posted prices.
