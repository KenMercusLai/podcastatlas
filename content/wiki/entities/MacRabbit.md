# MacRabbit

## Overview
MacRabbit is the independent Mac software studio remembered in [[anyway-194-anyway-194]] through [[CSSEdit|CSS Edit]], [[EspressoCodeEditor|Espresso]], and [[Slicy]].

## Current Profile
In this source, MacRabbit serves as a benchmark for small-team software craft. The hosts describe it as a low-profile, nearly one-person-style Mac app maker whose products were few but memorable because they combined useful workflows, visual finish, naming charm, and a feeling that the author cared about the user's craft.

The page remains source-bounded. It does not reconstruct MacRabbit's full corporate history, ownership, product timeline, or post-sale maintenance beyond what the episode states.

## Key Characteristics
- It is represented as a very small independent Mac software studio.
- Its products are remembered as both beautiful and useful, not merely decorative.
- Its product line anchors the episode's contrast between early Mac independent-app craft and AI-assisted software creation.
- Its influence is strongest in design and web-development workflows around CSS editing, code editing, and asset export.

## Evidence
- Studio profile - [[anyway-194-anyway-194]] describes MacRabbit as a low-profile, very small independent maker close to today's one-person-company ideal.
- Product influence - [[anyway-194-anyway-194]] names CSS Edit, Espresso, and Slicy as the studio's central remembered products.
- Craft benchmark - [[anyway-194-anyway-194]] uses MacRabbit to define a standard of software that feels polished enough to make users want to create.
- Workflow influence - [[anyway-194-anyway-194]] connects MacRabbit's tools to later expectations in code editors, Photoshop export, Sketch, and Figma-style design handoff.
