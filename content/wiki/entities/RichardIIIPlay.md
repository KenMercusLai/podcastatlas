# Richard III / 《理查三世》

## Overview
Richard III / 《理查三世》 is the [[WilliamShakespeare|Shakespeare]] history play used in the episode to show how drama can serve Tudor legitimacy and harden a hostile public image of [[RichardIII|Richard III / 理查三世]].

## Current Profile
The source treats the play as a political-memory instrument. Because Henry VII's dynastic claim was fragile, the play's darkened Richard helps make the Tudor accession look like providential rescue from civil war. The episode does not use the play as reliable biography; it uses it to explain how theatre, chronicle inheritance, and regime memory can converge.

## Key Characteristics
- It turns Richard III into the dramatic villain against whom Tudor order becomes legible.
- It illustrates how history plays can depart from historical accuracy for political and theatrical effect.
- It reinforces the existing wiki theme that later literature can shape public memory more durably than evidence.
- It links Shakespeare's craft to Tudor-era legitimacy needs.
