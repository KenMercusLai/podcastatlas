# International Code Council

## Overview
The International Code Council is the nonprofit body that maintains the International Building Code, a model code described in the source as the basis for most local American building codes.

## Current Profile
The episode presents the council as a national policy transmission point. Interested parties can propose code changes, and decisions may pass through a technical committee or the broader voting membership. When jurisdictions later adopt the model, a specialized amendment can affect construction far beyond its place of origin.

The elevator case also exposes a review tension: a committee rejected [[GregoryAVictor|Gregory A. Victor]]'s first proposal for lack of standardization and demonstrated cost-benefit support, but the broader membership later approved a fixed seven-foot requirement after an emotional emergency appeal.

## Key Characteristics
- Maintains a widely adopted American model building code.
- Accepts amendment proposals from interested participants.
- Uses both technical-committee review and broader membership voting.
- Can give local safety concerns national construction consequences through code adoption.
