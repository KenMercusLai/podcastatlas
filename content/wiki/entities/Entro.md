# Entro

## Overview
Entro is described in the current source as a non-human identity discovery, visibility, and categorization capability acquired and integrated by [[SailPoint]].

## Current Profile
Its represented role is to inspect endpoints, find machine identities, gather contextual information, and help connect those identities to accountable owners. The episode uses this capability to make orphaned credentials and agents visible before access can be reviewed or narrowed.

## Key Characteristics
- Discovers non-human identities and associated endpoints.
- Categorizes machine identities for governance workflows.
- Supports owner assignment for otherwise orphaned identities.
- Operates as part of SailPoint's broader identity platform in the source account.
