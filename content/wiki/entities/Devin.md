# Devin

Devin is the coding-agent product associated with [[Cognition]]. In [[ep108-vibe-coding-da-dizhen-cursor-dingjia-zhengyi-windsurf-shougou-fengbo-moxing-changshang-qin-erzi-men-you-jiang-ruhe-jinchang-lqn-icq1xqgk7xxxxzrpunj4fan]], Devin appears as context for why Cognition would acquire [[Windsurf]] after the latter's core team moved to [[GoogleDeepMind]].

[[vol-114-ai-de-2025-he-deepseek-men-de-weilai-duitan-fudan-zhangqi-jiaoshou-lhvhnvqtvuv4ln-cckcpedgldolo]] adds Devin as a near-term agent signal. The host cites overseas users treating Devin-like tools as capable of replacing some intern-level work, while [[ZhangQi|张奇]] uses that category to argue that [[AgenticWorkflow]] can accelerate in 2025 if agents combine task execution with reflection and recovery.
