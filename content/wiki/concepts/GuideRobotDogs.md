# Guide Robot Dogs

## Definition
Guide robot dogs are legged robots designed to help visually impaired users move through physical environments by combining navigation, obstacle detection, route memory, natural-language explanation, and safe command control.

## Current Synthesis
The Gaode episode makes guide robot dogs the strongest human-centered use case for navigation-first embodied AI. The value claim is not that a machine fully replaces a trained guide dog; it is that map data, route sharing, speech output, haptic feedback, and owner-specific command recognition may expand mobility support where trained guide-dog supply is extremely limited.

## Key Claims
- Guide robot dogs turn robot navigation into an accessibility product, not only a robotics demo.
- The core task is route guidance through obstacles, doors, open plazas, stores, transit, and destination-specific local paths.
- Shared memory can make one learned route reusable across multiple robots, unlike a biological guide dog's individual experience.
- Natural-language explanation and haptic feedback can tell the user what is ahead rather than only pulling or blocking movement.
- Owner-only command recognition is a safety requirement because a guide robot must not be diverted by strangers.
- The product still depends on road rights, public-space acceptance, safety validation, and real-user testing.

## Evidence
- Accessibility evidence: [[dang-jiqiren-xuehui-renlu-wuli-shijie-cai-zhenzheng-jieshangle-ai-658f592c4a52]] frames guide robot dogs around visually impaired users reaching post offices, markets, stalls, and other ordinary destinations.
- Supply evidence: [[dang-jiqiren-xuehui-renlu-wuli-shijie-cai-zhenzheng-jieshangle-ai-658f592c4a52]] says China has only a few hundred guide dogs, making scalable alternatives salient.
- Interface evidence: [[dang-jiqiren-xuehui-renlu-wuli-shijie-cai-zhenzheng-jieshangle-ai-658f592c4a52]] describes handle vibration, speaker prompts, earphone prompts, and route information during a closed-eye booth experience.
- Memory evidence: [[dang-jiqiren-xuehui-renlu-wuli-shijie-cai-zhenzheng-jieshangle-ai-658f592c4a52]] says short- and long-term memory plus cloud sharing can let route familiarity transfer across robot dogs.
- Safety evidence: [[dang-jiqiren-xuehui-renlu-wuli-shijie-cai-zhenzheng-jieshangle-ai-658f592c4a52]] states that a guide robot dog needs identity recognition so it follows its owner rather than arbitrary bystanders.

## Counterevidence & Qualifications
The episode is a Gaode-side product discussion and does not include visually impaired user outcome data, accident data, pricing, maintenance burden, regulatory approvals, or longitudinal comparison with guide dogs and canes. Biological guide dogs also provide social, emotional, and adaptive support that the source does not show machines matching.

## What Changed
- Initial synthesis: guide robot dogs enter the wiki as an assistive, navigation-first embodied-AI application.
- The current judgment keeps the use case promising but not proven because accessibility impact requires real-user evidence.
