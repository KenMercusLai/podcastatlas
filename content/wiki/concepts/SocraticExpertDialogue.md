# Socratic Expert Dialogue

## Definition
Socratic expert dialogue is an AI interaction pattern that asks targeted questions to expose missing context, assumptions, goals, and tradeoffs before offering advice, while encouraging the user to reason through the problem and acknowledging when human expertise is required.

## Current Synthesis
The bounded source presents questioning as the strongest claimed distinction between an expert protégé and answer-first generation. A user may know the desired outcome without knowing which circumstances change a professional judgment. Follow-up questions can therefore improve the problem representation before a response is produced.

The pattern can also preserve some active reasoning if questions require the user to articulate intent and examine consequences. That benefit is conditional. A sequence of questions can still funnel the user toward a system's assumptions, create an illusion of rigor, or end in an unverified answer. A genuinely Socratic design needs calibrated uncertainty, reasons that can be examined, and escalation when the model lacks sufficient grounding.

## Key Claims
- Good expert assistance helps define the problem before generating a solution.
- Targeted follow-up is most valuable when users do not know which contextual details matter.
- Dialogue can preserve user agency when it elicits reasoning rather than merely collecting inputs for an answer.
- Admitting uncertainty and escalating beyond the system's boundary are part of the method.
- More questions do not automatically mean better judgment; relevance, neutrality, evidence, and user comprehension still matter.

## Counterevidence & Qualifications
The source provides no comparative evaluation showing that this implementation improves accuracy, learning, independent reasoning, or decisions. The label “Socratic” is used functionally, not as a complete account of the historical Socratic method. Questions can be leading, burdensome, privacy-invasive, or optimized to make an output appear personalized. The user still needs access to reasons, evidence, and an accountable professional when stakes exceed the system's competence.

## What Changed
- Created a dialogue concept connecting contextual questioning with uncertainty disclosure and escalation.
- Distinguished reasoning-supportive inquiry from mere personalization or data collection.
