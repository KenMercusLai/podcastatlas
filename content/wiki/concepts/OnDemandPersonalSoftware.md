# On-Demand Personal Software / 按需个人软件

## Definition
On-demand personal software is a narrow program generated for one person's immediate workflow, often with one main function and a useful life too short or audience too small to justify conventional product development.

## Current Synthesis
The episode presents natural-language programming as a shift from choosing among packaged apps toward manufacturing a temporary tool around a personal need. Its bird-identification example is not a startup pitch: the user asks AI to build a practice loop that resembles a familiar check-in product but serves one learner's specific goal.

This lowers the minimum viable audience for software and can replace some lightweight app consumption. It does not remove software responsibility. Security, payments, identity, passwords, privacy, maintenance, distribution, and shared reliability still favor reviewed products or governed platforms, while generated personal tools remain strongest where failure cost and coordination needs are low.

## Key Claims
- Natural-language generation lowers the minimum audience and expected lifetime needed to justify a software tool.
- Personal tools can encode a user's exact workflow without becoming general products.
- Lightweight single-function apps face more substitution pressure than trust-heavy or networked systems.
- Generated code still requires acceptance criteria, data boundaries, maintenance judgment, and recovery paths.
- Traditional products can retain value through security, identity, payments, reliability, distribution, collaboration, and durable support.

- Expanding maker base: [[nianzhong-fupan-1-ai-daigei-wode-10-ge-aha-moments-zhuangminghao-rsi-laile-ai-de-qiguan-yu-cucao-jutou-jiafeng-zhong-de-chuangye-jihui-lqxcqjzbuepdvtqovozf8bepxbzb]] describes many small personal tools appearing on GitHub and use spreading beyond traditional enthusiasts.
- Trust boundary: [[nianzhong-fupan-1-ai-daigei-wode-10-ge-aha-moments-zhuangminghao-rsi-laile-ai-de-qiguan-yu-cucao-jutou-jiafeng-zhong-de-chuangye-jihui-lqxcqjzbuepdvtqovozf8bepxbzb]] expects payments, passwords, security, and privacy to preserve more value for established software.

## Counterevidence & Qualifications
The episode does not establish that AI caused the reported App Store revenue change or that personal generation broadly replaces commercial software. Many users will not want to specify, test, host, secure, or maintain even a small tool. Generated software can also create hidden dependency, data leakage, unsafe permissions, and abandonment risk.

## What Changed
- Created the concept from the episode's “daily disposable software” and personal bird-learning example.
- Defined the trust and coordination boundary that limits substitution of conventional software.
