# Critical Path Method Personal Planning

## Definition
Critical path method personal planning is the use of dependency mapping to identify which tasks determine total project duration and which tasks can run in parallel or consume slack without delaying completion.

## Current Synthesis
The episode translates critical path method through everyday examples: making tea, moving house, and preparing offline events. The method changes planning from a flat to-do list into a dependency graph. Some tasks have no schedule slack because every delay pushes the whole project; others matter but can be parallelized or sequenced flexibly.

The personal productivity value is not precision scheduling for its own sake. It is knowing where earlier preparation changes the total finish date and where effort creates no time advantage because it is outside the path that controls completion.

## Key Claims
- Project duration is controlled by dependent tasks on the critical path, not by the number of tasks listed.
- Non-critical work can be parallelized or delayed as long as it stays within available slack.
- Everyday planning improves when tasks are mapped by dependency rather than urgency alone.
- Moving some preparatory steps earlier can shorten the path that determines completion.
- Critical-path thinking complements bottleneck diagnosis but focuses specifically on elapsed time.

## Evidence
- Tea example evidence: [[ep86-dianfu-gongzuoliu-xiaolu-tisheng-3000-gkwrimaoad7vbjtrsqtotc4k]] uses Hua Luogeng's tea-making explanation to distinguish dependent from parallel tasks.
- Moving example evidence: [[ep86-dianfu-gongzuoliu-xiaolu-tisheng-3000-gkwrimaoad7vbjtrsqtotc4k]] maps inventory, boxes, packing, moving, unpacking, and cleaning into paths.
- Event-planning evidence: [[ep86-dianfu-gongzuoliu-xiaolu-tisheng-3000-gkwrimaoad7vbjtrsqtotc4k]] identifies venue booking and gift production as possible critical-path items in offline activity preparation.
- Method-boundary evidence: [[ep86-dianfu-gongzuoliu-xiaolu-tisheng-3000-gkwrimaoad7vbjtrsqtotc4k]] separates critical activities with no buffer from non-critical activities that can absorb slack.

## Counterevidence & Qualifications
Personal projects often have uncertainty, changing scope, and emotional friction that a clean dependency map cannot fully model. The method is most useful for visible sequencing problems, not as a total explanation of motivation or quality.
