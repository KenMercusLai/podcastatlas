# DAB Radio Capacity Expansion

DAB radio capacity expansion is the broadcast-infrastructure upgrade described in [[in-arms-way-gaza-deal-sticking-points-6a71b49647235c354d3c9b74]]. The episode says [[Kenya]], [[Ghana]], and [[Senegal]] are trialing DAB radio to compress radio waves into digital data and make room for more stations.

The concept matters because radio resilience can create congestion. Nairobi's airwaves are described as crowded, so the problem is not that radio is obsolete but that too many broadcasters want scarce spectrum. DAB is therefore an expansion path inside [[AfricanRadioResilience]], not a replacement by podcasts or streaming.

## Key Claims
- Broadcast modernization can serve radio growth rather than only shutting old systems down.
- DAB addresses station capacity and spectrum crowding while keeping the broadcast medium recognizable.
- The access value depends on whether listeners can receive DAB affordably, not only on whether the transmission standard is efficient.
- DAB trials show that digital transition and low-data public access can coexist.
