# Imagination Inflation and Source Confusion

## Definition
Imagination inflation and source confusion describe the increased tendency to believe an event occurred after repeatedly imagining it, especially when the later memory preserves content but loses reliable information about whether that content came from action, perception, suggestion, or imagination.

## Current Synthesis
The episode's action-imagination experiment makes the mechanism concrete: participants performed some actions and imagined others, then two weeks later were more likely to report repeatedly imagined actions as performed. Both ordinary and bizarre actions were vulnerable, while familiar plausible actions supplied especially usable material for reconstruction.

The mechanism links laboratory false memory to everyday photographs, family stories, partner retellings, and leading questions. Repetition can add detail and fluency until an imagined scene feels autobiographical, but the episode does not imply that every vivid or repeatedly considered event is false. The appropriate response is source monitoring and corroboration, not blanket dismissal.

## Key Claims
- Repeated imagination can increase later belief that an action was actually performed.
- Memory for content can survive while memory for its origin becomes uncertain or misassigned.
- Familiar schemas and plausible details make a reconstructed event easier to complete.
- Photographs, stories, conversation, and suggestive questions can supply ingredients for later source confusion.
- Vividness, detail, sincerity, and confidence do not independently identify the source of a recollection.

## Counterevidence & Qualifications
The source does not show that imagination always creates false belief, that bizarre events are immune, or that any disputed testimony can be rejected because memory is reconstructive. The experiments and effect boundaries remain episode-scoped because the supplied summary does not include full methods, rates, samples, effect sizes, or replication evidence.
