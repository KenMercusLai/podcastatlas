# Self-Doubt as Creative Check

## Definition
Self-doubt as creative check is Rubin's source-scoped claim that doubt can either undermine a creator or serve as a balancing tool that tests judgment before completion.

## Current Synthesis
[[essentials-how-to-access-your-creativity-rick-rubin-scim7816635332]] separates self-doubt from pure pathology. Rubin treats it as a possible check on oneself: if it becomes dominant, it can stop the work; if it stays in proportion, it can prevent overconfidence and sharpen decisions. In the creative-process frame, self-doubt belongs beside taste, phase awareness, and finishing discipline rather than replacing them.

## Key Claims
- Self-doubt can undermine creative work when it becomes disabling.
- The same doubt can help when used as a proportionate check on judgment.
- The value of doubt depends on whether it balances or overwhelms felt response.
- Completion requires enough commitment that doubt cannot defer release forever.
- Creative doubt differs from impostor syndrome when it tests the work rather than global personal worth.

- Dual effect - [[essentials-how-to-access-your-creativity-rick-rubin-scim7816635332]] records Rubin saying self-doubt can either be helpful or undermine the creator.
- Balance function - [[essentials-how-to-access-your-creativity-rick-rubin-scim7816635332]] says self-doubt can serve a great function when used as a balancing tool.

## Counterevidence & Qualifications
The source does not say all self-doubt is useful. It explicitly distinguishes helpful doubt from doubt that undermines the creator, and it does not address clinical anxiety or depression.
