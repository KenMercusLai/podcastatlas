# Essential Patents

Essential patents are patents required to implement a standard rather than merely helpful or optional. [[the-invention-invention]] uses the [[MPEGPatentPool]] to explain why essentiality screening matters: [[KenRubenstein]] is described as an umpire deciding which submitted patents were necessary to [[MPEG]] and which were not.

The concept keeps a standards pool from becoming an everything-bag. If only necessary patents enter, the pool better resembles [[ComplementaryPatents|complementary]] infrastructure; if optional substitutes enter, the pool starts to look like competitor coordination.

## Key Claims
- Essentiality limits a pool to patents that implement the shared standard.
- Independent or neutral screening can protect the pool from being used to suppress alternatives.
- Essential patents often need [[FRANDLicensing]] because implementers cannot avoid them once a standard becomes common.
- The concept is central to [[StandardsBasedInnovation]] because interoperability depends on broad implementer access.
