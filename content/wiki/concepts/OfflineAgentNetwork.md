# Offline Agent Network / 线下智能体网络

## Definition
Offline agent network / 线下智能体网络 is a dense physical-world service layer where payments, merchant devices, customer touchpoints, local offers, membership systems, and store operating agents create actionable offline context for AI systems.

## Current Synthesis
The Ant episode adds the Alipay version through [[AlipayTapNetwork|碰一下]]. If a payment touchpoint also becomes a context, authorization, distribution, and merchant-operations surface, then offline retail can support agents without waiting for every small business to build a full software API.

The value is not only the user's checkout speed. A store-level agent can use transaction and membership signals to analyze operations, target subsidies, manage members, and measure whether local advertising or couponing leads to store visits and purchases.

## Key Claims
- Offline agents need physical touchpoints, not only cloud APIs.
- Payment events can become context for merchant operations and local-service fulfillment.
- Store agents can help translate transactions into analysis, membership, subsidies, and distribution.
- Dense offline networks may make local advertising more outcome-based.
- Merchant ROI and trust determine whether offline agent networks become more than payment features.

- Merchant-agent evidence: [[273-guangwan-waitan-dahui-faxian-mayi-zhaodaole-xin-weizhi-lotxogfoqqwcjigxihtixvncbfc3]] names 小语 as a merchant operating agent for analysis, membership, subsidies, and store distribution.
- Business-model evidence: [[273-guangwan-waitan-dahui-faxian-mayi-zhaodaole-xin-weizhi-lotxogfoqqwcjigxihtixvncbfc3]] suggests offline ads, coupons, and store operations could shift toward effect-based payment if the network is dense enough.

## Counterevidence & Qualifications
The source does not prove merchant adoption, payback, or data-rights alignment. Offline agents may be constrained by hardware rollout, fragmented merchant systems, privacy concerns, and platform dependence.
