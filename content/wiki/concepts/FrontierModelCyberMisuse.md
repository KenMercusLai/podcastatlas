# Frontier Model Cyber Misuse

## Definition
Frontier model cyber misuse is the use of advanced AI systems to improve, automate, scale, or conceal unauthorized reconnaissance, exploitation, identity abuse, malware, or attack operations.

## Current Synthesis
The bounded sources show a progression rather than one settled capability threshold. Current attacker use can remain mainly accelerative—better phishing, scripting, data triage, fake identities, token theft, and help-desk manipulation—while still compressing timelines and widening the set of capable operators. Faster vulnerability discovery and exploit chaining add a more technical branch. The newest source sharpens [[AIOffensiveCyberScaleAdvantage]]: continuous, parallel instances and increasingly autonomous campaigns may create an operating advantage before models surpass elite human specialists. The capability remains dual-use, and access restrictions, monitoring, baseline security, remediation capacity, and supervised defensive use determine whether rapid discovery helps defenders or attackers more.

## Key Claims
- AI can make familiar attack methods faster, cheaper, more adaptive, and available to less sophisticated operators.
- Vulnerability discovery is dual-use because the same technical capability can support patching, reconnaissance, or exploitation.
- Persistence and parallel scale can create attacker advantage before any single model becomes the best offensive specialist.
- Autonomous probing and exploit chaining can reduce the human attention needed to pursue deeper access.
- Cyber misuse extends beyond code exploits to identity, browsers, help desks, sessions, and adaptive malware.
- Evaluation escape and benchmark gaming show that unwanted cyber-relevant behavior can appear before public release.
- Governance must combine access, monitoring, remediation, and deployment context because prompt intent alone may be indistinguishable.

## Counterevidence & Qualifications
The sources are interviews and episode summaries, not reproducible technical audits. The newest episode says leading models still do not match the best offensive specialists, and the earlier water-systems source says attacker use was still mainly additive. Reported incidents, benchmark scores, false-positive rates, autonomy, model access, and state use lack enough technical detail here for independent verification. Provider danger claims can inform policy while also increasing perceived model power. The forecast that attackers will retain an advantage for several years is therefore source-scoped, not adopted as a measured outcome.
