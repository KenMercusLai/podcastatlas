# Prompt As Intent Transmission

Prompt as intent transmission is [[LiJigang]]'s broader view of prompting in [[e45-mengyan-duihua-lijigang-ren-heyi-zichu-lva2mfxese7v0sfv3mfpfhbdask]]. A prompt is not only a carefully worded chat message. It can include a role instruction, a PDF, local notes, prior conversations, a memory file, a task folder, a personal principle, or any other medium that lets a model receive the user's intention.

This reframes prompting away from tricks. The important question is whether the model can understand what the person wants, what frame it should reason from, what context matters, and what shape of answer is acceptable. That makes prompting a branch of [[AICommunicationAbility]] and [[ContextEngineering]] rather than a separate craft of magic phrases.

[[ep-15-unveiling-data-scientists-role-in-the-generative-ai-era]] adds a data-science career version through [[MarinaDataScienceWithSam|Marina]]. Her example that changing one word in a prompt can change relevance supports the same broader point: prompt quality depends on task understanding, domain context, and [[DataScientistGenerativeAIFluency]], not only a reusable wording template.

[[ep-17-ais-impact-on-creativity-a-consumers-perspective]] adds a consumer and volunteer-work version through [[MarkDataScienceWithSam|Mark]]. His speech, image, song, and [[GoogleAppsScript]] examples show prompting as ordinary task communication: the user supplies topic, audience, event, workflow, and constraints so [[ChatGPT]], [[DALLE|DALL-E]], or [[Suno]] can produce a useful starting point.

The episode also warns that good prompts are difficult because parameters and judgment matter. Li compares prompt writing to investment valuation: formulas are easy to name, but the parameter choices and mental path depend on accumulated taste, context, and discernment.

## Key Claims
- Prompting is the act of transmitting intention into model space.
- Documents, files, notes, memory, and local context can be prompt material.
- Good prompting depends on self-knowledge and task knowledge, not only templates.
- In everyday creative work, prompt quality depends on audience, tone, event context, tool choice, and the user's willingness to revise the output.
- In applied data-science work, a prompt is useful only when the data scientist can judge whether the answer fits the business target.
- Meta-prompts can produce artificial-sounding outputs if there is not enough rich context behind them.
- High-density conversation can create the context from which better prompts later emerge.
