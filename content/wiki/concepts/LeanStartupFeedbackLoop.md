# Lean Startup Feedback Loop

## Definition
Lean startup feedback loop is the build-measure-learn approach of using MVPs, real-world feedback, validated learning, and pivots to test assumptions before committing large resources.

## Current Synthesis
The episode presents Lean Startup as the entrepreneurial counterpart to operations workflow. MVPs are not cheap products for their own sake; they are low-cost tests of core value assumptions. A result can be good, bad, or mixed as long as it produces validated learning that changes the next decision.

The pivot section sharpens the boundary. Pivot is not random quitting; it is changing direction while preserving a verified core, like a basketball pivot that keeps one foot planted. The host uses Dropbox, Slack, Instagram, and her own career transitions to show how feedback can preserve some validated insight while changing form, market, or channel.

## Key Claims
- MVPs should test the core value assumption with minimum necessary cost.
- Validated learning turns failure into evidence rather than identity judgment.
- Pivoting should preserve a verified core while changing the unproven route.
- Feedback loops reduce the cost of being wrong by making assumptions testable earlier.
- Personal career or creator shifts can be interpreted as pivots when they preserve proven capability, pain point, or audience feedback.
