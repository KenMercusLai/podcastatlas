# Core Tribe Positioning

Core tribe positioning is the practice of defining the first customer community that most clearly understands, repeats, and validates a product before the company tries to become mainstream. In [[advice-line-with-chris-riccobono-of-untuckit-c087247f-1f85-4c15-b4aa-4ffea0368c4c]], [[GuyRaz]] asks [[AdrianAlvarez]] to identify [[AeroShorts]]' core tribe before describing the brand as broadly for everyone.

The source treats volleyball players, college students, and high-school students as more useful first audiences than generic activewear consumers. [[ChrisRiccobono]] adds that the apparel category is crowded, so AeroShorts needs a sharper message and differentiation beyond price before broad fundraising and marketing can compound.

## Key Claims
- A mainstream ambition can start with a narrow tribe if that tribe creates repeat purchase, language, and social proof.
- A broad use case should not erase the first audience that actually understands the product.
- A founder's own identity can be an advantage when it matches the early customer community and content platform behavior.
- Core tribe positioning overlaps with [[SubcultureLedMarketing]], but it is more explicitly a positioning and sequencing choice.
