# First-Person AI Memory / 第一视角AI记忆

## Definition
First-person AI memory is the use of wearer-perspective audio, visual, and contextual data to help an AI system recall, summarize, retrieve, or act on what a person saw, heard, or experienced.

## Current Synthesis
The RayNeo source grounds the concept through Live Log. [[LiHongwei|李鸿伟]] argues that glasses can capture "what you see" and "what you hear" more naturally than a phone, making memory useful for functional recall such as finding objects and remembering events, and for emotional recall such as summarizing travel or meaningful moments.

The concept is not equivalent to continuous video recording. The source presents it as filtered, low-power, event-selective sensing supported by [[TieredOnDeviceSensing]]. That makes it useful as a possible [[WearableAIAssistant]] capability while also tying it to [[SmartGlassesBystanderPrivacy]], [[ConsentBasedRecording]], and [[AIHardwarePrivacyExchange]].

## Key Claims
- First-person capture has value because it aligns with what the wearer is actually seeing and hearing.
- Memory use cases split into functional recall and emotional life-recording.
- Always-on memory depends on filtering and trigger design, not simple full-time high-resolution recording.
- Glasses can capture contexts a phone misses when the phone is pocketed, handheld, or socially interruptive.
- The same capability raises bystander consent, privacy, storage, and retrieval-governance questions.

## Evidence
- Live Log framing - [[no-221-leiniao-ceo-xinjishu-yuelaiyueduo-women-weishenme-hai-xuyao-yifu-zhineng-yanjing-gkwridon6uwmaoosszqset9vd]] describes glasses as seeing what the user sees and hearing what the user hears.
- Functional memory - [[no-221-leiniao-ceo-xinjishu-yuelaiyueduo-women-weishenme-hai-xuyao-yifu-zhineng-yanjing-gkwridon6uwmaoosszqset9vd]] names finding items and remembering what happened as useful recall cases.
- Emotional memory - [[no-221-leiniao-ceo-xinjishu-yuelaiyueduo-women-weishenme-hai-xuyao-yifu-zhineng-yanjing-gkwridon6uwmaoosszqset9vd]] names travel and beautiful-moment summaries as a separate value path.
- Technical limit - [[no-221-leiniao-ceo-xinjishu-yuelaiyueduo-women-weishenme-hai-xuyao-yifu-zhineng-yanjing-gkwridon6uwmaoosszqset9vd]] says always-on camera requires layered low-power sensing rather than brute-force recording.

## Counterevidence & Qualifications
The source does not provide retention, privacy, battery, storage, or retrieval-accuracy evidence. It also does not settle how bystanders consent to being recorded by someone else's glasses.
