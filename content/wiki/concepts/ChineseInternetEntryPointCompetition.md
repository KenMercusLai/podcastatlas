# Chinese Internet Entry-Point Competition / 中文互联网入口竞争

## Definition
Chinese internet entry-point competition is the recurring fight to control the first route users take into online services, including keywords, browser plugins, homepages, navigation pages, search defaults, security tools, mobile assistants, and app stores.

## Current Synthesis
The source makes entry-point competition the through-line of [[ZhouHongyi|周鸿祎]]'s career. The object of competition changes from Chinese keywords to security software, browsers, search, mobile distribution, and enterprise security, but the strategic problem stays similar: whoever controls a trusted user-access surface can redirect attention, data, ads, and bargaining power.

## Key Claims
- Language and usability friction can create a new entry point, as [[3721]] did by turning Chinese keywords into a substitute for memorizing English URLs.
- Browser plugins and default settings can become distribution infrastructure, but aggressive installation, popups, and difficult uninstall can convert entry-point control into trust damage.
- Security software can become an entry point because users grant it unusually high authority over other software, updates, warnings, and removals.
- Browser, navigation, and search products can turn a utility tool into advertising and traffic leverage.
- Mobile internet weakens PC-era entry points when app stores, handset vendors, and closed apps redirect user distribution.
- Entry-point ownership can spill into legal and public-opinion fights when competitors treat default access as existential.

## Evidence
- Chinese-keyword access: [[no-216-shi-bu-sha-yi-ren-hongyi-dapao-zhouhongyi-de-sanshinian-quanmian-zhanzhengshi-zhongguo-hulianwang-gushi-27-1008693437]] says 3721 solved ordinary users' difficulty with English URLs and sold Chinese keywords as a navigation product.
- Trust damage: [[no-216-shi-bu-sha-yi-ren-hongyi-dapao-zhouhongyi-de-sanshinian-quanmian-zhanzhengshi-zhongguo-hulianwang-gushi-27-1008693437]] says 3721's plugin behavior produced "rogue software" criticism and legal disputes with CNNIC and [[Baidu]].
- Security as entry point: [[no-216-shi-bu-sha-yi-ren-hongyi-dapao-zhouhongyi-de-sanshinian-quanmian-zhanzhengshi-zhongguo-hulianwang-gushi-27-1008693437]] describes 360 Security Guard, free antivirus, security browser, URL navigation, and software manager as the traffic system behind [[Qihoo360|Qihoo 360]].
- Search and default leverage: [[no-216-shi-bu-sha-yi-ren-hongyi-dapao-zhouhongyi-de-sanshinian-quanmian-zhanzhengshi-zhongguo-hulianwang-gushi-27-1008693437]] says 360 switched browser and navigation defaults into 360 search in 2012 and quickly became the second-ranked search service.
- Mobile shift: [[no-216-shi-bu-sha-yi-ren-hongyi-dapao-zhouhongyi-de-sanshinian-quanmian-zhanzhengshi-zhongguo-hulianwang-gushi-27-1008693437]] says 360 Phone Guard and 360 Mobile Assistant were important in Android distribution but were later squeezed by handset-maker app stores.

## Counterevidence & Qualifications
This source is centered on Zhou and 360, so it does not cover every Chinese internet entry-point layer. Community, ecommerce, short-video, payment, operating-system, and super-app entry points are only adjacent here unless connected to Zhou's story.
