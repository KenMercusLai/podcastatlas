# Industrial Ladder

Industrial ladder is the development sequence described in [[getting-entrepreneurial-in-korea-summer-school]], where countries often start with simpler labor-intensive goods such as T-shirts and then try to move toward steel, cars, and computer chips. The source uses garment manufacturing as a first rung because it can absorb many workers without requiring high formal education.

The concept is not a guarantee. [[Bangladesh]] became one of the largest clothing exporters, but [[OliverKim]] says it did not move as expected into more complicated goods. The episode therefore treats [[TextileKnowledgeTransfer]] as powerful but incomplete: countries can climb the first rung and still stall.
