# Global Positioning System / GPS

The Global Positioning System / GPS appears in [[kafeidou-liangci-zaoyu-pingguo-chongji-yundong-shoubiao-jiaming-weihe-hai-neng-zengzhang-1006272684]] as the technical root of [[Garmin]]'s business. The source describes GPS as a U.S. military navigation system that became more available to civilian aviation after a 1983 Korean civil-airline incident, creating the conditions for specialized navigation hardware.

In this source, GPS is not just a location signal. It is a capability that can move across markets: aviation and marine devices, surveying, consumer car navigation, running watches, golf maps, city-running accuracy, and outdoor route finding. Garmin's story shows how a once-specialized signal can be commoditized in one market while remaining valuable in more demanding use cases.

## Key Claims
- GPS value depends on the use case: ordinary phone maps can satisfy casual users, while aviation, marine, endurance, golf, and outdoor users may pay for reliability, battery life, map detail, and device fit.
- [[NavigationDeviceCommoditization]] can happen when a platform turns GPS-based navigation into a default service.
- GPS can still support [[ProfessionalWearableMoat]] when the product combines positioning with sport-specific metrics, maps, terrain, and user trust.
