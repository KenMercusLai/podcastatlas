# Project-Based Vocational Learning / 项目式职业学习

[[ep262-gaokao-guohou-zhishi-guiling-women-xuyao-zenyang-de-kexue-jiaoyu-ls8ecqcdpe9d5ioytyca3jqdf-3r]] adds the general-science counterpart through [[ProjectBasedScienceLearning|项目式科学学习]]. The parallel is useful: whether in vocational training or K12 science, a project builds learning only when students connect the artifact to evidence, concepts, real constraints, and reflection rather than treating the finished object as proof of understanding.

Project-based vocational learning / 项目式职业学习 is the hands-on learning mode highlighted in [[ep241-xiaoqi-hezuo-shi-xinyidai-de-tiefanwan-ma-lnmpsbvoqbexeardxyx88hywufig]]. [[LiuChang|刘畅]] observes that some vocational students who struggled with abstract book learning gained confidence once they could make, fix, wire, code, or complete concrete projects.

The concept matters because it gives [[VocationalEducation|职业教育]] a value that is not only lower-status credentialing. It can create capability, motivation, and skill identity, but the source worries that this value can be reduced if students are pushed back into a purely exam-and-degree route through [[VocationalDegreeProgression|升学]].

## Key Claims
- Hands-on projects can reveal competence that standard academic assessment may miss.
- Confidence and interest can grow when students see a working result, not only a test score.
- Project learning fits [[SchoolEnterpriseCooperation|校企合作]] because companies can provide real equipment, workflows, and problems.
- AI can help students troubleshoot coding, wiring, and summaries, but [[HumanJudgmentUnderAI|human judgment]] remains necessary to understand and own the result.
