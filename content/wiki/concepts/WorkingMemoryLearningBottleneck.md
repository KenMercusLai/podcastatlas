# Working Memory Learning Bottleneck

## Definition
Working memory learning bottleneck is the learning constraint where missing fluency in earlier skills consumes limited working memory and prevents a student from solving higher-level problems.

## Current Synthesis
The Alpha School source uses prerequisite gaps to explain why grade-level assignment can hide actual learning blockers. A student may appear ready for advanced math or reading by age, but missing multiplication fluency, phonics, vocabulary, or earlier concepts can load working memory so heavily that new reasoning stalls. In the source's system, AI-supported diagnosis and right-level mastery are meant to remove those bottlenecks before students move on.

## Key Claims
- Learning can fail because earlier subskills are not automatic enough, not because the student cannot understand the target concept.
- Grade level is a weak proxy for readiness when students carry hidden prerequisite gaps.
- Fluency in basics protects working memory for higher-level reasoning.
- Remediation works best when it identifies the specific missing skill rather than reteaching broad grade-level content.
- AI-supported learning systems can, in principle, make bottlenecks visible through fine-grained performance and retention data.
- Claims about repair speed remain source-scoped until independently evaluated.

## Evidence
- Prerequisite examples: [[how-to-accelerate-learning-improve-education-joe-liemandt-scim7393383815]] discusses eighth graders missing earlier math skills, reading, multiplication, and phonics.
- Working-memory mechanism: [[how-to-accelerate-learning-improve-education-joe-liemandt-scim7393383815]] says missing multiplication facts can bottleneck SAT math because basics consume mental capacity.
- Diagnostic model: [[how-to-accelerate-learning-improve-education-joe-liemandt-scim7393383815]] links right-level lessons, mastery thresholds, and retention checks to finding and fixing gaps.
- COVID-loss context: [[how-to-accelerate-learning-improve-education-joe-liemandt-scim7393383815]] treats pandemic learning loss as an example of hidden prerequisite damage.

## Counterevidence & Qualifications
The source does not isolate working memory as the only cause of poor performance. Motivation, instruction quality, sleep, environment, disability, stress, language background, and selection can also affect learning. The bottleneck concept is useful only when paired with actual diagnosis rather than assumed from test scores alone.
