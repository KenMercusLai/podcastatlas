# Cognitive Offloading / 认知卸载

## Definition
Cognitive offloading is the use of other people, external records, search systems, navigation tools, or AI to store information or perform cognitive operations that would otherwise be done internally.

## Current Synthesis
Across the sources, offloading is an ordinary human strategy rather than an AI-era defect. Social knowledge, books, search engines, translation tools, and navigation systems can free limited attention and memory for other work. The benefit depends on retained access, verification, and judgment: knowing where to retrieve information can be more useful than memorizing every fact.

Generative AI changes the intensity of offloading because it returns organized prose and completed reasoning rather than a field of sources that still requires comparison. The learning source identifies the risk as removal of search, recall, synthesis, explanation, and correction—the same operations that build memory and judgment. The teen-homework source adds an incentive problem: guided modes may preserve learning, but users can switch to answer-first competitors. The workplace source adds a purpose boundary: translation drafts and other bounded tasks can be delegated, while reading, conversation, embodied experience, taste, and responsibility are harder to outsource without weakening the frame used to judge output.

The [[PoppyCrum]] episode turns this into [[CognitiveAmplificationBoundary]]. AI-generated tests, coaching analytics, and feedback can reveal gaps while preserving active work; finished answers can improve immediate output while reducing germane cognitive load and later transfer. Offloading is therefore task-relative: a person should identify which capability the tool is meant to support, which operation can be delegated, and which practice must remain active.

## Key Claims
- Offloading is useful when it frees capacity while preserving access, verification, judgment, and the capability the user intends to retain.
- Generative AI can remove more comparison and synthesis than search because it supplies an already organized answer.
- Offloading becomes [[CognitiveDebt]] when the delegated operation was also the training loop for attention, memory, writing, reasoning, taste, or self-direction.
- [[FirstDraftThinking]], retrieval, explanation, and guided questioning can delay delegation until the learner has formed a frame that AI can test or refine.
- Homework gains, fluent output, or faster completion do not by themselves demonstrate later transfer or independent capability.
- Bounded, checkable tasks are safer to delegate than responsibility-bearing work whose quality depends on lived context and human judgment.
- Product incentives matter because users may abandon learning-preserving guardrails for systems that give immediate answers.

## Counterevidence & Qualifications
The sources do not show that internal memory is always superior, that all tool use causes decline, or that every user needs to retain every delegated skill. Reported homework, exam, EEG, ownership, recall, and transfer effects remain source-scoped because the notes do not expose full methods, samples, effect sizes, or long-term replication. Tasks differ: offloading routine operations may enable higher-level work, while preserving effort can become wasteful if the operation is irrelevant to the intended capability. The practical boundary requires an explicit goal rather than a blanket rule for or against AI.
