# AI Context Machine / AI 上下文机器

AI context machine is [[WangTianfan]]'s phrase-level thesis for products that help AI move from generic intelligence toward personal wisdom. In [[reai-yige-hangye-15-nian-de-liyou-shi-shenme-duitan-wang-tianfan-woyao-tou-zhenzheng-de-kuaile-tou-zui-chun-de-yuanjing-tou-renxing-de-guanghui-gonglu-boke-lu98aa1byafbbljyjrn8oquiezk]], the ideal context machine records what a user says, hears, sees, does, and feeds back, then turns that context into reflection, recall, care, or action.

The source makes hardware important but not sufficient. Wearable devices, glasses, or pendants can expand the capture surface, yet Wang argues that shallow recording is not the point. The product question is whether interaction design and software can help the user understand themselves, connect with others, or live more presently.

## Key Claims
- AI context products need richer user context than a one-off prompt can provide.
- Physical-world capture can make AI more useful because users do not live only inside apps or documents.
- The strongest value comes after capture: summarization, salience, feedback, reflection, privacy, and user-facing interaction loops.
- Context machines raise privacy and consent questions because they can capture other people's speech, faces, spaces, and behavior.
