# Root-Base Priority / 根本根据地优先

[[zizhi-tongjian-hanji-986-tianyu-qiwang-bixian-lingqi-kuang-lvlvu057-tnz3hal6oodhydvzvbd|Hanji 986]] supplies the trigger for the root-base question. After [[CaoCao|曹操]] defeats [[LyuBu|吕布]] in [[YanzhouLateHan|兖州]], [[TaoQianLateHan|陶谦]] dies and [[LiuBei|刘备]] takes [[Xuzhou|徐州]], making an outward attack look timely. The episode stops at the moment a counselor is about to object, so it prepares rather than fully states the principle.

Root-base priority / 根本根据地优先 enters the wiki through [[zizhi-tongjian-hanji-987-dingtao-zhizhan-caocao-he-lvbu-dianfeng-duijue-lofq0pq8n9rrfvfttunahisy0ave|Hanji 987]] as [[XunYu|荀彧]]'s answer to [[CaoCao|曹操]]'s temptation to take [[Xuzhou|徐州]]. The principle is not anti-expansion. It says expansion becomes dangerous when the actor's own base is still exposed, under-harvested, or politically unsettled.

The source case is [[YanzhouLateHan|兖州]]. Xun Yu argues that Cao Cao's root base is the place where his people trust him, where grain can be gathered, and where later attack or retreat remains possible. [[LyuBu|吕布]] and [[ZhangMiaoLateHan|张邈]] make that base unsafe, so chasing Xuzhou after [[TaoQianLateHan|陶谦]]'s death would trade a real foundation for an attractive but uncertain gain.

The concept differs from [[StrategicRetreatBaseBuilding|退让式根据地经营]]. Strategic retreat base-building concerns turning an imposed fallback position into future power. Root-base priority concerns refusing an optional outward move until the existing foundation is secure. It also extends [[WarCostTempoDiscipline|战争成本与速决纪律]] upstream: the cost problem is decided before the campaign begins, through harvest, rear security, local acceptance, and whether the target can feed the army.

## Key Claims
- A tempting expansion can be strategically wrong if it exposes the actor's base to a nearby unresolved enemy.
- Hanji 986 shows the tempting-expansion setup before Hanji 987 supplies Xun Yu's full base-first argument.
- A base is not only territory; it is harvest, manpower,民心, route safety, and a credible fallback.
- Historical precedent is useful when it identifies the function of a base, not when it becomes a slogan for passivity.
- Refusing a campaign can be an active strategy when it preserves the conditions for a later decisive campaign.
- The concept marks a boundary on opportunism: a target's weakness does not matter enough if one's own rear cannot hold.
