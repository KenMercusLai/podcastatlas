# Intelligence Failure Mass Arrest

Intelligence failure mass arrest is the pattern where a coercive roundup depends on inaccurate, stale, or politically distorted suspect lists. In [[699-the-troubles-return-of-the-ira-part-3-glt9519811642]], [[OperationDemetrius]] uses outdated [[RoyalUlsterConstabulary|RUC]] files that do not properly reflect the split between the [[OfficialIRA]] and the [[ProvisionalIRA]].

The episode's point is not only that some targets were wrong. Because 342 people were arrested and all were Catholics, the operation made [[InternmentWithoutTrial]] look like collective punishment while missing the even-handedness [[EdwardHeath]] said he wanted. The failure therefore deepened [[CounterinsurgencyLegitimacyTrap]].

## Key Claims
- Coercive accuracy matters politically as well as operationally.
- Old files can preserve a prior organizational map after the conflict actor has already changed.
- Roundups can create more usable grievance than security benefit when the error pattern maps onto communal identity.
