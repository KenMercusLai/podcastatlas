# Actionable Organizational Values

## Definition
Actionable organizational values are values clear enough to resolve dilemmas, guide decisions, shape processes, and survive movement through organizational layers.

## Current Synthesis
[[how-modern-brands-build-loyalty-purpose-and-identity-andy-stalman-shekhar-natarajan-podcast]] treats values as operating tools rather than wall text. [[ShekharNatarajan]] contrasts actionable values with vague slogans, while [[AndyStalman]] argues that values should answer questions and create impact. In this frame, values matter when they affect collaboration, hiring, leadership, AI behavior, and tradeoffs between revenue and culture.

## Key Claims
- Values are actionable only when employees can use them to resolve concrete dilemmas.
- Leadership has to reinforce values because they decay as they move through organizational layers.
- Collaboration cannot be made real by stating it; processes must make collaboration easier than isolated competition.
- Values connect brand, culture, and AI because agents need organizational DNA before they can act consistently.
- Younger workers' search for purpose increases the cost of treating values as decorative language.

## Evidence
- Decision use: [[how-modern-brands-build-loyalty-purpose-and-identity-andy-stalman-shekhar-natarajan-podcast]] says values solve dilemmas, answer questions, and create impact.
- Amazon example: [[how-modern-brands-build-loyalty-purpose-and-identity-andy-stalman-shekhar-natarajan-podcast]] uses Amazon as an example of values that help resolve organizational choices.
- Process design: [[how-modern-brands-build-loyalty-purpose-and-identity-andy-stalman-shekhar-natarajan-podcast]] has Shekhar argue that collaboration must be designed into processes rather than only written on a wall.
- AI consistency: [[how-modern-brands-build-loyalty-purpose-and-identity-andy-stalman-shekhar-natarajan-podcast]] links shared DNA, culture, values, and purpose to whether AI can answer consistently.

## Counterevidence & Qualifications
The source gives strong practitioner claims but limited evidence on how to test whether values are truly actionable. Some values may also conflict, so the concept should include escalation rules and tradeoff clarity rather than assuming every value points to one obvious answer.
