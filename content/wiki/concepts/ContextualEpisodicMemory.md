# Contextual Episodic Memory

## Definition
Contextual episodic memory is the binding of people, objects, actions, place, time, and internal state into a situated event that can later orient perception, identity, and future simulation.

## Current Synthesis
The Ranganath episode makes context the organizing feature of episodic memory. The hippocampus is described as linking otherwise separate elements to a particular situation, while event boundaries mark changes in topic, place, activity, or goal that can separate one remembered episode from another. This helps explain why interrupted, frequently switched experience may later feel fragmented.

Context also shapes familiarity and self-orientation. Waking in an unfamiliar setting requires reconstructing how the present situation arose, while a new scene that shares the spatial layout of an earlier one may feel familiar enough to trigger deja vu despite different surface details. The concept therefore complements [[ReconstructiveMemory]]: retrieval is not replay but context-sensitive rebuilding from linked elements and prior structure.

## Key Claims
- Episodic memory binds elements of experience to a specific context rather than storing each element in isolation.
- Context retrieval helps a person orient after sleep, travel, or a sudden situational change.
- Event boundaries segment continuous experience and can make frequent task switching produce competing memory fragments.
- Familiar spatial structure can produce a familiarity signal even when surface details differ, offering one experimental account of deja vu.
- Episodic memory helps update a continuing sense of self and supports simulation of possible futures.

- Context binding - [[how-to-improve-memory-focus-using-science-protocols-dr-charan-ranganath-scim5612458885]] defines the hippocampus as linking elements of experience to a particular context.
- Orientation and self - [[how-to-improve-memory-focus-using-science-protocols-dr-charan-ranganath-scim5612458885]] uses waking and amnesia examples to connect episodic retrieval with situational and autobiographical updating.
- Event segmentation - [[how-to-improve-memory-focus-using-science-protocols-dr-charan-ranganath-scim5612458885]] says topic, place, or context changes create boundaries that separate what came before.
- Deja vu - [[how-to-improve-memory-focus-using-science-protocols-dr-charan-ranganath-scim5612458885]] describes virtual-reality work where shared spatial layout can evoke familiarity across visually different scenes.

## Counterevidence & Qualifications
The source is a condensed public conversation, not a full model of hippocampal, perirhinal, semantic, procedural, or working-memory systems. Its waking-orientation and deja-vu examples are explanatory illustrations, not diagnostic tools, and deja vu can also occur in temporal-lobe epilepsy or other contexts requiring medical interpretation.
