# Patent Pool

A patent pool is a licensing structure where multiple patent holders combine rights so users can access a set of related inventions through a shared arrangement. In [[the-invention-invention]], the first major case is the 1856 [[SewingMachineCombination]], which let rival sewing-machine makers stop blocking each other with lawsuits.

The source's modern case is the [[MPEGPatentPool]], which used [[EssentialPatents]] screening and [[FRANDLicensing]] commitments to make a video standard broadly usable without turning cooperation into unlawful collusion.

## Key Claims
- Patent pools can convert a [[PatentThicket]] into a workable production system.
- The useful version pools [[ComplementaryPatents]], not substitutes that should compete.
- A pool needs access rules, price discipline, and neutrality so outsiders are not blocked.
- Patent pools can become cartel tools if participants use them to restrict output, fix prices, or exclude competitors.
- Modern standards often need patent pools because no single company owns all the necessary pieces.
