# Astra 冲击 Agent、机器人与 AI 制药：模型能力跃迁之后，真正的瓶颈是什么？

## 概览

本期围绕 Astra 发布后的行业变化展开，讨论个人 Agent、机器人与 AI for Science 三个方向。嘉宾认为，Astra 在长程任务、Computer Use、三维理解和行动反思方面明显进步，但其价值在不同领域并不均衡：普通用户未必能感受到代际差异，机器人和生物医学研究者却已经看到工作方式的变化。

个人 Agent 的主要障碍不只是模型能力，还有浏览器访问限制、用户身份验证、云端虚拟机与 Token 成本。节目提出，未来消费级 Agent 可能需要与本地硬件结合，才能证明 Agent 代表真实用户，同时降低推理成本并减少被网站屏蔽的风险。

机器人领域被认为迎来了接近“GPT 时刻”的变化：Astra 已能把反思转化为动作，并将大模型的控制边界下压到较低层级。不过，它仍然速度缓慢、缺乏直觉物理能力，无法胜任高动态、双臂协作和难以用语言描述的任务。因此，更可能落地的架构是“大模型负责慢思考与规划，小模型负责快速控制”。

AI 制药的核心瓶颈则不在生成候选分子，而在真实实验的设计、执行和验证。模型可以快速提出方案，动物实验和人体试验却受自然周期制约。节目最终把三个行业的共同问题归结为：模型展示的是能力曲线，而产业真正面对的是验证成本与落地周期。

## 分段落总结

[00:00] **节目背景与三条讨论主线**

[事实] 节目宣布将消费商业类内容独立为新播客《消费101》，随后引出 Astra 对 Agent、机器人和制药行业的影响。

[事实] 主持人列举了个人 Agent、系统一模型、AI 科学发现和虚拟细胞计划等近期进展，并提出三个核心问题：个人 Agent 的商业化卡在哪里、机器人如何被底层模型冲击、AI 制药的真正瓶颈是什么。

[事实] 主持人认为，相较不断变化的热点产品，本期讨论的行业底层逻辑更接近本质，也更不容易过时。

[04:18] **Astra 的实际体验：反思、自我改进与长程任务**

[事实] 机器人测试显示，Astra 能识别机器人本体的速度、活动空间和碰撞问题，并把反思过程转化为动作调整。

[事实] 在插花实验中，Astra 能理解花茎分叉会妨碍插入，并采取捏紧分叉后再插入的策略，表现出一定的三维空间和物理操作理解。

[事实] Astra 还能根据少量图片快速生成仿真环境，降低从真实环境迁移到模拟环境时所需的拍摄、标定和人工修改成本。

[事实] 在模型开发和编程场景中，Astra 对上下文与既有任务的认知更稳定，长程任务和前端审美有所提升，但速度偏慢，运行一整晚或持续 24 小时时仍可能出现幻觉。

[09:13] **Computer Use 在生物医学中的价值**

[事实] 生物医学团队已经将部分内部任务切换到 Astra，主要看重其 Computer Use 和长程任务能力。

[事实] Astra 可以操作界面陈旧、术语繁多的专业软件，用户也能通过观察其鼠标和键盘操作学习软件使用方法。

[事实] Computer Use 是让模型根据屏幕视觉信息决定点击位置、输入内容，并串联多个动作完成任务；它不要求软件提供专门的 API。

[事实] 生物医学任务经常持续 8 至 24 小时，嘉宾会在白天使用反馈较快的模型，夜间则让 Astra 执行较长的 Pipeline。

[13:23] **浏览器 Agent 的访问困境**

[事实] 许多购物、旅行和客服网站不愿开放 API，因此个人 Agent 仍需要依赖浏览器操作。

[事实] 云端浏览器容易被网站识别为商业流量或机器人流量，Manus 等产品因此逐渐从消费场景转向白领工作场景；节目还提到亚马逊已经屏蔽 Meta Muse。

[事实] 嘉宾提出，本地运行浏览器与小模型可能避开云端商业 IP 的限制，因为网站看到的是用户自己的网络与设备。

[推测] API 调用与浏览器操作可能长期并存：开放接口适合高效率执行，而无法获得接口的服务仍需依靠视觉化操作。

[15:50] **消费级 Agent 的成本、身份与软硬件结合**

[事实] Meta Muse 为每位用户提供云端虚拟机，但这种架构既面临网站屏蔽，也需要承担 Token、CPU、内存和沙箱等成本。

[事实] 节目估算，Meta Muse 提供的一亿免费 Token 对应的成本约为每位用户每周 100 美元；嘉宾还分享了大规模 Rollout 时 CPU 成本接近 GPU 成本的经历。

[事实] 云端 Agent 难以证明自己代表某个真实用户，商家也会担心多个 Agent 持续比价、刷取流量并夺走原有入口。

[推测] 消费级 Agent 最终可能落到软硬件结合：由用户拥有的设备确认身份，在本地生成大部分 Token，只将困难任务路由给前沿模型。

[24:57] **企业采用分化与 AI for Science 的算力消耗**

[事实] 嘉宾认为，GrokBot 目前更多被用于尝鲜；传统法律、医疗和大型企业仍受制于软件权限与合规体系，甚至尚未自由采用更成熟的编程 Agent。

[事实] 行业采用存在明显分层：前沿用户可以尝试各种模型和工具，较保守的企业仍停留在基础 Copilot 阶段。

[事实] 节目援引估算称，OpenAI 使用大量 Agent 处理纳维—斯托克斯方程问题时，发送约 270 万条信息并产生约 1300 亿输出 Token，按零售价估算成本约 2200 万美元。

[推测] 前沿模型公司竞争的重点可能逐渐从普通消费任务转向 AI for Science，因为重大科学突破潜在价值更高，也更能消耗和体现模型能力。

[28:43] **AI for Science 与机器人的能力跃迁并不相同**

[事实] Astra 在生物医学中的提升主要来自编程和长程任务能力，而非生物医学知识本身；部分专门测试知识的基准并未显示明显提升。

[事实] 前沿模型对生物医学内容的安全限制越来越严格，实际使用中经常拒答，因此团队有时会改用限制较少的模型。

[事实] 现有生物医学基准往往把问题简化为数据集上的预测任务，与真实药物发现存在较大差距。

[事实] 在机器人领域，Astra 被认为带来了定性变化，并在多个仿真基准中领先；此前多次模型升级则未能让原本做不到的机器人任务变得可行。

[30:58] **机器人需要快慢模型分层**

[事实] 机器人需要及时响应，高动态任务无法等待大型模型进行冗长推理，因此长期仍需要具备类似能力的小模型。

[事实] 传统分层由大模型负责“打开冰箱、取出食材”等任务规划，小模型负责具体动作；Astra 已能进一步给出“向右移动两厘米”等低层控制指令。

[事实] Astra 无法无限向下取代控制模型，因为它速度慢、推理链长，而且对液体溢出、玻璃破碎等直觉物理缺乏即时理解。

[事实] 嘉宾认为，本地机器人模型小于 10B 较为舒适；准静态任务可以接受数百毫秒的云端延迟，高动态任务则必须在本地完成。

[35:49] **Astra 的机器人能力边界**

[事实] 专用机器人模型动作更快，会连续尝试并根据状态变化调整；Astra 每一步都要分析成败原因，因此更像人类思考，但也更缓慢。

[事实] 如果 Astra 对失败原因分析错误，可能陷入僵局；它在抓取后旋转物体、对准孔位等操作上仍有明显短板。

[事实] Astra 让从真实场景生成三维仿真变得更容易，但没有同步提升物理引擎的准确性，因此 Real-to-Sim 的视觉进步不等于机器人策略必然进步。

[事实] 对本体厂商而言，Astra 降低了部分智能能力的接入门槛；对“大脑”公司而言，一部分会继续训练更快的专用模型，另一部分可能转向部署和工具集成。

[39:11] **训练范式与机器人数据标注的变化**

[事实] Astra 可能推动机器人研究从传统规划转向 Agentic 系统，即把规划、控制和各种工具能力组合起来处理长程任务。

[事实] 嘉宾认为，机器人数据应详细标注成功与失败的因果关系、交互过程和直觉物理，而不只是用一句话描述完成了什么动作。

[事实] 数据公司可能分成两类：一类大规模出售未经标注的原始数据，另一类理解前沿模型训练方法并提供高价值的精细标注数据。

[推测] 精细标注的价值将取决于数据公司能否从有限交易信息中推断前沿实验室的训练偏好，而模型公司可能继续把关键标注方法视为机密。

[43:11] **从惊艳演示到重新认识局限**

[事实] 早期测试中，Astra 能快速完成抓取等任务，引发“机器人 GPT 时刻”的判断；随着任务复杂度增加，其问题逐渐显现。

[事实] Astra 几乎无法完成双臂叠衣服等任务，在难以用语言清楚描述的灵巧操作中表现较弱。

[事实] 它首次执行任务后可能有所提速，但继续重复时效率不再明显提升，未能像人或专用模型一样把熟练任务压缩到数秒完成。

[事实] 嘉宾因此把下一阶段问题定义为：如何组合 Astra 式慢思考与机器人原生快模型，并设计双方之间有效的调用与指令接口。

[45:13] **系统一模型 Jeff 的启示与限制**

[事实] Jeff 将自己定位为系统一模型，只对选项输出概率，理念上接近机器人需要的快速决策模型。

[事实] 测试显示 Jeff 在机器人任务上表现较差，因为它不能直接输入图像，需要其他视觉模型先把画面转化为状态信息。

[事实] Jeff 在堆叠方块时缺乏根据倾斜状态反向补偿的能力，而 Astra 能通过视觉和推理尝试维持平衡。

[推测] 快速模型若要真正适用于机器人，需要同时具备多模态输入、物理状态理解和低延迟决策，而不能只追求推理速度。

[47:13] **AI 制药的核心不是预测，而是实验闭环**

[事实] 嘉宾认为 Astra 在 AI for Science 中相对更强，主要优势是长程任务能力，但现有基准无法充分衡量真实生物医学工作。

[事实] 真正重要的任务是让模型提出可执行的实验方案，包括温度、湿度、分子、储存方式和给药周期，而不仅是预测蛋白质活性或生成分子式。

[事实] 节目将这种能力称为“Human Use”：由 AI 给实验人员或技术员生成指令，让人类在真实世界中完成实验。

[事实] 嘉宾估计，现阶段模型在实验设计上的完成度约为 30%，仍需熟悉具体方向、设备和材料的专家大量修改。

[51:39] **湿实验、验证周期与产业瓶颈**

[事实] 严肃的 AI 制药公司仍需拥有或接入实验室，以验证模型预测并积累自己的实验数据。

[事实] 细胞和小鼠实验通常需要数周，灵长类实验一次约需四个月，有时需要重复两轮；AI 制药公司完成动物实验后，常将项目授权给大型药企推进人体试验。

[事实] 从候选设计推进到灵长类验证，周期可能为 6 至 12 个月，而完整药物研发通常需要 5 至 10 年。

[事实] 数学问题可以快速验证，生物医学却受真实世界反馈速度限制；即使 AI 将分子设计从半年缩短到数小时，后续动物和人体实验仍是瓶颈。

[推测] AI 制药的突破速度最终取决于能否改造实验流程，使湿实验从项目末端的验证环节变成与模型共同设计、持续反馈的闭环。

[56:11] **开源模型之后，专有数据成为壁垒**

[事实] 蛋白质结构预测工具的开源降低了底层技术门槛，并促使行业更重视专有实验数据。

[事实] 一条关于某个分子能否在动物体内杀死癌细胞的数据，可能价值数万至数十万美元，因为实验成本高、周期长，且通常不会出现在互联网训练语料中。

[事实] 嘉宾看好专门提供真实生物实验数据和实验接口的公司，并提到实验服务可以通过 MCP 或 API 直接接入大模型。

[事实] 前沿实验室若希望做真正的高价值科学发现，而非只刷新基准成绩，就不可避免地需要自有实验室或稳定的湿实验合作方。

[61:01] **科学家的角色从解题转向定义问题**

[事实] 当前生物医学 AI 的进步仍主要来自通用编程能力；部分明确的问题上，模型已经能比专业科学家完成得更好。

[事实] 生物医学数据体量巨大，单个人的数据可能达到两个 TB，高效处理和理解这类复杂数据仍是重要机会。

[事实] 当问题具有明确输入、测试集和目标时，AI 的解题能力可能超过人类；科学家未来更重要的工作是定义值得解决的问题、设计研究方法并判断投入价值。

[事实] 在药物与医疗等高风险领域，即使 AI 能自动提出答案，重大决策仍需要科学家或医生负责验证与背书。

[64:01] **新型基准、数据飞轮与优先突破方向**

[事实] 嘉宾主张建立没有固定上限的生物医学任务，例如不断提高药物杀伤癌细胞的效果，而不是容易被刷满的分类题。

[事实] 持续执行真实实验可以形成数据飞轮，让模型围绕特定科学目标不断改进。

[事实] AI 尚未独立完成一款被充分验证并广泛使用的药物，主要原因之一是现代 AI 出现时间短于完整药物研发周期。

[事实] 模型进展与实验反馈周期高度相关，因此蛋白质和酶等可快速实验的方向更可能率先突破；衰老、罕见病等数据稀少且周期漫长的方向进展会较慢。

[68:01] **人与 AI 的双向“蒸馏”**

[事实] 机器人领域仍需要大量普通人的生活技能数据，因为当前机器人尚未达到普通人的操作水平，做饭、叠衣服、行走和跳舞等行为都具有训练价值。

[事实] 在科学领域，AI 的知识面可能超过单个科学家，但长期投入、问题定义和价值判断仍需要人类参与。

[事实] 科学家也可以反向向 AI 学习，在交叉学科中快速获取知识并形成新想法，因此双方是相互学习的关系。

[事实] 现阶段模型更像记忆了大量知识并针对场景优化，距离像人一样从零开始学习、在短时间内自主成长为领域专家仍很远。

[71:51] **三个领域最关注的下一步**

[事实] 模型公司的关注点是内存、显存与电力成本，希望让个人和企业在本地运行较小模型，解决日常生活与企业工作中大部分问题。

[事实] 嘉宾区分了模型的“高度”与“广度”：AI for Science 需要能力上限很高的模型，而日常工作更需要覆盖面广、成本较低的模型。

[事实] 机器人领域最关注低样本泛化与快速部署，希望从依赖多名博士长期驻场调试，转向普通人也能完成部署的通用机器人。

[推测] 嘉宾预测 2028 年初通用机器人将开始真正实用，届时用户可能通过自然语言让机器人完成家庭中大部分事务；这一时间判断在节目中也被主持人称为相当激进。

[75:45] **AI 进入真实世界的最终挑战**

[事实] AI for Science 的关键是理解并调动现实世界资源，包括预算、设备、实验周期、人员和机器人，而不仅是生成理论方案。

[事实] 未来的任务可能从“设计一种抗癌药”变为“在十万美元预算和既有实验条件下设计并验证一种药物”，要求模型规划复杂的真实世界流程。

[事实] 交互范式可能从人类编写 Prompt 指挥 AI，转为 AI 生成清晰、无歧义且可执行的指令，调度人类和机器人完成实验。

[事实] 实验设备也可能为 AI 重新设计，例如直接向模型提供底层波形或信号，而不必先生成供人类医生观看的图像。

[18:06] **结语：能力曲线与落地周期**

[事实] 主持人补充指出，AI 圈对模型发现潜在新型基因编辑机制感到兴奋，生物圈则更倾向于等待实验室验证结果。

[事实] 机器人需要在物理世界反复尝试，制药需要等待动物代谢和实验周期，Agent 则必须通过商家与用户的接受考验。

[事实] 节目将这种认知差异概括为：AI 圈看到的是模型能力曲线，产业从业者看到的是验证成本和落地周期。

## 播客点评/总结

本期最有价值的部分，是把 Agent、机器人和 AI 制药三个看似不同的领域放在同一条逻辑链上：模型能力已经快速前进，但能否进入真实世界，取决于身份、成本、延迟、物理反馈和实验验证。它没有把演示效果直接等同于产业成熟度，而是持续追问“下一步由谁验证、要花多久、成本由谁承担”。

机器人部分提供了较细致的技术边界：Astra 的重要性不只是成绩提升，而是让大模型开始介入低层动作控制；与此同时，速度、直觉物理和灵巧操作仍要求专用快模型存在。AI 制药部分则清楚区分了计算机内的预测与真实实验，指出湿实验反馈速度才是决定产业节奏的核心变量。

本期的局限是大量公司名、模型名、价格和融资信息来自口头讨论，部分表述带有传闻、个人估算或转录误差，不能直接视为经过独立核实的行业数据。关于 2028 年通用机器人实用化等判断，也属于嘉宾预测而非既定事实。

[推测] 这期节目适合关注 Agent 商业化、具身智能、AI for Science、AI 制药及模型基础设施的从业者。对于希望理解“为什么模型演示已经惊艳，产业落地仍然缓慢”的听众，它提供了一套较完整的分析框架。
