# Anthropic 上市前夜：两万亿美元估值、大模型生意与投资风险

## 概览

本期围绕 Anthropic 招股书展开，讨论这家成立约五年的大模型公司为何选择此时上市，以及惊人的收入增长、约两万亿美元估值和巨额算力投入能否持续。嘉宾认为，抢先上市不只是为了融资，也是在争夺大模型赛道的定价权、声誉和长期融资渠道。

讨论同时揭示了大模型生意的矛盾：企业对 AI 的真实用量快速增长，但前沿模型迭代极快，旧产品可能在数月内失去竞争力。Anthropic 具有人才、算力、工作流和 Coding 市场优势，却需要持续投入并承受技术领先地位随时变化的风险。

嘉宾进一步将大模型公司理解为各行业的底层基础设施乃至商业共创者，其收入模式可能从 API 调用延伸至医药研发、企业服务和按成果分成。中国开源模型则可能凭借成本和本地部署占据大量常规任务，但其估值仍取决于能否缩小与前沿模型的能力差距、创造可验证的商业价值。

投资层面，嘉宾长期看好大模型赛道的配置价值，但强调上市初期的市场情绪、估值和价格波动同样重要；长期值得配置不代表任何价格都值得立即买入。

## 分段落总结

[00:58] **招股书揭示的大模型生意**

[事实] 主持人称 Anthropic 公布招股书，市场给出的上市估值约为两万亿美元。

[事实] 节目引用的数据称，公司上半年收入接近 163 亿美元，约为去年同期的 14 倍。

[事实] 本期重点追问高速增长能持续多久、模型能力能否形成长期商业优势，以及当前估值是否合理。

[02:51] **为何抢先上市**

[事实] 嘉宾认为，Anthropic 在 AI Coding 领域已经处于领先位置，不能简单视为 OpenAI 之后的行业老二。

[事实] 同赛道率先上市的公司通常更有机会定义市场故事、估值标准和投资者比较框架，后上市者可能面临折价压力。

[事实] 嘉宾表示，公司并不缺少现金，此次上市更可能是为了抢占估值高地、取得上市公司身份并拓宽股权及债务融资渠道。

[推测] 在 OpenAI 等竞争者继续融资和抬高估值基准的情况下，Anthropic 选择尽早上市带有明显的战略抢跑意味。

[08:32] **大模型是超级重资产行业**

[事实] 嘉宾将大模型形容为大型制造业：无论资产放在哪家公司的报表上，社会层面都需要承担数据中心、芯片和能源等巨额投入。

[事实] Anthropic 同时依赖多家云服务商，而其中部分合作伙伴也拥有自己的竞品，形成股东、渠道、算力供应方和竞争者交织的生态。

[推测] 为避免受制于单一云平台，领先模型公司最终可能亲自参与更多重资产建设，以掌握关键算力资源。

[09:45] **两万亿美元估值与稀缺性溢价**

[事实] 嘉宾以收入预期和市销率讨论估值，认为一万五千亿至两万亿美元的定价需要非常激进的未来收入增长作为支撑。

[事实] 节目认为 Anthropic 上市后可能迅速被指数和 ETF 纳入，长期基金及被动资金因缺少纯粹的大模型上市标的而产生配置需求。

[推测] 稀缺性和被动买盘可以支撑上市初期估值，但不能替代收入兑现和技术领先这两个长期条件。

[15:42] **“海鲜业”：模型快速折价的残酷竞争**

[事实] 招股书被引用称，Anthropic 约 80%的收入来自过去六个月发布的模型，意味着旧模型的商业价值衰减很快。

[事实] 嘉宾将大模型行业比作“海鲜业”：产品发布后便不断折价，公司必须持续推出更强模型。

[事实] Anthropic 的有利条件包括人才持续流入、充足算力以及参与大量真实工作流，但嘉宾仍无法确认其领先地位能否长期保持。

[推测] 模型寿命过短可能只是行业高速迭代阶段的现象；若未来能力提升速度放缓，不同代际模型或可像不同制程芯片一样长期共存。

[19:01] **技术王座与资本市场的马太效应**

[事实] 嘉宾指出，率先上市不会自动改变一家公司的竞争地位，但领先者可以利用资本和影响力进一步强化优势。

[事实] 节目引用研究结论称，美股长期创造的财富高度集中于极少数公司，并以微软、谷歌和亚马逊等老牌科技企业为例说明“新王”并不容易出现。

[推测] 大模型所需的巨额资本可能进一步强化集中度，使缺乏百亿乃至千亿美元资源的公司难以上牌桌。

[21:43] **客户用量爆发与真实需求**

[事实] 节目称 Anthropic 的净收入留存相关指标达到约 900%，主要来自既有客户 Token 用量大幅增加，而非单纯增加订阅功能。

[事实] Anthropic 的主要收入来自 API 调用，客户由试用转向正式、大规模使用时，会产生非常高的同比增长。

[事实] 嘉宾认为，数据中心建设或芯片囤积可能存在局部泡沫，但客户从尝试转向高频使用说明 AI 的终端需求确实在爆发。

[推测] 当前惊人的增长率受到低基数影响，未来更应关注高用量能否持续，而不能仅依据单一百分比判断公司质量。

[24:33] **从模型供应商到商业共创者**

[事实] 嘉宾修正了自己对大模型公司的理解，认为其角色可能从出售模型转向与各行业共同解决问题，并分享由此产生的商业收益。

[事实] 节目列举了医药研发、罕见病药物、金融及投行工作等场景，说明大模型可能直接参与产品研发和业务流程，而不只是提供 API。

[事实] Anthropic 和 OpenAI 被认为正在探索按成果付费、行业解决方案及更深层企业合作，以减少 API 产品快速商品化带来的压力。

[推测] 如果模型公司能够直接创造可量化的产业成果，其价值上限可能远高于传统软件或云服务供应商。

[29:17] **下一个 Coding 仍可能是 Coding**

[事实] 嘉宾认为 Coding 不应只理解为程序员写代码，而应涵盖数字世界中由代码构造的聊天机器人、视频、自动化流程和各种产品。

[事实] 因此，AI Coding 的市场上限不应只与程序员工资比较，而应与更广泛的白领成本及企业研发支出比较。

[推测] Coding 本身仍有大量未开发空间，所谓“下一个大场景”可能只是 Coding 向普通用户和更多行业工作流的扩张。

[30:45] **AI 投入超过人力与人均产出差距**

[事实] 节目称，按官方价格计算，Anthropic 内部模型调用支出一度超过员工现金薪酬支出。

[事实] 嘉宾计算 Anthropic 人均年创收约为 600 多万美元，而 MiniMax 和智谱约为 40 万及30万美元，差距达到十倍以上。

[事实] 节目还称，Anthropic 前五大客户之外的收入占比由第一季度的64%升至第三季度的79%，客户集中度有所下降。

[推测] 企业预算可能逐渐从人力转向 AI，但由此带来的就业和社会影响仍有待观察。

[33:02] **巨额账面亏损的会计解释**

[事实] 节目指出，Anthropic 上半年超过 800 亿美元的净亏损中，700 多亿美元属于非现金项目，主要来自公允价值调整及股权激励相关会计处理。

[事实] 嘉宾强调，这类账面亏损与主营业务经营亏损并非同一概念，不能只凭标题判断公司烧钱程度。

[推测] 评估大模型公司的经营质量时，现金流、算力投入产出比和剔除非现金项目后的表现，比表面净利润数字更有参考价值。

[34:35] **云渠道合作的收益与风险**

[事实] 节目称 Anthropic 有48%的收入来自各类云平台合作伙伴。

[事实] 嘉宾认为，早期依靠多家云厂商分销并不等于财务造假或资金循环，而是利用合作伙伴渠道拓展市场的正常方式。

[事实] 美国大型科技企业的投资、云服务和模型业务通常由不同部门决策，因此同一家公司可以同时成为股东、供应商、客户和竞争者。

[推测] 多元合作能够降低对单一渠道的依赖，但渠道占比较高仍意味着公司需要逐步增强直接触达客户的能力。

[36:41] **真正的经营风险：需求与算力期限错配**

[事实] 节目回顾称，Anthropic 在2023年收入仅四千多万美元，而研发费用超过四亿美元；到2026年上半年，训练和研发成本约占收入的59.8%。

[事实] 公司未来十年拥有约8000亿美元的资本投入承诺，而客户合同并不一定具有同样长的期限。

[事实] 节目称，2026年第一季度前后，每一元算力投入带来的收入达到一元；第二季度进一步达到约两元。

[推测] 最大风险并非 AI 需求完全消失，而是需求增速低于市场的极高预期，导致长期算力承诺难以消化并触发估值修正。

[43:00] **如何评价中国大模型公司**

[事实] 节目称 MiniMax 和智谱收入均有快速增长，但绝对规模、人均创收和增速仍与 Anthropic 存在明显差距。

[事实] 嘉宾认为行业仍处于渗透率从零向10%提升的早期阶段，此时单看同比增速意义有限。

[事实] 评价大模型公司更重要的指标包括现金流何时转正、转正能否持续，以及一元算力投入能否至少带来一元收入。

[推测] 中国一级市场资金规模不足，使部分尚处早期阶段的公司更早进入港股市场，导致公开市场承担了类似美国中后期风险投资的功能。

[47:51] **中国开源模型的机会与压力**

[事实] 嘉宾指出，中国市场的个人和企业付费意愿相对较弱，而低成本追赶前沿模型的能力曾是中国模型公司获得高估值的重要依据。

[事实] 节目称，Anthropic 估计约5%至7%的收入来自违反使用规则的用户；嘉宾将其解释为可能涉及模型蒸馏，并认为相关限制正在加强。

[事实] 中国开源模型已经被部分海外企业用于客服、销售、图像和视频等成熟任务，复杂研发工作则仍可能采用最前沿的闭源模型。

[推测] 企业可能形成分层用模模式：普通任务使用便宜的开源模型，高价值及高难度任务使用能力最强的前沿模型。

[52:27] **开源模型估值从哪里来**

[事实] 嘉宾提出，中国开源模型的估值可能来自性价比、广泛使用或解决实际商业问题的能力。

[事实] 闭源领先厂商也在进入金融、医疗、法务和咨询等垂直领域，并提供可复用工具和完整解决方案。

[推测] 如果闭源模型能够以更高成本创造更大的商业收益，开源厂商仅靠低价将难以取得同等估值，必须证明自身的技术追赶或落地价值。

[推测] 中国模型的技术进展可能呈波浪式变化，短期差距会扩大或缩小；本地部署、端侧设备和基础任务仍可能形成稳定市场。

[57:46] **上市后是否值得配置**

[事实] 嘉宾认为，是否在上市时立即买入，需要结合发行估值、市场情绪、盘前交易和当时的整体市场环境判断。

[事实] 长期来看，两位嘉宾都倾向于配置 Anthropic，理由包括其赛道代表性以及未来可能被主要指数纳入。

[事实] 对短期交易而言，若上市情绪过于亢奋，其中一位嘉宾会选择等待；另一位则相对更乐观，认为关键是超配或低配，而非完全不持有。

[推测] Anthropic 兼具稀缺性和高度不确定性，上市后可能出现剧烈波动，因此长期产业判断与短期买入价格必须分开考虑。

## 播客点评/总结

本期的价值在于没有把 Anthropic 简化成“高增长神话”或“巨额亏损泡沫”，而是从上市策略、会计口径、算力投入、客户结构、渠道生态及模型迭代速度等多个角度拆解大模型公司的经济模型。尤其是“海鲜业”比喻和算力投入产出比，为理解这个新行业提供了直观框架。

讨论的另一个亮点，是把 Coding 从程序员工具扩展到整个数字生产体系，并进一步探讨模型公司成为行业共创者的可能性。这种视角解释了大模型公司的潜在市场为何极大，也说明单纯以传统 SaaS 或基础设施公司的估值方式衡量它们可能并不充分。

局限在于，节目大量讨论依赖招股书数据及嘉宾预测，部分公司名称、数字和专有名词在转录中存在识别误差；对于未来收入、技术领先、指数纳入和企业预算转移的判断也具有明显不确定性。[推测] 因而本期更适合作为理解大模型商业模式和投资框架的材料，而不是直接的投资结论。

[推测] 本期适合关注 AI 产业、科技股、一级与二级市场以及中美大模型竞争的听众，尤其适合希望理解“技术领先如何转化为收入、现金流与估值”的投资者和从业者。
