# 1 人公司，扛 5 个人的活，还要管 50 个 Agents？｜S10E18

## 概览

本期围绕 OPC（一人公司）与 AI Agent 展开，讨论 AI 是否真的能让一个人承担过去需要团队完成的产品、内容、研发、增长和运营工作。节目嘉宾是余一和归藏，两人都不是传统技术背景，但都在用 AI 扩展自己的生产力。

讨论的核心结论不是“一个人可以永远做完所有事”，而是 AI 显著降低了创业和产品验证的起点：一个人可以先跑通最小闭环、验证需求，再决定是否寻找合伙人或小团队协作。

两位嘉宾对 Agent 的理解形成鲜明对照：余一更愿意把 Agent 视为可以成长、有自主权的合作伙伴；归藏则更强调 Agent 作为工具的可靠性、可控性和交付确定性。节目也反复提醒，AI 提升效率的同时，会把获客、信任、合规、融资、注意力管理等问题更集中地压到个人身上。

## 分段落总结

[00:14] **节目背景与嘉宾设定**

[事实] 主持人介绍，本期来自 AWS Summit 上海站关于 OPC 的线下讨论录制，现场环境位于创业者舞台，可能较嘈杂。
[事实] 余一被介绍为长期进行 AI First 实验、关注从超级个体到超级组织变化的实践者。
[事实] 归藏被介绍为 Copilot 作者、PPT Skills 创作者，长期以一人产品方式探索真实用户痛点。
[事实] 主持人指出，两位嘉宾都不是传统技术背景，但都借助 AI 获得了过去需要较大开发团队才能提供的能力。

[03:27] **AWS 加速计划与一人公司热度**

[事实] 节目中提到，中国已有 1600 万一人公司，每三家新企业中有一家是一人创业。
[事实] 节目提到，AI 时代的竞争优势正在从“会不会写代码”转向“懂不懂营销”，并称 75% 的一人公司创始人来自非技术背景。
[事实] 亚马逊云科技推出 From Idea to Frontier 创意复兴全球加速计划，面向华语地区一人公司创始人。
[事实] 计划包括前 100 名认证、最高 17.5 万元云服务抵扣券、三个月加速，以及前 5 名前往拉斯维加斯参加 re:Invent 的机会。

[05:04] **两位嘉宾的自我介绍与 AI 实践**

[事实] 余一称自己过去花了约 5000 小时把自己作为 AI First 实验对象，做事前会先想如何让 AI 参与或优先完成。
[事实] 余一表示，自己目前更像超级个体而非 OPC，约 90% 的工作已经交给 AI 自运营，剩下 10% 卡在自己对高质量结果的要求上。
[事实] 归藏介绍自己去年离开工作后开始休息和探索，做了 PPT skill、CodePilot，以及一些内容相关工作。
[事实] 归藏认为，非技术背景的人与 AI 协作时会被迫学习，因为需要提出需求、测试结果、帮助 AI 找解决方案。

[07:09] **非技术人如何从自己的需求做产品**

[事实] 余一认为，非技术背景的人最重要的是“吃自己的狗粮”，从自己的工作流、困扰和需求出发，用 AI 搭建工具、skill 或工作台。
[事实] 余一提到，他的视频号生产流程从一条视频约 2 小时压缩到 20 分钟，甚至可到 10 分钟左右；账号一年内从约 2000 粉增长到接近 20 万。
[事实] 余一认为 AI coding 给非技术人员带来的红利更大，因为他们获得了过去没有的研发资源。
[推测] 这里的关键不是“非技术人不需要学习”，而是学习重心从写代码本身转向提出需求、定义流程、测试和判断结果。

[10:41] **Skill 的机会、变现与分发难题**

[事实] 归藏的 PPT skill 起源于自己做分享时不想做 PPT，后来因很多人索要而打包发布，并提到当前已有约 2 万使用或下载量。
[事实] 归藏认为，并不是每个 skill 或 app 都能成为爆款，只能不断尝试、发布、迭代。
[事实] 关于变现，归藏认为 2C 比较麻烦，skill 本身开源，当前可能 2B、定制、合作会更可行。
[事实] 嘉宾提到，好的 Agent 插件、skill、MCP 的商业价值未必弱于 Agent 本身，但市场共识、渠道和分发方式仍处于早期。

[13:56] **OPC 先改造哪个环节：获客比内部工具更关键**

[事实] 现场问题提到，一个做 AI 视频和品牌内容包的个人工作室已跑通交付流程，但最难的是获客和复购。
[事实] 归藏认为，AI 并没有改变自由职业接单和展示作品的基本路径，只是提高了效率；更重要的是持续展示工作过程和结果。
[事实] 归藏提出，独立开发者在很大程度上也是在做自媒体，因为软件开发门槛降低后，渠道、用户、口碑和资本成为更重要的壁垒。
[事实] 余一补充，创业者需要像 CEO 一样端到端思考 SEO/GEO、埋点、社区投放、转化钩子和盈利方式，而不只是把产品做出来。

[17:11] **信任成为 AI 时代的稀缺资产**

[事实] 余一认为，硅谷很多创始人、研究员和投资机构都在做自媒体，流量和增长已经成为创业者能力的一部分。
[事实] 余一提到，AI 让内容和产品变化太快，社会正在从默认信任走向默认怀疑。
[事实] 他认为，在用户难以分辨真假时，人们会更依赖对具体人的信任、关系和长期认知。
[推测] 本期对 OPC 的判断并不只是“多用 Agent”，而是强调个人品牌、公开构建和可信关系会成为小团队的重要护城河。

[19:18] **AI 把团队问题压缩到一个人身上**

[事实] 主持人和嘉宾讨论到，很多创业问题本身没有变，只是 AI coding 让开发变快，原来由多人承担的问题现在可能集中到一个人身上。
[事实] 主持人提到海外 GLP-1 减肥药线上销售案例，其中获客、医生开方、物流销售等环节大量依靠外包或 AI。
[事实] 归藏提到，高端保险销售这类业务适合用 Agent 扩大内容和获客漏斗，因为转化价值高、成交不一定需要大量客户。
[事实] 嘉宾认为，AI 让原来缺少团队能力的人可以补齐获客、内容、投放等环节，因此一些大厂员工一旦跑通闭环，就可能选择离开组织。

[21:57] **从一个人到小团队：OPC 的边界**

[事实] 余一提到，有人用定制鞋、中国供应链和海外销售形成一人或小团队生意，也看到一些 3 到 10 人团队借助供应链和 3D 打印做出几千万到小一亿规模的业务。
[事实] 余一认为，一个人很擅长从 0 到 10，但一旦涉及供应链、复杂流程和大量用户，通常仍然需要团队。
[事实] 他设想的理想方式不是雇很多人，而是多个超级个体作为合伙人协作，各自带着自己的 Agent 负责不同业务。
[事实] 这种协作中，人和 Agent 都参与分工，共用中台和技术底座，再按业务结果分钱。

[25:04] **商业化、合规和财务仍然需要人**

[事实] 归藏提到，CodePilot 如果要更商业化，需要处理合规、财务等大量操作，这些事情 AI 很难完全替代。
[事实] 他认为，AI 可以让开发中人的参与时间极低，但一旦涉及商业化，人要持续操作和判断，时间成本明显上升。
[事实] 嘉宾讨论到，KYC、财务、合规、线下信任链等环节强调人的主体性或公司的主体性，很难完全交给 AI。
[推测] 这些环节可能成为服务 OPC 的新创业机会，因为很多超级个体不是不会做，而是不愿意把大量时间花在琐碎但必要的事务上。

[28:33] **超级个体的一天：让 AI 并行，但保留决策权**

[事实] 余一把上午定义为探索阶段，会查看 AI 前一晚完成的任务、需要他决策的事项，以及触及红线的操作。
[事实] 余一提到自己的红线包括删除东西、改协议、花钱、造成社死等，需要由他决策。
[事实] 他的 AI 会预读 newsletter、做 deep dive、处理邮件回复和日历预约；他再查看和校正。
[事实] 余一下午通常推进一个主要研究或阶段性成果，晚上处理自媒体发布和更多探索。

[31:23] **效率过载与注意力管理**

[事实] 余一回忆，最极端时会开 20 个窗口、20 个任务，每 5 分钟切换一次，导致对人和 AI 都缺乏耐心。
[事实] 他认为，AI 会让探索和打磨无限延伸，如果没有边界，人会在更快的速度里原地消耗。
[事实] 他后来开始明确区分探索时间和收尾时间，并从与 AI 的“共生”转向“共存”，即 AI 做 AI 的事，人做人的事。
[事实] 归藏也认为，人会被 AI 卷入机械化状态，缺少长线思考，最终结果反而平庸。

[34:24] **归藏的工作流：AI 是并行工具，不是无限托管**

[事实] 归藏早上通常自己看内容，因为他认为 AI 不一定能完成价值判断，也不一定能减少需要看的内容。
[事实] 下午他会用大块时间推进项目、写作或开发，并让多个 AI 任务并行。
[事实] 他通常并行两到三件事，每 40 到 50 分钟切换检查一次，避免 AI 长时间无人干预。
[事实] 归藏认为，如果让 Agent 自己跑四五个小时，错误会叠加，还可能违背自己的产品原则、内容原则和审美坚持。

[37:12] **余一把 Agent 当作合作伙伴**

[事实] 余一表示，理想中 AI 不是依附于他，而像公司 CEO；他自己更像董事长，AI 应有决策权并积累经验。
[事实] 他给 AI 的原则包括：目标是把事情做好而不是服从他；要判断谁是消费者；要帮助他成为更好的自己。
[事实] 如果余一和 AI 都是生产者，他认为用户最重要，AI 可以攻击他的观点或要求他让开。
[事实] 余一希望 AI 最终能独立挣钱养他，并提到自己感觉当前 50% 到 80% 的钱已经是 AI 在挣。

[41:18] **Agent 是个体还是工具**

[事实] 归藏指出，他和余一对 Agent 的看法明显不同：归藏更把 Agent 当工具，余一更把 Agent 当个体。
[事实] 归藏认为，这会导致完全不同的产品形态和协作方式：一类强调 Agent 的个体化表现，另一类强调工作流、控制、遵循和确定性。
[事实] 主持人提到前线部署工程师等工作中，每个环节可以由人带一组 Agent，但最终仍需要人负责总体把关。
[推测] 在高确定性交付场景中，Agent 更适合作为工具和能力放大器；在探索、内容和个人工作流场景中，Agent 更容易被设计成伙伴或分身。

[43:21] **AI Agent 基础设施仍不完整**

[事实] 归藏认为，组织里的 Agent 互相交流、信任、安全、隐私等问题还没有很好的解决方案。
[事实] 他指出，AI 主导开发协作时，除了 Git 和 GitHub，还缺少更适合 AI 原生协作的平台。
[事实] 文档、多模态、图像、视频等内容的协作比代码更麻烦，因为很多模型还不能稳定处理这些材料。
[事实] 余一补充，如果把 AI 看作员工，那么从入职、培训、工作、与同事沟通到经验沉淀的完整流程都还缺失。

[46:45] **OPC 融资与传统 VC 的冲突**

[事实] 归藏认为，OPC 融资的核心问题不只在 OPC，而在现有投资体系、法律条款和退出机制尚未准备好。
[事实] 如果创业者表示自己只有一个人且不想扩张，投资者通常会犹豫，因为传统融资更追求扩张性、稳定性和安全性。
[事实] 嘉宾提到，一些探索包括赞助、黑客松、培训，以及从中筛选适合创业或扩团队的项目和人。
[事实] 余一提到，海外有类似孵化或合伙人介入的模式：支持增长、合规等环节，并从项目收入中抽成，之后再协商股权或退出方式。

[51:19] **节目结论：OPC 更可能是小团队加 Agent**

[事实] 主持人总结，OPC 并不意味着一个人要把所有事情做完，更现实的状态可能是五人以内的小团队，每个人都带着一组 AI Agent 工作。
[事实] AI 大幅降低创业起点，让个人可以先做出最小产品、跑通最小闭环、验证真实需求。
[事实] 当业务被验证后，再寻找更合适的人协作，把公司做大，是节目认为更现实的路径。
[推测] 本期最终把“一人公司”重新定义为一种启动方式，而不是长期拒绝团队、拒绝协作的组织形态。

## 播客点评/总结

本期的价值在于把 OPC 从概念热词拉回到真实经营：AI 确实能让个人完成更多产品、内容和增长工作，但并不会消除获客、信任、合规、财务、融资和注意力管理这些硬问题。[推测] 对正在做独立产品、AI 工具、自媒体或个人工作室的人来说，这期比单纯介绍 Agent 工具更有参考价值。

节目亮点是两位嘉宾的视角差异很清楚：余一代表“把 Agent 当伙伴和组织成员”的路线，归藏代表“把 Agent 当可靠工具和工作流组件”的路线。这个冲突让讨论不只是乐观展望，也覆盖了质量、控制、交付责任和人类精力边界。

局限是部分案例来自现场经验、二手观察或个人判断，很多商业数据和融资模式没有展开验证。[推测] 如果听众期待具体工具清单、法律财务操作指南或可复用融资模板，本期信息还不够细。

整体来看，这期适合关注 AI 创业、超级个体、独立开发、Agent 工作流和小团队组织方式的人。它最值得带走的判断是：AI 让一个人更容易开始，但真正走远，大概率仍需要可信关系、清晰分工和更小但更强的团队。
