# AI 变革下的十个 Aha Moments：从持续学习、学术体系到创业与个人智能体

## 概览

本期播客邀请 New York Cognition 联合创始人谷雨，以十个年度 Aha Moments 回顾 AI 在模型研发、Computer Use、数学推理、持续学习、视频生成和个人智能体等方向上的快速进展。贯穿讨论的一条主线是：模型能力的扩展屡次突破原有预期，许多曾被认为必须依靠复杂工程或专门算法解决的问题，正在被更强的基础模型直接化解。

讨论进一步延伸到 AI 对学术评价、职业价值和创业环境的影响。谷雨认为，传统论文投稿与审稿体系正在失去有效性，AI 人才和资源也在向前沿实验室及创业公司流动；与此同时，人类智力的稀缺性可能下降，审美、方向判断和情绪价值的重要性则可能上升。

作为从学术团队转向创业公司的亲历者，谷雨还反思了技术自洽与商业闭环的差异：研究团队擅长发现本质问题，但公司必须把技术映射到真实需求、产品形态和商业价值，并在产品成熟度、发布节奏与市场反馈之间找到平衡。

## 分段落总结

[00:05] **嘉宾背景与年度 Aha Moments**

[事实] 谷雨介绍自己是 New York Cognition 的联合创始人，公司从事认知学习相关工作，团队包括 17 名全职成员和 4 名实习生。

[事实] 公司已完成总额约四千万美元的种子轮融资，并计划启动 A 轮融资。

[事实] 本期以谷雨在 2026 年经历的十个 AI Aha Moments 为线索，讨论模型、Agent、学术和创业环境的变化。

[01:21] **创业公司做 RSI 的机会被重新认识**

[事实] 谷雨此前认为，递归式自我改进（RSI）属于模型叙事，创业公司既难追赶头部模型厂，也缺少作为改进起点的自有模型，因此机会有限。

[事实] Recursive、Mirando 等团队的发布改变了他的判断；他以 Mirando 在较短时间内完成强预训练模型为例，认为小团队确实可能取得超预期结果。

[事实] 他认为 AI 研发能力增强后，模型可以更多参与训练基础设施和研究流程建设，而大模型公司长期积累的基础设施有时会因适配成本过高成为负担。

[事实] 从零开始的创业公司没有旧系统包袱，可以更快替换训练方案和基础设施，但全栈模型训练仍然需要大量资金、算力和数据。

[推测] 如果研发自动化继续增强，创业公司的核心优势可能不再是资源总量，而是组织灵活性和采用新技术的速度。

[04:36] **Computer Use 的“手”基本成熟，瓶颈转向“脑”**

[事实] 谷雨认为，Computer Use Agent 过去最突出的问题是泛化性和可靠性，而过去一年里，软件与网页操作层面的问题已接近解决。

[事实] 他将当前状态概括为“手已经基本解决”，下一步难点是认知层面：Agent 是否理解企业内部规则、业务流程和具体任务应当如何处理。

[事实] 其团队早期曾让 Agent 多次执行任务，再挑选正确轨迹并封装成可复用技能；随着模型能力增强，这套复杂流程已不再总是必要。

[事实] Computer Use 的操作能力与业务认知并非同一个问题，但数字世界中的工作最终仍需通过软件和网页操作完成。

[推测] 企业级 Agent 的竞争重点可能从点击是否准确，转向能否理解组织语境、积累经验并持续适应业务。

[06:55] **Apprentice Bench 与持续学习评估**

[事实] 团队推出 Apprentice Bench，用于评估 Agent 部署后能否在生产过程中持续学习和迭代。

[事实] 该基准以建筑行业的会计场景为背景，包含 100 个连续任务，涉及公司惯例、具体工作流和审批规则。

[事实] 与相互独立的传统测试题不同，这 100 个任务需要依次完成，Agent 必须利用前序任务中的反馈和知识处理后续任务。

[事实] 谷雨认为，真正的长程智能不是让 Agent 埋头执行一个耗时很久的任务，而是像员工一样，从新人逐渐成长为熟悉公司的老员工。

[事实] 该基准主要测试持续学习这一元能力，而非针对某家公司的会计规则，因此仅围绕题目内容“刷分”并不能真正提高模型能力。

[推测] 这一评估思路试图把 Agent 的长程能力从“单次任务持续多久”，重新定义为“能否在连续工作中形成终身学习能力”。

[11:18] **持续学习的关键与现有模型差距**

[事实] 谷雨表示，持续学习能力是区分前沿模型与非前沿模型的重要维度。

[事实] 能帮助模型更好编写 memory notes 的数据，可能对持续学习能力产生明显作用；长会话式编码产品也会自然产生具有类似性质的数据。

[事实] 他认为相关训练 recipe 仍不成熟，团队和其他模型公司都还在探索。

[事实] Apprentice Bench 未完全公开测试数据，并计划推出难度更高的新版本；届时最强模型的得分也可能明显下降。

[推测] 高质量长期交互数据以及模型整理、调用自身经验的能力，可能成为下一阶段训练竞争的重点。

[13:18] **非形式化数学推理突破原有预期**

[事实] 谷雨此前认为，高水平数学能力需要 Lean 等形式化验证系统提供可靠信号。

[事实] 后来的进展显示，当数据规模和质量提升后，模型通过非形式化方法也能达到数学竞赛金牌水平，并进一步处理一些长期未解决的问题。

[事实] 这改变了他两年前对纯语言模型数学能力上限的判断，也让他再次接受 scaling 所体现的“苦涩教训”。

[事实] 对话同时讨论了数学活动的意义：即使机器能解决问题，人仍可能因为探索过程、方法积累和智力挑战本身而继续研究数学。

[推测] 数学未来可能部分转变为类似竞技运动的活动，其价值不只来自结果，也来自人类挑战自身能力的过程。

[16:14] **Memory Notes 的能力上限被低估**

[事实] 谷雨曾公开认为，用 memory notes 实现认知学习并不可靠，因为它不是稳定的优化算法。

[事实] 随着模型能力增强，他发现这种方法仍能通过扩展和继续训练取得效果，其能力上限高于此前判断。

[事实] 他认为 memory notes 的效果曾受模型自身能力限制；模型越强，生成和利用记忆的质量也可能越高。

[事实] 按其观察，目前在这方面真正表现较强的主要是 Anthropic 和 OpenAI，其他团队的效果仍有明显差距。

[推测] 外部记忆未必取代参数学习，但可能成为强模型实现持续学习和个性化的重要工程路径。

[18:13] **AI 学术投稿与评价体系面临失效**

[事实] 谷雨认为，AI 研究的会议投稿和评价体系已接近临界点，大量低质量 AI 生成内容和灌水论文降低了审稿效率。

[事实] 他已一年半没有投稿，半年多没有审稿或担任领域主席，因为这些活动不再是高优先级，也难以体现对时间的尊重。

[事实] 团队招聘毕业生时，更重视候选人对自身工作的理解、研究报告中的逻辑表达、问答反应和对当前问题的判断，而不是简单统计论文数量。

[事实] 他仍认可同行评议，但认为有效评议应来自具有较高判断力和研究品位的同行，而现有审稿体系的参与门槛过低。

[事实] 对 AI 人才而言，前沿实验室和创业公司不仅报酬更高，也拥有更多资源；高校教职的吸引力因此相对下降。

[推测] 新评价机制可能更重视真实贡献、现场交流和业内信誉，但其形成速度可能落后于旧体系的失效速度。

[21:41] **人类智力价值、博士选择与个人动机**

[事实] 谷雨用夸张比喻表达一种判断：当 AI 降低脑力的稀缺性后，外貌、身体和情绪价值可能变得相对更重要。

[事实] 他将 AI 比作“数字世界的机械”：机械降低了体力的重要性，而 AI 可能进一步降低脑力劳动的重要性。

[事实] 面对是否值得读博士的问题，他不愿给出统一建议，认为每个人的追求不同，只要真正想清楚并愿意去做即可。

[事实] 他认为“想做一件事就去做”本身也是一种理性，不必为所有人生选择寻找复杂的功利解释。

[推测] 这段讨论并非否定知识或博士教育，而是在强调，当外部回报快速变化时，个人兴趣可能成为更稳定的决策依据。

[23:51] **创业选择源于自主性与风险态度**

[事实] 谷雨从未把进入大公司、获得高薪职位视为自己的默认路径，因为固定工作时间会让他感到痛苦。

[事实] 他更看重按照自身状态安排工作的灵活性，也不需要明确划分工作日与周末。

[事实] 创业让他对所做方向拥有更大决策权和 ownership，而不只是完成别人赋予的使命。

[事实] 他表示自己对风险缺乏强烈感知，做事时更在乎是否想做，而不太计算代价。

[事实] 他的父母没有对婚姻、职业或其他人生节点提出世俗要求，这为他提供了一定安全感。

[推测] 他的创业选择更多来自对生活方式和自主权的偏好，而非单纯追求财务回报。

[25:58] **从学术品位到市场闭环的创业教训**

[事实] 谷雨所在团队在学术界重视 vision、taste 和本质问题，不会先发明算法再寻找应用场景。

[事实] 转向创业后，团队却发现自己也可能成为“拿着锤子找钉子”的人，因为技术体系内部自洽并不等于商业成立。

[事实] 创业公司必须和市场共同完成闭环，明确技术解决谁的问题、以什么产品形式出现，以及能创造什么商业价值。

[事实] 团队过去对发布质量要求过高，总想等产品足够完整和扎实后再公开，但创业公司有时需要先推出不成熟版本，以更快获得市场反馈。

[事实] 谷雨借用“灭火器与砖头”的比喻说明：当用户需求足够紧迫时，简单但立即可用的方案可能先于完美产品赢得市场。

[推测] 学术团队创业的主要转型障碍，不一定是技术能力不足，而是难以降低完美主义标准并建立快速的市场反馈循环。

[29:55] **教育路径不再只有单一答案**

[事实] 对于高中毕业后直接工作、甚至不读本科的现象，谷雨认为在教育资源丰富的环境中具有一定合理性。

[事实] 他认可现行教育体系与整体国情的适配性，但认为对个体而言，部分教育过程更偏向筛选，而非训练真正有价值的能力。

[事实] 如果年轻人能较早接触有效训练和真实工作，就可能在高中阶段做出有价值的贡献。

[事实] 他同时强调，这条路径对教育资源和成长环境要求很高，不会成为普遍选择。

[推测] AI 时代可能增加非传统成长路径的可行性，但这种机会仍会受到家庭、地域和资源条件的明显制约。

[30:52] **AI 创业从非主流选择变成从众趋势**

[事实] 谷雨观察到，创业过去常被视为非主流路径，但近一年开始有人因为“周围人都在创业”而加入。

[事实] 他将这种变化主要归因于市场资金充裕，并表示国内一些新实验室获得的估值规模超出他的预期。

[事实] 他提到，公司四千万美元的种子轮在硅谷已属较大规模，而常见种子轮可能在五百万至一千万美元之间。

[事实] 他认为，让掌握前沿技术的年轻人在较低个人财务压力下获得资本尝试创新，总体上对社会有益。

[事实] 在没有回购或对赌义务时，创业者承受的主要风险往往是投入数年时间却没有结果，而非个人财务损失。

[推测] 资本充裕会扩大创新试验数量，但创业成为潮流后，创始人的真实动机与市场纪律也会更加重要。

[32:54] **AI 视频已从技术演示迈向可消费内容**

[事实] 谷雨认为，视频生成在最近几个月达到此前未预料的高度，已经能够支持约两小时、角色和情节较为一致的电影。

[事实] 他以 B 站上的 AI 僵尸片为例，称片中多名角色的脸、服装和整体情节能够长时间保持一致，让观众沉浸观看。

[事实] 观众知道作品由 AI 创作，但弹幕主要讨论剧情，而不是反复讨论制作技术。

[事实] 两位对话者认为，用户最终更在意交付内容的质量，而不是内容由什么工具生成。

[事实] AI 还显著降低了小说、剧本和视频的创作门槛，使个人想法更容易被制作成完整作品。

[推测] 当观众不再把“由 AI 制作”当作内容的核心卖点时，生成式影视才真正进入与传统内容直接竞争的阶段。

[36:12] **AI 时代更稀缺的是审美与情绪价值**

[事实] 谷雨给出一个高度概括的判断：未来人可能最需要两种东西，一是审美，二是“美”。

[事实] 他所说的审美，是判断正确方向和前进路线的能力；“美”则更多指向情绪价值。

[事实] 对话将这一判断与剧本生产成本下降联系起来：当 AI 能高速生成内容时，单纯执行智力劳动的价格可能继续下降。

[推测] 当生产能力趋于充裕后，决定“做什么、什么值得做”的判断力，可能比完成作品本身更稀缺。

[36:32] **个人智能体的突破更多来自产品设计**

[事实] 谷雨认为，个人智能体近期兴起并不完全因为技术跨过了全新临界点，产品和交互设计同样关键。

[事实] 与按任务拆分的 session 式对话相比，个人助手更适合拥有一个长期持续的会话，使交互更接近在即时通讯工具中与固定对象交流。

[事实] 卡通或毛绒形象可以增强拟人感；主动性也不一定需要全新技术，定时检查邮件和主动推送早已可以通过计划任务实现。

[事实] 他正在尝试多个个人智能体，主要用于查看邮件、筛选重点信息并主动提醒；受国内服务平台接入限制，订外卖、酒店和机票等能力还不够实用。

[事实] 他预计，当用户真正对个人智能体形成生活依赖后，最终可能只需要一个主要助手。

[推测] 个人智能体的长期壁垒可能来自持续关系、用户记忆和服务整合，而不只是单次任务能力。

[39:03] **对下一年的预测：持续学习与 RSI 模型**

[事实] 谷雨认为，每一阶段的模型发展都有关键词：此前包括视觉语言、多模态和编码，而接下来一段时间的关键词可能是持续学习。

[事实] 他指出 AI 模型正以周为单位迭代，因此以一年为跨度进行预测已经非常困难。

[推测] 他预测下一年可能出现一家 RSI 创业公司训练出的最强或至少达到前沿水平的模型。

[推测] 持续学习可能成为下一阶段模型研究、产品能力和职业选择共同关注的方向。

## 播客点评/总结

本期的核心价值在于，嘉宾并未把 Aha Moment 简化为产品盘点，而是持续复盘自己曾经判断错误的地方：从 RSI 创业公司、Computer Use、非形式化数学推理到 memory notes，多次认知更新都指向同一结论——不能过早低估模型扩展带来的能力跃迁。

另一个亮点是将技术、学术制度与创业实践放在同一条变化链上讨论。Apprentice Bench 对“长程智能”的重新定义、学术评价体系失效的观察，以及从技术自洽走向市场闭环的反思，为 AI 研究者和技术创业者提供了较具体的思考框架。

[推测] 节目的局限在于，部分结论主要依据嘉宾个人经历、身边案例和主观观察，例如学术体系“彻底崩塌”、人类智力价值下降以及融资市场变化，缺少更广泛的数据支撑，应作为趋势判断而非确定事实理解。

[推测] 本期尤其适合关注 AI Agent、持续学习、模型训练和技术创业的研究者、产品经理与创始人，也适合正在重新考虑博士、教职、大厂或创业路径的人收听。
