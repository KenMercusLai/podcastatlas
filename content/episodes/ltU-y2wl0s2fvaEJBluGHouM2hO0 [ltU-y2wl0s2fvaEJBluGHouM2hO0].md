# Personal Agent 的演进、竞争与终局：对话蚂蚁灵光负责人蔡伟

## 概览

本期播客围绕 Personal Agent 展开，蚂蚁灵光负责人蔡伟从灵光的研发历程出发，讨论了 AI 产品如何从 Chatbot、Coding Agent 演进到能够主动管理个人事务的智能助理。他认为，Personal Agent 要真正成立，必须同时解决智能、供给与安全可信三个核心问题。

节目进一步把三代 AI 产品分别对应到信息行业、软件行业和服务行业。Personal Agent 的潜在价值不只是增加一个应用入口，而是借助模型重组服务供给，逐步介入个人生活中的计划、提醒、决策和执行，长期甚至可能连接智能硬件与机器人。

在产品与产业层面，讨论涉及主动性与边界感、记忆与个性化、模型和应用的协同、生态开放、商业模式及竞争壁垒。蔡伟判断，短期竞争主要取决于智能水平，中长期则更依赖供给生态和安全能力；补贴可以帮助获客和教育市场，却无法代替持续的产品价值。

## 分段落总结

[00:00] **节目主题与核心判断**

[事实] 本期嘉宾是蚂蚁灵光负责人蔡伟，讨论范围包括全球 Personal Agent 的产品进展、模型演进、市场格局和潜在补贴竞争。

[事实] 蔡伟将 Personal Agent 的关键要素概括为智能、供给和安全可信。

[事实] 节目把 Chatbot、任务型 Agent 与 Personal Agent 分别关联到信息、软件和服务行业，并认为三者对应的潜在市场规模依次扩大。

[01:24] **嘉宾经历与中美 AI 产业差异**

[事实] 蔡伟曾在美国生活十年并在 Google 从事计算机视觉研发，回国后经历创业和投资，于 2024 年加入蚂蚁并参与其 AI 战略及产品建设。

[事实] 他认为硅谷更关注底层技术与智能上限，国内团队则更重视技术如何落入具体场景、服务哪些用户以及成本是否可控。

[事实] 他将大模型视为继互联网、移动互联网和深度学习之后的新一轮重大技术浪潮。

[04:13] **灵光从 Fast Research 到 Personal Agent**

[事实] 灵光于 2025 年3月立项，早期产品定位是“Fast Research”，通过结构化表达提高用户获取信息的效率。

[事实] 团队随后发现模型已经可以生成互动式内容，于是把面向普通用户的“闪应用”发展为特色功能，并与快速研究、多模态能力共同构成首个公开版本。

[事实] 春节后，模型的长程任务能力跨过新的可用门槛，团队开始向 Personal Agent 演进，并用了约半年时间处理基础设施、算法效果、安全、隐私和合规问题。

[事实] 灵光始终以“真人助理能为用户做什么”为第一性原理，希望模型随着能力提高，逐步解锁更多线上乃至线下任务。

[12:34] **三代 AI 产品及其交互形态**

[事实] Chatbot 主要提高信息获取效率，把搜索、阅读、归纳和回答整合为一次交互；较窄、较弱的陪聊或写作需求则可能被后续通用产品吸收。

[事实] Claude Code、Manus 等任务型产品要求模型拆解复杂任务、调用不同工具并组合结果，因此代表了不同于问答产品的新形态。

[事实] 面向专业用户的 Coding Agent 强调执行过程、工具调用和代码变更，而面向普通消费者的产品更应关注事情是否真正完成，以及何时需要用户决策。

[事实] Personal Agent 的新增能力在于主动性：它不仅响应请求，还要在合适的时间主动提供信息、管理事项并推进任务。

[19:33] **主动性、记忆与边界感**

[事实] Personal Agent 需要持续理解用户的事项、偏好和上下文，并根据重要程度选择主动提醒、继续执行或保持安静。

[事实] 不同用户对提醒频率和交互方式的偏好不同，因此主动性必须与个性化结合。

[事实] 灵光当前采取相对克制的产品主张，尽量减少打扰，并根据实际反馈调整推送、对话和详情页等不同信息载体。

[推测] Personal Agent 的核心难题并非单纯提高消息数量，而是判断哪条信息值得占用用户注意力。

[28:00] **Personal Agent 集中出现的条件**

[事实] OpenClaw 等极客产品展示了模型在配置好技能和工具后，可以主动、自动地执行长程任务，但安装和配置门槛较高。

[事实] 面向大众的 Personal Agent 需要更多个人上下文，而这些上下文不仅来自对话，也可以来自用户授权连接的服务。

[事实] 灵光优先接入支付宝生态中的服务，并依靠蚂蚁已有的合作体系降低与服务商沟通接口和权限的成本。

[事实] 涉及购物、支付和个人数据时，系统必须明确哪些操作可以执行、哪些需要授权，以及数据如何得到合规保护。

[事实] 蔡伟据此把行业成熟条件总结为智能、供给和安全可信。

[34:48] **海外产品启示与通知策略**

[事实] Instinct 展示了 Personal Agent 不一定以独立 App 存在，也可以通过电话、短信、网页乃至其他硬件提供服务。

[事实] 蔡伟认为 Muse 在产品细节和边界感方面表现突出，其主动消息通常频率较低但信息增益较高。

[事实] 如果通知缺少个性化价值，用户会把它视为营销信息，继而忽略提醒、关闭通知甚至卸载产品。

[事实] 信息需要按照与用户当前需求的距离分层，优先呈现直接影响行程、决策或任务完成的内容，而不是泛化推荐所有相关信息。

[42:04] **Personal Agent 与服务业重构**

[事实] 蔡伟认为 Personal Agent 是正确方向，但当前 App 形态并非终局；理想状态是它能够承担真人助理在生活中的大量工作。

[事实] 现实中的营养师、教练、家教等服务由不同的人提供，未来部分服务可能由一个或少量 Personal Agent 统一承接。

[事实] 节目把 Chatbot、任务型 Agent 和 Personal Agent 分别对应到信息行业、软件行业和服务行业，并粗略判断其市场潜力依次为千亿、万亿和十万亿级别。

[事实] 蔡伟认为模型在部分专业知识上已经接近普通真人服务者，未来可能推动服务业供给方式的系统性重构。

[46:34] **旧入口不会立即消失**

[事实] Chatbot 长期可能替代传统搜索的一部分功能，但搜索公司也会利用已有的算法、人才和数据积累完成自我革新。

[事实] Google 把 AI 视为不能输的竞争，并通过 Gemini 等产品主动推动自身转型。

[事实] 用户习惯不会一夜迁移，即使新型搜索和聊天产品快速增长，传统搜索仍然拥有庞大的用户规模。

[推测] 新旧入口更可能经历长期共存和渐进迁移，而不是由新产品在短期内完全取代旧产品。

[49:19] **大模型带来的是供给侧变革**

[事实] 蔡伟认为移动互联网主要通过手机、定位等条件扩展使用场景，而大模型则直接创造或重新组织智能供给。

[事实] 大模型既能即时生成全新内容，也能把原本分散的服务连接起来，形成新的端到端体验。

[事实] O2O 完成了大量线下服务的线上化，为 Personal Agent 调用现实服务奠定了供给基础。

[事实] 钉钉、飞书及各种生活服务都可以成为 Agent 的供给，但前提是能够以安全、可信且开放的方式被访问。

[54:57] **App、硬件与无处不在的助理**

[事实] App 只是 Personal Agent 的一种表现形式；国内用户高度习惯移动 App，因此当前产品通常优先在手机上落地。

[事实] 电话和短信在美国服务体系中更常见，因此类似 Instinct 的无 App 模式在美国更容易成立。

[事实] 灵光会优先保证 App 体验，同时开放能力，让动手能力较强的用户连接家庭设备、车机和其他硬件。

[事实] 灵光2.0的部分内测用户已经通过多轮对话把产品连接到扫地机器人、车机和净水设备，这些并非团队最初预设的场景。

[推测] 当模型、接口和安全体系进一步成熟后，Personal Agent 可能从单一应用扩展成跨设备存在的服务层。

[59:02] **从“帮我管事情”切入市场**

[事实] 普通用户目前并不总能理解 Personal Agent 可以做什么，新产品仍需要市场教育。

[事实] 灵光选择“帮我管事情”作为具体切口，覆盖家庭、父母、小孩及其他需要持续关注和跟进的生活事项。

[事实] 灵光不仅观察 DAU、留存等常规指标，也关注用户创建、持续管理、完成或中途放弃了多少事项。

[事实] 蔡伟强调愿景可以很大，但初始切口需要聚焦，让用户能够明确感受到产品价值。

[72:35] **产品、业务与组织协同**

[事实] 蔡伟把产品理解为用特定形态组织要素、满足特定用户需求；业务型产品则往往还要协调用户、商家、平台和利益分配等多方关系。

[事实] 电商和支付必须深入供给、物流、交易、风控和售后，不能只优化前端体验，因此天然具有较重的业务属性。

[事实] 蚂蚁内部对 AI 方向投入明确，灵光团队仍需通过持续沟通，让公司在产品形态和商业模式尚未稳定时保持方向一致。

[事实] “灵光”这一名称延续了蚂蚁的“灵”系列命名，也包含聪明、灵敏和灵光一现的含义。

[78:58] **指标之外的产品方向**

[事实] 灵光关注用户规模和留存，但也追踪事项是否真正创建、保持活跃并最终完成。

[事实] 蔡伟认为把目标压缩成单一数字会丢失大量信息；一旦目标变成唯一考核指标，团队就容易选择最容易达成数字、却未必正确的路径。

[事实] 在模型和产品都快速变化的阶段，稳定的产品主张比频繁切换的 KPI 更有指导作用。

[事实] 他期待灵光最终成为拥有千万乃至上亿 DAU 的通用 AI 产品，同时强调推动行业进步和积累能力也具有独立价值。

[88:26] **AI 时代产品经理的变化**

[事实] 对用户需求的洞察仍然重要，但 AI 产品还增加了大量“策略产品”工作，即持续调整模型和整体产品效果。

[事实] 产品经理需要理解模型的能力边界，部分灵光产品经理由技术岗位转型，其他成员也会阅读论文并深入学习模型。

[事实] 产品设计不能只匹配当下模型，还要预判三至九个月后的能力演进，以便产品成熟时与新模型形成匹配。

[事实] AI 工具也使产品经理能够更直接地制作原型，提高产品验证效率。

[92:09] **模型与应用的双向驱动**

[事实] 灵光团队与基础模型团队高度协同，产品需求会从预训练阶段开始影响模型的数据和能力建设。

[事实] Coding Agent 强调代码能力，Personal Agent 则更重视长程任务拆解、异常恢复和工具调用质量。

[事实] 后训练适合调整风格和行为，但基础能力仍需要尽可能在预训练等更早阶段建立。

[事实] 蔡伟认为 OpenAI、Anthropic 更多表现为强模型能力外溢出产品，而蚂蚁则有较多由生活服务应用反向拉动模型发展的成分。

[97:43] **记忆系统与个性化表达**

[事实] 灵光倾向于尽可能记住用户主动提供的上下文，但是否调用记忆要依据当前对话或任务的真实目的。

[事实] 不相关地调用旧信息可能带来冒犯、隐私不适或低情商表达，因此记忆不是越多展示越好。

[事实] 灵光把自己定位为助手：在用户需要时出现，不需要时保持安静，但可以在后台继续推进事项。

[推测] Personal Agent 的个性化质量主要取决于能否在正确情境调用正确记忆，而不仅是记忆容量。

[101:22] **通用产品还是垂直业务**

[事实] 产品应当做轻还是做重，取决于用户体验所要求的完整链路，而不是抽象地选择产品驱动或业务驱动。

[事实] 电商若要保障交易、供给、物流和售后，就必须深入产业链；仅做导购难以取代完整平台。

[事实] 搜索等信息需求则更容易由通用产品覆盖，通用能力可能吸收大量垂直工具。

[推测] Personal Agent 最终需要多深地进入业务链条，将由各类生活服务对履约和供给控制的要求决定。

[117:25] **未来六个月的模型演进**

[事实] 长程任务由多个步骤组成，即使单步错误率较低，累积后仍会显著降低整体成功率。

[事实] 对用户而言，能够调用工具不等于完成任务；如果最后一步没有交付结果，前面的执行过程也难以产生价值。

[事实] 真实用户案例可以形成数据反馈，帮助模型改进任务拆解、异常恢复和工具使用方式。

[事实] 多模态能力将使 Personal Agent 更实时、更自然地观察、聆听和表达，并支持类似真人助理的交互。

[120:17] **从数字助理走向具身智能**

[事实] 当前模型擅长写作、绘画和创作，却仍难以完成叠被子、做饭、洗碗等日常体力任务。

[事实] 蔡伟认为机器人可能成为 Personal Agent 的现实载体，而 Personal Agent 则充当软件层、中枢大脑或“灵魂”。

[事实] 具身智能目前更容易在工业、商业和公共场景落地，进入家庭仍面临感知、控制和灵巧操作等困难。

[事实] 打开冰箱、系鞋带等人类看来简单的动作，实际需要复杂的力量控制、反馈和判断。

[125:00] **Personal Agent 在产业版图中的位置**

[事实] Personal Agent 既可能是独立应用，也可能发展成连接和编排各类服务的操作系统层，两种角色并不冲突。

[事实] 支付宝等平台中的服务若被原子化、Agent 化，可以通过开放平台被不同 Agent 调用，而不必只服务于灵光。

[事实] MCP 等接口只是服务 Agent 化的第一步，完整生态还需要解决授权、安全、合规和商家链路改造。

[事实] 产品使用产生的反馈和数据能够反向促进模型迭代，形成模型与应用相互推动的循环。

[128:49] **中心化、控制权与竞争壁垒**

[事实] Agent 生态最终是中心化还是分布式，取决于模型能力、供给范围、用户体验、商业格局和区域习惯，当前无法下定论。

[事实] 掌控权不只存在于用户入口，也可能属于产业链中不可替代的操作系统、芯片或基础设施环节。

[事实] 从公司角度看，掌控关键环节意味着商业利润；从社会和用户角度看，更重要的是整个链条能否以低成本提供良好体验。

[事实] 蔡伟判断 Personal Agent 的短期壁垒主要是智能，中长期壁垒则是供给和安全。

[135:34] **模型能力仍未进入稳态**

[事实] 智能手机在 iPhone 4 之后逐渐形成稳定模块，但大模型目前仍在快速演进，尚未出现类似的稳定状态。

[事实] 尽管行业曾讨论 Scaling Law 是否失效，模型仍从代码生成持续进步到长程任务执行。

[事实] 只要智能能力继续高速提升，就会不断解锁新的产品形态和商业机会；未来增速可能放缓，但也可能出现新的技术浪潮。

[推测] 当前判断 Personal Agent 终局仍然过早，产品边界会随着模型能力变化而反复重构。

[137:37] **补贴大战与产品价值**

[事实] 蔡伟认为 Personal Agent 会是持续演进的长周期赛道，竞争终会形成阶段性稳态，但产品本身不会停止变化。

[事实] 补贴是获客和竞争决策，与产品和技术演进是两条独立的线；竞争对手补贴也可能迫使其他公司应战。

[事实] 他认为 Personal Agent 在春晚期间出现补贴活动是有可能的，形式未必是直接红包，也可能是让用户低成本体验某项服务。

[事实] 补贴无法弥补产品价值不足，因为消费者最终会停止使用不能持续创造价值的产品。

[推测] 国内 Personal Agent 的早期竞争可能同时包含市场教育、场景体验和流量争夺，而不只是价格补贴。

[143:28] **算力成本与普惠可能性**

[事实] Personal Agent 的主动执行会增加推理次数，但许多后台任务不需要即时完成，可以利用算力低谷和较便宜的硬件运行。

[事实] 蔡伟相信算力成本会长期下降，算力基础设施也会逐渐具有类似水、电、煤的公共基础设施属性。

[事实] 现实中少数人拥有真人助理，可能源于供给昂贵，而不代表普通用户没有助理需求。

[事实] 如果 AI 助理创造的价值显著高于使用成本，它就可能从高端服务转变为面向大众的增量需求。

[149:20] **Personal Agent 的商业模式**

[事实] 第一种商业模式是生产力收费：按照 Agent 为用户创造的价值定价，只要用户收益、产品价格和服务成本之间存在合理空间，就能形成交易。

[事实] 第二种模式是入口收费：当用户信任 Agent 的购物、医疗或保险建议时，平台可以通过广告、抽成或通道费变现。

[事实] 如果未来只有少量中心化 Personal Agent，入口模式更可能成立；如果生态较分散，按生产力价值收费更具可行性。

[事实] 蔡伟强调，大模型首先是供给侧变革，因此 Personal Agent 并不必然沿用传统互联网的流量商业模式。

[事实] 蔡伟认为如果 Personal Agent 热度上升后留存下降，更可能是产品尚未做好，而不是方向本身不成立。

[事实] 根据 Muse 和灵光内测的观察，他判断行业已经接近用户能够持续使用的拐点。

[事实] DAU 容易受到补贴、营销和竞争影响，短期更像投票结果；长期仍需由产品创造的真实价值支撑。

[事实] Personal Agent 的留存来自其接管了用户生活中重要、长期且需要持续管理的事项，这与低频的一次性问答不同。

[158:01] **终局想象与快问快答**

[事实] 蚂蚁过去的硬件积累主要来自刷脸支付和“碰一下”等设备，AI 消费硬件并非其传统优势，但公司正在增加关注。

## 播客点评/总结

本期的主要价值，是把 Personal Agent 从一个模糊的“AI 助手”概念拆解为智能、供给和安全三个相互制约的系统问题。节目没有只讨论模型参数，而是持续追问任务能否完成、服务能否连接、授权是否可信，以及产品是否真正进入用户的生活流程。

另一个亮点是对产品方法的讨论：主动并不等于频繁打扰，记住信息也不等于随时调用。边界感、信息分级和完成度，被放在与模型能力同等重要的位置，这对设计消费级 AI 产品具有较强参考价值。

[推测] 节目的观点主要来自灵光负责人的产品实践和产业判断，因此对 Personal Agent 的长期前景整体偏乐观；市场规模、行业拐点、生态终局及未来补贴等结论仍需更多用户数据和时间验证。

本期适合关注 AI Agent、消费级 AI 产品、互联网平台转型、模型与应用协同，以及服务业数字化的人群。对于产品经理和创业者而言，其中关于切入场景、指标异化、模型能力预判及长期积累的讨论尤其值得参考。
