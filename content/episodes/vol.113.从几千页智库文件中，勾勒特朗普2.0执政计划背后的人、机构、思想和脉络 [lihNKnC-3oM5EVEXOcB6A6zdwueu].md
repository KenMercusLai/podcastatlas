# Vol.113 从几千页智库文件中，勾勒特朗普2.0执政计划背后的人、机构、思想和脉络

## 概览

本期节目试图绕开特朗普个人的言行，转向他背后的智库、政策文件、组织网络和新右翼思想脉络。主播说明自己不是美国政治专家，本期更像是阅读几千页材料后的学习笔记，并提醒听众带着批判眼光看待其中带有民族主义、民粹主义或美国视角的内容。

节目主要围绕三份材料展开：传统基金会的《Mandate for Leadership 2025》、共和党2024党纲，以及美国优先政策研究中心 AFPI 的 Agenda。主播认为，Project 2025 虽然未必会被特朗普政府全盘照收，但它有历史传承、作者阵容、过渡计划、人才库和培训系统，能反映“将川普主义制度化”的努力。

讨论主线按 Project 2025 的四个承诺展开：恢复家庭中心地位、拆除行政国家、捍卫主权边界和财富、保障上帝赋予的个人自由。节目重点分析了政府改革、削减联邦机构、移民、供应链、能源、通胀、美联储、教育部、贸易互惠和关税等议题，并把这些政策想法放回美国保守主义、民粹主义和贸易保护传统中理解。

## 分段落总结

[00:10] **开场与方法说明**

[事实] 主播说明本期播出时正值美国政府换届，主题是特朗普政府，但重点不是特朗普本人，而是背后的团队、智库和政策规划。

[事实] 主播强调自己不是政治专家，也没有在美国生活过，本期内容是阅读大量资料后的学习笔记整理。

[事实] 主播表示会尽量保持中立，并提醒听众用辩证和批判眼光看待美国政坛相关人士的想法。

[02:00] **从特朗普个人转向背后组织**

[事实] 主播认为特朗普2016年是政治素人，但这一次“有备而来”，背后已有更成熟的团队和政策准备。

[事实] 本期的重要启发来自《纽约客》文章《Inside the Trump Plan for 2025》，该文描绘了特朗普2025执政计划背后的人、机构、思想和脉络。

[事实] 主播用“有组织、有预谋、筹备多时”概括文章呈现出的特朗普2.0准备状态。

[04:00] **CPI与右翼组织网络**

[事实] 主播介绍 Conservative Partnership Institute，即 CPI 保守派伙伴研究所，并称其是2020年特朗普败选后右翼组织网络中的核心之一。

[事实] CPI 为离开政府的前特朗普官员和保守派人士提供土壤，孕育出美国问责基金会、州自由核心小组网络、选举诚信网络、美国时刻等组织。

[事实] 这些组织分别承担攻击拜登提名人选、挑战州共和党建制、监督选举、培养下一代保守派工作人员等功能。

[06:00] **三份核心政策材料**

[事实] 主播本期主要参考三份材料：传统基金会的《Mandate for Leadership 2025》、共和党2024党纲、AFPI Agenda。

[事实] 共和党2024党纲被主播称为“川普20条”，其文本更像竞选提纲，表达较简明甚至粗糙。

[事实] AFPI 是特朗普2020年败选后成立的智库，主播特别提到其首席经济学家被特朗普提名为财政部副部长。

[推测] 主播把三份文件互相对照，是为了区分哪些想法只是意识形态表达，哪些更可能进入实际政策优先级。

[08:00] **为什么重视Project 2025**

[事实] 主播指出传统基金会的“劝建书”有历史传承，第一本在1980年冬交给当选总统里根，并据称在里根第一年有大量建议转化为政策。

[事实] 传统基金会称，2016年交给特朗普的版本也有相当比例被特朗普政府实施。

[事实] 2025版本比以往更早发布，原因是文件认为现代联邦政府复杂，保守派必须提前一年准备过渡和改革。

[12:00] **作者阵容与操作系统**

[事实] 主播提到《Mandate for Leadership 2025》的34位作者中，有15位曾在特朗普竞选团队或政府任职。

[事实] 作者中包括纳瓦罗等特朗普第一任政府人物，也有许多曾在政府部门担任副职、熟悉部门运作的人。

[事实] 该文件不仅提出思想和政策大纲，还包含180天过渡计划、潜在雇员数据库和培训系统。

[推测] 这些设计既服务于特朗普政府快速接管行政机器，也可能试图用预设人才库限制特朗普用人的任意性。

[16:00] **将川普主义制度化**

[事实] 主播认为 Project 2025 未必会被全盘吸收，但其四个核心承诺能反映当下美国保守主义的重点。

[事实] 主播转述传统基金会主席的说法，Project 2025 的目标不是直接成为特朗普执政纲领，而是将川普主义制度化。

[事实] 文件开篇用通胀、药物过量、学校文化、觉醒主义等语言描绘美国社会危机。

[18:00] **四个承诺的总框架**

[事实] Project 2025 的四个承诺分别是：恢复家庭为美国生活中心、拆除行政国家、捍卫主权边界和财富、保障个人自由。

[事实] 主播认为第二、第三条对外国听众更直观重要，但第一、第四条更能体现川普主义和美国民粹主义的精神基础。

[事实] “恢复家庭中心地位”被主播概括为反性别平权、反科技公司、反堕胎三类核心主张。

[20:00] **家庭议题的激进表达与弱化落地**

[事实] Project 2025 提出要从联邦规则、机构规章、合同、法规、立法中删除多样性、性别等相关内容。

[事实] 共和党党纲中对应内容被弱化为削减向孩子灌输批判性种族理论、激进性别意识形态等学校的联邦资助，以及禁止男性参与女子体育。

[事实] AFPI Agenda 则进一步具体化为家长择校权、加强父职和核心家庭等政策表达。

[推测] 主播认为这些议题虽然是共和党内核，但许多极端内容未必会立刻落地，更可能先从K12教育、择校和部分性别议题入手。

[24:00] **拆除行政国家成为核心议题**

[事实] 主播认为“拆除行政国家”是特朗普第二任期非常重要的命题，因为它关系到政府改革、长期执政基础和川普主义传承。

[事实] Project 2025 认为现代联邦政府已经偏离宪法原意，行政机构获得了过多由国会让渡的权力。

[事实] 文件批评行政机构每年发布规则，却不由政治任命者直接发布，也不充分受到国会和选民问责。

[推测] 主播认为，共和党对行政权扩张的批评存在选择性，因为它同时也希望恢复或使用符合自身目标的行政令。

[30:00] **迁出华盛顿与裁撤官僚**

[事实] Project 2025 建议将联邦机构迁出华盛顿，以打破“环城公路泡沫”，让官僚更接近受政策影响的普通美国人。

[事实] 文件提出华盛顿大都会区聚集富裕县，联邦雇员收入高于私营部门同等职位，政策制定者与美国其他地区脱钩。

[事实] 主播提到特朗普政府期间，农业部部分机构迁往密苏里州 Kansas，内政部土地管理局迁往科罗拉多州。

[推测] 主播认为，机构外迁也可能成为间接裁员手段，因为部分雇员会因家庭和生活原因离职。

[35:00] **美国政治妥协能力的下降**

[事实] 主播引用《当灯光暗淡之后》，说明美国政治制度依赖国会、两党、参众两院、国会和总统之间的妥协。

[事实] 书中认为，政治谈判从幕后转移到摄像机前，会迫使政客在选民面前坚守立场，减少妥协空间。

[事实] 主播把这种妥协减少与美国国会失衡、党派极端分裂、特朗普出现联系起来。

[推测] 主播认为共和党很多政策表达更像是在反对民主党，而不是正面说明自己方案更优。

[38:00] **联邦预算与削减支出**

[事实] 共和党党纲和 AFPI 都把控制浪费性联邦开支与战胜通胀联系起来。

[事实] AFPI 认为美国联邦预算问题不是收入不足，而是支出过度，因为收入长期大致稳定在GDP的16%到18%，支出却增长更多。

[事实] 主播提到联邦支出中64%为强制性支出，30%为可自由支配支出，AFPI 认为两类支出都有削减空间。

[42:00] **掌握政府控制权**

[事实] 主播认为拆除行政国家只是手段，更关键的是让总统任命的官员更多、更强，并能监督职业官僚。

[事实] Project 2025 详细拆解各联邦部门、岗位和历史，提出解构集中行政国家的重要性。

[事实] 文件对国土安全部、国家海洋与大气管理局、教育部等部门提出拆分或解散建议。

[46:00] **行政命令反复与政府效率部**

[事实] 主播注意到 Project 2025 中有大量建议要求新政府恢复特朗普时期行政命令、撤销拜登时期行政命令。

[事实] 主播认为两党政府每四年摇摆，会造成大量制度摩擦成本。

[事实] 主播提到马斯克的政府效率部，认为其表面目标是削减联邦支出，但也可能配合重组联邦部门和安排新的中层管理者。

[48:00] **主权、边界、财富与反精英叙事**

[事实] Project 2025 的第三个承诺是捍卫美国主权、边界和财富，抵御全球威胁。

[事实] 文件用美国公司管理者、大学校长、华尔街对冲基金经理与普通工人对立的语言，表达反精英和民粹主义精神。

[事实] 文件主张，如果国际组织和协议侵蚀美国宪法、法治或人民主权，就不应改革而应放弃。

[事实] 文件还提出非法移民应当结束，边界应当封闭，美国制造业和工业基础应当恢复。

[50:00] **移民政策的两种表述**

[事实] 共和党党纲提出封锁边境、阻止移民入侵，并执行美国历史上最大规模的驱逐行动。

[事实] AFPI 则用更中性的语言，主张恢复合法移民体系完整性，按个人优点和技能选择移民。

[事实] AFPI 反对连锁移民和签证抽签，认为它们会引入低技能移民并加重公共服务负担。

[推测] 主播认为实际政策可能不是单纯反移民，而是更理性也更冷血地按“是否有价值”筛选移民。

[52:00] **供应链与能源自给**

[事实] AFPI 专门提出建立只依赖美国工人和盟友的供应链。

[事实] AFPI 用疫情、俄乌战争、加拿大洪水导致木材价格上涨等例子说明供应链脆弱性。

[事实] 主播认为到了具体政策层面，美国真正能做到较高自给的领域主要是能源。

[54:00] **通胀作为最优先议题**

[事实] AFPI Agenda 第一章和共和党党纲第一章都把通胀放在最前面。

[事实] 共和党提出通过释放美国能源、控制浪费性支出、削减过度监管、确保边境安全来战胜通胀。

[事实] 主播认为能源价格对美国通胀有影响，但增加能源供给能否直接降低油价、能否解决服务业通胀，传导路径并不清晰。

[推测] 主播认为将非法移民与通胀强绑定，可能是政治家借经济学理论支撑政治诉求。

[58:00] **美联储、金本位与自由银行**

[事实] Project 2025 中关于美联储的章节认为，联邦储备导致了通胀和衰退周期。

[事实] 作者建议至少把充分就业从美联储任务中剔除，让其专注价格稳定。

[事实] 更激进的建议是废除美联储，用自由银行取代，让利率和货币供应由市场决定。

[推测] 主播认为这一建议接近回到金本位，逻辑上能抑制货币滥发，但也会带来许多负面影响，最终很难走到这一步。

[62:00] **为什么美联储获得独立权力**

[事实] 主播引用《当灯光暗淡之后》，解释美国国会在1913年设立美联储时，并未意识到货币政策权力后来会如此重要。

[事实] 美联储最早目标是防止1907年式金融恐慌再次发生，后来逐渐获得通过短期利率影响总需求的货币政策职能。

[事实] 书中还认为，货币政策需要专业性，且加息等决策常会让选民不快，因此政治家愿意把责任交给技术官僚。

[推测] 主播认为，现在政治家批评行政国家过大，但最初正是政治系统把复杂、长期、容易得罪选民的权力外包给专业机构。

[66:00] **自由与“政府武器化”**

[事实] Project 2025 的第四个承诺是保障上帝赋予的个人权利自由，包括宗教自由、言论自由和集会自由。

[事实] 共和党党纲提出要结束政府针对美国人民的“武器化”行为。

[事实] 主播介绍，特朗普卸任后因带走总统文件、拒绝按传票归还，海湖庄园遭FBI搜查，之后共和党推动设立“联邦政府武器化特别小组委员会”。

[推测] 主播认为“政府武器化”是共和党向民主党和左翼扣上的帽子，但该委员会本身也可能被视为一种武器化行为。

[70:00] **教育部成为关键靶点**

[事实] 主播认为特朗普阵营对美国教育制度非常不满，尤其是高等教育更偏进步主义和自由派。

[事实] 共和党党纲提出培养优秀K12学校、赋予家庭择校权、把教育归还各州。

[事实] 取消联邦教育部是 Project 2025 和共和党党纲都明确出现的撤销部门主张。

[事实] Project 2025 追溯教育部与1964年民权法案、低收入儿童和弱势学生补偿等历史关联，并批评教育部被教育协会、教师工会和高等教育游说团体利用来扩大联邦支出。

[72:00] **政策组合的矛盾与贸易问题引出**

[事实] 主播总结，特朗普政府可能优先打击非法移民、减税、放松产业政策、刺激增长并压制通胀。

[事实] 主播同时指出，这些政策之间存在矛盾，例如打击移民可能推高劳动力成本，减税可能减少联邦收入。

[事实] 主播由此引出最后一个重点话题：贸易和关税。

[74:00] **纳瓦罗的贸易赤字逻辑**

[事实] Project 2025 的贸易章节由纳瓦罗和另一位较温和作者共同撰写，呈现出支持和反对关税的不同观点。

[事实] 纳瓦罗认为贸易赤字代表美国制造业、国防工业基础和供应链被外包到外国。

[事实] 纳瓦罗认为外包压制美国蓝领工人实际工资，剥夺他们进入中产阶级的机会，并削弱制造业和国防工业基础。

[推测] 主播认为，美国鹰派把贸易问题上升为国土安全和本国就业问题后，中国更难只按商业逻辑与其沟通。

[78:00] **贸易互惠与美国保护主义传统**

[事实] 主播推荐公众号《太阳照常升起》主理人沐峰关于全球贸易、全球化和川普主义的文章。

[事实] 主播认为理解“贸易互惠”是理解美国贸易保护主义的重要钥匙。

[事实] 沐峰文章提到，1791年汉密尔顿在《Report on Manufactures》中系统阐述幼稚产业理论，为美国贸易保护提供思想基础。

[80:00] **American System与关税武器**

[事实] 主播提到 Henry Carey 提出的 American System，包含高关税、基础设施建设、保护纺织和钢铁等支柱工业，以及用差别关税促进农产品出口。

[事实] 主播认为，从共和党历史视角看，贸易保护是美国传统，WTO式超级全球化反而是历史意外。

[事实] 贸易互惠在这种传统中意味着，如果一方受损，就可用关税反击或补偿。

[82:00] **自由贸易与互惠为何分离**

[事实] 主播认为二战后很长时间，美国拥有近乎所有产业优势，因此自由贸易与互惠在表现上几乎一致。

[事实] AFPI 文件也主张公平互惠贸易，即外国商品进入美国时的关税应与美国商品进入外国时的关税相同。

[事实] 主播认为美国企业出于避税和降低人力成本，把生产和研发逐步迁出本土，最终导致去工业化和超级全球化。

[86:00] **全球化中的当地就业与德国案例**

[事实] 主播借此前讲日本五大商社的内容指出，国际贸易和出口不仅是产业竞争，也影响当地就业和经济。

[事实] 主播认为日本五大商社选择融入当地经济体系，并做出培育动作，以降低当地对日本企业的威胁感。

[事实] 主播引用德国案例，说明德国曾因中国需求获得汽车、机床、工程技术等领域订单，但部分行业早已感受到中国竞争和市场准入限制。

[事实] 到2023、2024年，德国汽车和中小企业对中国竞争压力感受增强，德国政府也提出经济多元化和新的对华战略。

[90:00] **麦金莱与特朗普的历史类比**

[事实] 沐峰认为特朗普较像美国第25任总统 William McKinley。

[事实] 主播介绍 McKinley 在任期内提高关税、保护美国工业、维持金本位，并反对通胀政策。

[事实] 主播提到 McKinley 时代通过关税和政治操作让夏威夷最终纳入美国版图，并把这与特朗普关于加拿大、巴拿马的言论相类比。

[推测] 主播认为特朗普有意模仿某些前美国总统的做法，但能否成功无法判断。

[92:00] **高关税、弱管制与高技能移民**

[事实] 主播总结 McKinley 政策包不是单纯高关税，而是进口高关税、本土弱管制、吸引欧洲企业技术和人才、低收入税、高质量移民的组合。

[事实] 主播认为美国拥有全世界最大的内需市场，高关税壁垒可能促使企业迁入美国。

[事实] 主播认为美国作为老牌移民国家，只要对高技术移民友好，仍能吸引企业家和科技人才流入。

[推测] 主播认为只有美国较可能用高关税、去管制和移民政策组合来吸引人才、资本和技术。

[94:00] **没有简单结论的政策图景**

[事实] 主播表示自己没有得出具体结论，因为特朗普及其政府想做的事很多、很杂、很矛盾，有些长期，有些匪夷所思。

[事实] 主播希望通过梳理书籍和政策文件，让听众理解这些政策背后的原因和根基。

[事实] 节目最后回到《纽约客》文章中关于美国时刻创始人和 J.D. Vance 的叙述。

[96:00] **新右翼一代与川普主义遗产**

[事实] Vance 在《终结全球化盛宴》中阐述了新右翼原则：经济民粹主义、政治民族主义、外交孤立主义，以及对移民的重新思考。

[事实] 美国时刻创始人认为右翼组织正在华盛顿创造新的持久文化，并扶持受特朗普和MAGA影响的年轻保守派。

[事实] 主播认为特朗普不是历史偶然，也不是任期结束后美国就会恢复原轨道的特例。

[推测] 主播认为未来会有更多美国年轻人继承川普主义、MAGA和新右翼原则，但这会把美国和世界带向何方仍难以判断。

## 播客点评/总结

[推测] 本期的价值在于把特朗普2.0放进组织、文件和思想史的框架里看，而不是停留在特朗普个人言论层面。节目通过 Project 2025、共和党党纲和 AFPI Agenda 的互相对照，帮助听众理解哪些主张是意识形态，哪些可能成为政策工具。

[推测] 亮点是把美国内政改革、行政国家、教育、移民、能源、通胀、关税和贸易互惠串成一条线，并不断提醒这些政策之间存在矛盾。尤其是对“贸易互惠”和美国保护主义传统的解释，有助于中文听众理解为什么关税在美国右翼语境中不只是贸易工具。

[推测] 局限是节目大量依赖主播对政策文件和二手材料的阅读与整理，很多判断仍属于基于文本的推断，而非对未来政策结果的确认。节目也明确承认无法得出确定结论，因为特朗普2.0的议程复杂、矛盾且仍在展开。

[推测] 本期适合关心美国政治、特朗普2.0、Project 2025、中美贸易、全球化退潮和美国新右翼思想的听众；如果只想获得快速新闻结论，可能会觉得本期材料密度较高、铺陈较长。
