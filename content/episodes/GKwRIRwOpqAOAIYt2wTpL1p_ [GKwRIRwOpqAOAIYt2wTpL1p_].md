# 环球影城为何押注“惊吓生意”：本土 IP、淡季增长与运营挑战

## 概览

本期节目先梳理多条商业科技动态：苹果计划在中国大陆推出首批 Apple Intelligence 功能；民航局调整国内航线准入政策，以缓解运力过剩与过度竞争；奈飞则在订阅增长承压、内容库遭到质疑的背景下裁员并调整发行模式。

节目还关注 Character AI 破产引发的未成年人数据安全问题。该公司用户黏性突出，但高昂的算力和人才成本造成持续亏损，其掌握的私密对话数据也成为监管关注的焦点。

核心讨论聚焦环球影城的“惊吓生意”。节目认为，万圣节活动既能填补秋季淡季、延长游客停留时间，也能复用环球长期积累的恐怖内容与制作资源；季节限定项目还可以成为测试外部及本土 IP 商业潜力的低风险场景。不过，沉浸感、接待能力和授权依赖之间的矛盾，也给这种模式带来明显挑战。

## 分段落总结

[00:30] **本期议题与环球影城投稿**

[事实] 节目将讨论国内航线准入政策调整、奈飞内容库引发的投资者担忧，以及环球影城万圣节活动的运营方式与 IP 策略。

[事实] 听友注意到北京环球影城部分热门鬼屋下午才开放，却提前约两小时出现排队现象，并询问中国小说、游戏 IP 为何越来越多地进入园区。

[事实] 环球已在多个城市开展万圣节惊吓活动，并在拉斯维加斯开设全年营业的 Universal Horror Unleashed 恐怖体验场馆。

[01:58] **苹果 AI 入华与智能体应用阻力**

[事实] 据节目援引的报道，苹果计划于当年12月通过 iOS 27.3 在中国大陆推出 Apple Intelligence，首批主要是此前已在美国上线的基础功能。

[事实] 此次更新预计不会包含新版 Siri AI 助手等当年新发布的功能。

[事实] 华为、小米等本土厂商已经在手机中加入自有 AI 服务，报道认为苹果较晚上线基础功能可能缺乏足够吸引力。

[事实] 字节与努比亚合作的第二代豆包手机未能与多家应用开发商达成共识，包括微信、淘宝在内的150多款应用拒绝让其 AI 智能体代替用户操作。

[03:00] **国内航线准入政策调整**

[事实] 民航局发布国内航线航班评审优化措施，将航段分类并设置相应的承运人数量目标；达到目标后，将暂停新的航空公司进入。

[事实] 已有航段若客座率未达到目标，也会暂停批准增加航班量。

[事实] 2024年以来，国际航线恢复缓慢、国内运力相对过剩，加之高铁竞争加剧，民航票价持续下行。

[事实] 当年上半年，国有三大航空公司均出现收入增加但亏损扩大的情况。

[事实] 分析人士认为，优化航线准入和航班量管理有助于引导航空公司合理安排运力、减少重复投入并缓解过度竞争。

[03:49] **奈飞裁员与内容竞争压力**

[事实] 奈飞宣布裁员约1000人，约占员工总数的6%，是其自2022年以来规模最大的一轮裁员。

[事实] 奈飞营收高度依赖订阅，但该业务可能正在接近增长上限；过去一年公司股价下跌超过40%，平台观看时长增速放缓也引发投资者担忧。

[事实] YouTube 等平台以成本较低的免费用户创作内容吸引大量观众，而奈飞收购华纳失败进一步加剧了外界对其内容库的担忧。

[事实] 奈飞正在拓展体育直播和视频播客，但当年尚未打造出足够热门的作品。

[事实] 面对院线电影持续产生文化影响力，奈飞计划于次年在影院推出新电影，调整长期采用的流媒体直接发行模式。

[05:03] **Character AI 破产与未成年人数据安全**

[事实] 美国40个州的总检察长提出，应在 Character AI 的破产程序中加强对未成年用户及其数据的保护。

[事实] 监管方担忧，该平台收集的用户私密对话可能在破产处置中被出售；公司律师则表示，尚无买家对用户数据或业务提出收购报价。

[事实] Character AI 因算力与 AI 人才成本高昂，每月亏损约800万至900万美元，并已申请破产保护。

[事实] Sensor Tower 数据显示，Character AI 当年第一季度的用户平均每月使用时长为982分钟，高于节目所列 ChatGPT 的215分钟。

[事实] Character AI 与 ChatGPT 过去两年均因青少年安全问题面临监管压力。

[06:24] **环球影城的全球惊吓产品布局**

[事实] 北京环球影城围绕《盗墓笔记》《第五人格》和《寂静之地》等国内外 IP 推出主题鬼屋、街头互动和夜间演出。

[事实] 奥兰多和好莱坞环球将《怪奇物语》《罪人》等影视作品改编为鬼屋；日本环球还设置了仅限成年人、进入前须签署同意书的封闭式恐怖项目。

[事实] 环球在拉斯维加斯开设全年营业的恐怖体验场馆，以《德州电锯杀人狂》《驱魔人》及自有经典怪物 IP 打造鬼屋和现场演出，并计划把这种模式复制到芝加哥。

[事实] 环球将传统主题公园之外的惊吓项目视为进入新市场、吸引新游客的一种方式。

[08:17] **惊吓活动拉动淡季业绩**

[事实] 秋季通常是主题公园行业的淡季，部分景区会缩短营业时间并减少人员配置。

[事实] 节目援引行业人士观点称，万圣节活动最多可使整个主题乐园行业的秋季表现提高三成。

[事实] 对北京等北方市场而言，万圣节位于暑期旺季结束与天气明显转冷之间，季节限定活动可以填补客流缺口。

[事实] 惊吓项目适合夜间开展，北京环球影城在“有鬼日”将营业时间延长至晚上10点，游客停留时间的增加也带动了园区及周边的商店和餐饮消费。

[事实] 奥兰多环球的万圣节惊悚之夜需要另外购票，活动期间夜间客流甚至可能超过白天，许多场次接近售罄。

[09:34] **环球的恐怖内容传统与资源复用**

[事实] 环球影业从20世纪20年代起便陆续将《歌剧魅影》、德古拉、科学怪人和狼人等故事搬上银幕，相关怪物后来成为流行文化中的固定角色。

[事实] 佛罗里达环球影城开业一年后便将这些恐怖角色引入万圣节活动，该活动后来发展成每年秋季回归的“万圣节恐怖之夜”。

[事实] 各地环球影城会保留相似的活动框架，再根据当地观众每年更换 IP 和内容。

[事实] 季节性鬼屋使用过的道具和布景会被保存并按新主题改造，演职人员也可能跨项目调配，从而复用既有资源。

[11:01] **季节限定活动成为 IP 试验场**

[事实] 环球主题乐园最初以电影片场的真实体验吸引游客，因此长期依赖影视内容及其线下体验转化。

[事实] 环球拥有超过6500部影片，但乐园项目的竞争力仍取决于 IP 的受欢迎程度，以及能否被转化为具有持续吸引力的现场体验。

[事实] 环球逐渐形成自有 IP 与外部 IP 并用的模式，哈利·波特和任天堂是典型的长期外部合作案例。

[事实] 万圣节限定活动可以更灵活地与外部及本土 IP 短期合作；北京环球影城曾引入《王者荣耀》《原神》，并在本次活动中与《盗墓笔记》《第五人格》等本土 IP 合作。

[事实] 业内人士认为，环球可以先利用季节性活动观察一个 IP 能否带来客流、消费和复购，再判断是否值得长期投入。

[事实] 恐怖题材在 Z 世代喜爱的视频类型中位列第三；每年轮换热门 IP 既能吸引原作粉丝，也能为老游客提供再次到访的理由。

[推测] 季节限定鬼屋兼具活动产品与市场测试功能，使环球能够以相对灵活的方式评估不同 IP 的线下商业价值。

[13:08] **沉浸体验与接待能力的矛盾**

[事实] 现代鬼屋越来越像充满细节的小型剧场，需要灯光、音效、道具、演员表演以及惊吓节奏相互配合。

[事实] 有的鬼屋单个房间会安排多达六名演员，部分项目还包含约90秒的开场表演。

[事实] 演员互动越丰富，游客在场景中停留越久，单位时间能够通过的人数就越少，热门项目因此可能需要排队两至三个小时。

[事实] 为提高通行速度，园区通常让游客连续成队前进，但这会压缩欣赏场景细节的时间，后方游客也可能提前看到惊吓环节。

[推测] 鬼屋越追求个性化、近距离的沉浸体验，就越难兼顾大型主题乐园所需要的高吞吐量。

[14:43] **外部 IP 授权带来的经营风险**

[事实] 外部 IP 从场景设计、角色形象到周边商品，都可能需要版权方审核。

[事实] 环球采用的外部 IP 越多，其在内容取舍和调整节奏上的主控权就越有限。

[事实] 授权到期后能否继续使用，以及续约价格和条件是否变化，并不完全由环球决定。

[事实] 康卡斯特年报指出，如果无法以合理条件续签授权，相关业务可能受到影响。

[推测] 环球需要在头部授权 IP 的即时吸引力与自有原创角色的长期可控性之间保持平衡。

## 播客点评/总结

[推测] 本期最有价值的部分，是把看似单纯的节庆娱乐拆解为淡季经营、营业时长、二次消费、资源复用和 IP 测试等多层商业机制，让听众看到鬼屋排队热潮背后的主题乐园经营逻辑。

[推测] 节目对模式局限的讨论也较完整：沉浸感越强，项目吞吐量可能越低；外部 IP 越热门，园区在授权成本、内容审核和长期运营上的自主权可能越弱。这使分析没有停留在“热门 IP 带来客流”的单一结论上。

[推测] 受节目篇幅限制，讨论主要依赖公开报道和企业材料，缺少具体项目的成本、客单价、复购率及授权费用数据，因此尚难量化判断惊吓项目的实际盈利能力。

[推测] 本期适合关注主题乐园运营、文旅消费、IP 商业化及季节性营销的听众，也能为希望理解线下沉浸式体验如何平衡内容质量与接待效率的人提供清晰入门框架。
