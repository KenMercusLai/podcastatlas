# 从视频工具到创作 Agent：垂直 AI 的机会、壁垒与出海方法

## 概览

本期围绕通用 Agent 与垂直 Agent 的关系展开。小影科技创始人兼 CEO 韩晟认为，Agent 与传统工具的核心区别在于：用户只需说明目标，产品就要主动理解需求、作出专业判断并组织执行，最终交付可检查的结果。

讨论以视频创作为主要案例。面向大众用户和小商户时，需求往往模糊且评价标准主观，因此创作 Agent 不能只做“一句话生成”，而要通过首版作品与用户持续互动，以局部修改逐步逼近满意结果。衡量产品的关键，也应从生成成功率转向是否缩短“产生想法”到“获得满意作品”的距离。

节目还探讨了垂直 Agent 的生存空间、自研模型的必要性、线上线下结合的商业机会，以及拉美、中东等市场的本地化方法。最终建议是：创业团队应从自身长期积累出发，通过快速测试验证真实需求，在适合自己的细分市场建立优势。

## 分段落总结

[00:53] **通用 Agent 开始从回答问题走向交付结果**

[事实] 主持人以旧金山 Builder Demo Day 为背景，引出通用 Agent 与垂直 Agent 的关系，以及通用模型进入垂直领域后创业公司的机会。

[事实] 韩晟将新一代 Agent 的关键特征概括为自主性和结果交付能力，例如围绕“尽快上网”的目标寻找临时宽带方案、投诉服务商并推动问题解决。

[事实] 主持人在一周内筹备活动时，把网站搭建、信息表单和提交跟踪等工作交给 Agent，认为这类必要但增量有限的事务具有很高的 Agent 使用性价比。

[04:39] **视频 Agent 要承担理解、判断与执行**

[事实] 传统视频产品主要让用户操作工具，而 Agent 产品需要先理解用户想要的结果，再作出类似导演的专业判断，并组织拍摄、剪辑等环节完成交付。

[事实] 以汉堡店的周末套餐宣传视频为例，Agent 必须判断目标顾客、核心卖点和预期行动，再决定素材选择与内容结构。

[事实] 除了保证信息准确，产品还需判断广告是否吸引人、是否符合商户特点；发布和付费等关键动作则仍应由用户最终授权。

[事实] 用户省去的操作，会转化为产品需要增加的需求理解、专业判断和结果把关。

[06:43] **开发门槛下降后，识别需求成为核心能力**

[事实] 模型能力提升带来了三个变化：同质化应用增多、满足个性化需求的小产品增多、过去难以实现的垂直需求开始能够被小团队完成。

[事实] 应用商店对同质化的生图、生视频产品加强了管制，新开发者推出类似产品可能更难上架。

[事实] 小而个性化的产品未必拥有巨大市场，但仍可能形成规模有限、能够盈利的生意。

[事实] 当开发本身越来越容易时，发现真实需求和选择正确场景的重要性随之上升。

[08:47] **大众创作需求模糊，Agent 必须补足专业能力**

[事实] 小影过去的剪辑、模板和生成式视频产品本质上仍是工具，而 Agent 阶段更关注用户想借视频完成什么事情。

[事实] 大众用户和小商户的目标很多样，常常只会说“帮我做个视频”；相比之下，专业客户通常能给出更具体的要求。

[事实] 团队希望把行业专家的能力沉淀为 Agent 的 skill：一方面主动询问必要信息，另一方面依据行业经验直接提出方案。

[事实] Personal Agent 能够通过长期上下文了解用户；垂直 Agent 则可以利用这些背景信息，提高专业交付的上限。

[13:08] **通用 Agent 像管家，垂直 Agent 像专业团队**

[事实] 韩晟把通用 Agent 比作了解用户多年的“老管家”，把垂直 Agent 比作受邀完成具体任务的专业团队；前者可向后者传递用户背景和任务信息。

[事实] 对低频需求，用户可以只与通用 Agent 沟通，由其调用专业 Agent；对高频创作需求，用户可能绕过通用入口，直接与垂直 Agent 协作。

[事实] 多 Agent 体系同时涉及注意力管理：有些用户愿意和多个 Agent 分别沟通，有些用户只想面对一个统一入口。

[推测] 通用与垂直 Agent 更可能形成入口、上下文和专业执行之间的协作关系，而不只是相互替代。

[16:17] **自研模型取决于核心体验与成本优势**

[事实] 小影过去认为调用外部 API 已经足够，现在则从两个标准判断是否自研：能否掌握决定核心体验和交付结果的能力，以及能否用更少算力达到相同效果。

[事实] 在旅行视频中，素材选择、故事组织和成片评价都会直接影响核心体验，因此团队希望把长期积累的专业经验沉淀进产品和模型。

[事实] 团队称其在口播、唱歌等生活化场景中，通过数据建设、后训练、部署和业务接入，取得了接近主流闭源模型的效果，而算力成本约为其十分之一。

[事实] 团队针对宠物口播、音乐驱动画面等具体需求进行专门优化，并通过统一接口减少多个模型反复调用造成的算力浪费。

[20:08] **创作 Agent 不能止步于“一句话生成”**

[事实] 小影曾从“一句话生成完整视频”出发，但发现一句话只能描述任务，无法充分表达创作意图。

[事实] 同一个旅行视频可能强调朋友同行的氛围，也可能追求电影感；大众用户往往要先看到首版作品，才知道自己真正想要什么。

[事实] 产品随后改为先理解和预判用户意图，生成第一版，再根据反馈进行局部修改，而不是每次推倒重做。

[事实] 验证指标不再局限于生成成功率，还包括用户看到首版后是否愿意继续，以及后续修改次数。

[事实] 韩晟认为，个人创作 Agent 最重要的价值，是缩短用户从产生想法到获得满意作品之间的距离。

[22:50] **创业机会必须与团队长处匹配**

[事实] 小影选择大众创作领域，并优先考虑拉美、中东等已有大量用户积累的市场。

[事实] 团队曾尝试直接制作 AI 短剧并投放到红果、TikTok，后来发现业务核心并非制作效率，而是内容品味、剧本创作和美术效果把控。

[事实] 由于这些能力并非团队所长，小影选择果断放弃该方向。

[推测] AI 降低了进入新领域的技术门槛，却没有消除内容判断、行业经验和组织能力带来的适配差异。

[24:03] **垂直 Agent 的机会藏在复杂流程与线下运营中**

[事实] 主持人以二手物品出售为例：传统流程涉及拍照、发布、定价、沟通、预约和上门取货，步骤繁琐且存在爽约及安全问题。

[事实] 一个垂直 Agent 可以识别车库中的可售物品、生成商品信息、匹配价格、联系买家并安排上门搬运，但其商业闭环的重要部分仍是后端运营。

[事实] 韩晟认为，垂直 Agent 成功需要面对复杂的人机交互，并处理通用 Agent 难以独立完成的具体流程，尤其是线上线下相结合的任务。

[事实] 专业用户或许能用通用 Agent 把复杂事务拆成多个小任务，但一般用户通常缺乏这种任务拆解和连续推进能力。

[28:02] **出海本地化远不只是语言翻译**

[事实] 真正的本地化还包括文化、地方节日、当下流行趋势，以及当地用户偏好的情绪、音乐和视觉表达。

[事实] 巴西狂欢节强调音乐、舞蹈和庆祝氛围，印度排灯节涉及灯火、家庭团聚与祝福，不同节日对应的表达方式并不相同。

[事实] 小影在2014年巴西世界杯期间加入世界杯和桑巴元素后，相关视频素材获得了显著增长。

[事实] 模型可以提供翻译和文化知识，但难以仅凭静态知识判断今年流行什么、哪些表达自然、哪些元素已经过时。

[事实] 小影通过懂当地语言的团队成员连接本地创作者持续共创，再结合产品上线后的实际数据反馈修正判断。

[30:49] **用快速测试验证需求，而非先做完整产品**

[事实] 团队会先提出基本假设，即使产品尚未完成，也可以制作展示视频并通过网红传播来测试市场反应。

[事实] 除传播量外，评论中是否出现“怎么做”“我想要”等主动需求信号，也是判断是否命中的重要依据。

[事实] AI 编程让验证进一步加速，团队不仅能快速制作营销内容，也能迅速做出可用的产品原型。

[推测] 需求验证的成本下降后，创业团队可以更早淘汰错误方向，但也需要建立清晰指标，避免把短期传播误判为长期需求。

[32:26] **“人人都是生活导演”可能催生新市场**

[事实] 让普通人成为“生活导演”长期难以实现，因为创作者既要懂用户和内容，也要掌握剧本、拍摄、剪辑及商业判断。

[事实] 韩晟认为，Agent 有机会成为每个人的个性化导演，帮助大众用户从单纯表达情绪，走向以涨粉、流量或卖货为目标的内容创作。

[事实] 这一机会不只是扩大既有大众工具市场，而是帮助普通用户跨越到专业创作和商业化领域，形成过去不存在的新增市场。

[事实] 节目以编程产品作类比：一类产品提高现有工程师的效率，另一类产品则让从未写过代码的人也能做出自己的应用。

[36:09] **给 AI 出海创业者的两点建议**

[事实] 第一项建议是先认识自己的长处和既有积累，借助 AI 把优势继续放大。

[事实] 第二项建议是重视业务、用户和客户洞察，不要仅仅因为某个赛道热门就跟随进入。

[事实] 相比盯着竞争激烈的大市场，创业者可以寻找适合自己的细分市场，争取成为“小池塘里的大鱼”。

## 播客点评/总结

本期的突出价值在于，它没有把 Agent 简化为更自然的交互界面，而是从需求理解、专业决策、执行交付、责任边界和评价指标等方面，解释了 Agent 产品与传统工具的结构性差异。

讨论中的视频创作、二手交易和城市安家案例都较为具体，尤其是“通用 Agent 像管家、垂直 Agent 像专业团队”的比喻，清晰呈现了两类产品未来可能形成的协作模式。关于创作 Agent 需要通过首版作品逐步澄清意图的经验，也对消费级 AI 产品设计具有参考价值。

局限在于，部分产品名称和技术术语的转录不够清晰，个别段落存在明显缺字或识别错误；关于自研模型效果、算力成本和市场规模的判断主要来自嘉宾陈述，节目中没有给出更完整的测试口径或外部数据。

本期适合关注 AI Agent、消费级应用、视频创作、产品出海和早期创业的人群，也适合正在判断“通用模型如此强大，垂直产品还有什么价值”的产品经理与投资从业者。
