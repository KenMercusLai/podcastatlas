# DeepSeek 限制背后：国产大模型的算力困局与破局路径

## 概览

本期从 DeepSeek 收紧 C 端服务切入：长期不活跃对话被归档、单次输入长度受限、每日对话出现限额。嘉宾认为，这些变化不只是用户增长或商业收费问题，更反映出模型厂商必须在免费聊天服务、模型训练与前沿实验之间重新分配稀缺算力。

讨论进一步区分了普通聊天数据与 Agent 数据的价值。聊天服务主要构成推理成本，用户对话也未必适合直接训练；相比之下，编程 Agent 和行业 Agent 产生的任务轨迹更有助于提升模型能力。这也解释了模型厂商为何愿意补贴 Coding Plan、Agent SDK 和 Harness 生态。

节目的核心忧虑是国内外算力在芯片代际、数量和软件生态上的差距。国产模型厂商既要使用较旧或受限的英伟达芯片，又面临进口和海外算力收紧；国产卡虽然正在增长，但仍需解决性能、产能、训练适配以及缺少统一计算平台等问题。

最终给出的方向是：持续投入国产芯片与基础软件，同时把现有模型真正应用到各行各业。嘉宾强调，多数传统业务并不需要最强模型，现阶段提高 AI 的渗透率、寻找合适的第三方部署和推理服务，可能比单纯追逐模型榜单更能创造现实价值。

## 分段落总结

[00:31] **DeepSeek 收紧 C 端服务**

[事实] 节目提到 DeepSeek 对 C 端设置了三类限制：长期不活跃对话归档、单次输入压缩到约四万字、每日对话数量设限。

[事实] B 端 API 并未受到同等程度的限制，C 端用户也没有类似付费订阅的扩容选项。

[推测] 嘉宾认为，用户量和 API 调用量增长造成的算力压力，是此次限制的重要原因。

[推测] 不直接向 C 端收费，可能还与支付系统改造、客服和退款等服务成本有关。

[03:39] **DeepSeek 的目标并非经营聊天产品**

[事实] 嘉宾称 DeepSeek 更重视 AGI、模型研发和开源生态，并未把服务普通聊天用户作为唯一目标。

[事实] DeepSeek 模型已经开源，有大量第三方平台和云厂商可以提供部署或推理服务。

[事实] DeepSeek 的 B 端服务也较少提供传统企业软件常见的定制支持，客户主要通过统一平台使用 API。

[推测] 收紧免费聊天而不开放 C 端付费，说明其可能更愿意把有限算力留给训练、实验和生态建设。

[07:10] **普通聊天数据为何价值有限**

[事实] 模型训练数据需要经过清洗，并保持足够的多样性和泛化能力。

[事实] 嘉宾认为，大量用户聊天记录存在风格杂乱、目的不一和质量不稳定等问题，直接用于训练可能增加后续对齐成本。

[事实] 普通 Chat 服务主要提供用户体验，却持续消耗推理算力，未必能为模型训练带来相应回报。

[推测] 对以 AGI 为目标的模型厂商而言，闲聊和角色扮演数据的重要性正在下降，免费 Chat 因而更容易被视为成本负担。

[09:45] **Agent 数据成为模型厂商争夺的资源**

[事实] 节目将 Coding Agent、长期执行任务的 Agent 及行业垂直 Agent 所产生的数据视为更有价值的训练材料。

[事实] 这些数据能够呈现工具调用、任务规划、错误修复和长程工作等实际过程。

[事实] 部分厂商通过 Coding Plan、Agent SDK 等方式补贴用户使用；企业 API 则可能通过更高价格提供不将数据用于训练的承诺。

[推测] 厂商补贴 Agent 产品，不只是为了订阅收入，也是在获取更贴近真实工作的任务轨迹。

[12:47] **Harness 生态与行业 Agent**

[事实] 节目讨论了由基础 Harness 向行业 Harness 演进的可能：基础层提供通用工具和 Agent 框架，行业层承载特定领域的工作流程。

[事实] 模型厂商希望开发者使用自己的 Agent SDK 或 Harness，以扩大模型应用范围并积累新的任务数据。

[事实] 嘉宾认为，未来软件公司可能围绕不同行业开发专用 Harness，而模型公司则提供基础能力和生态支持。

[推测] DeepSeek 推动 Harness 和插件机制，可能是在为行业 Agent 生态及高价值数据入口进行长期布局。

[15:05] **国内外芯片代际与规模差距**

[事实] 节目梳理了 A100、H100、H800、H20、H200、B200、GB200 和 B300 等芯片代际，并称国内厂商主要仍在使用 H100、H800、H20 和少量 H200。

[事实] 嘉宾称，海外头部模型公司使用了大量更新一代的 B200、GB200 或 B300，同时拥有规模更大的芯片集群。

[事实] 国内头部互联网公司虽然拥有数十万乃至约百万张 GPU，但芯片型号更杂、整体代际较旧，其他模型厂商往往只有万卡级集群。

[推测] 国产模型在算力条件明显受限的情况下仍能接近海外领先模型，体现了工程优化和资源利用能力。

[20:09] **模型研发的三项核心资源**

[事实] 嘉宾把模型研发的关键资源概括为数据、人才和算力。

[事实] 数据和人才固然重要，但算法人员提出实验方案后，还需要足够多、能够被有效调度的 GPU 才能验证。

[事实] 万卡集群的搭建、调度和故障处理需要专业 AI Infra 团队，这类经验本身也十分稀缺。

[推测] 算力不足不仅限制实验次数，也可能削弱国内机构对顶尖研究人才的吸引力。

[23:16] **算力竞争改变人才与科研路径**

[事实] 节目提到，现代 AI 研究需要的算力已经超出许多高校能够提供的范围。

[事实] 对部分学生而言，进入大型科技公司实习可能比留在学校更容易接触大规模算力和真实工程环境。

[推测] 算力向大公司集中，可能进一步改变 AI 人才培养方式，并扩大高校与产业实验条件之间的差距。

[23:56] **国产卡的出货、适配与工程优化**

[事实] 节目引用的数据称，2025 年中国 AI 芯片出货总量约四百万张，其中英伟达约占 55%，华为约有八十万张，其余由百度、阿里、寒武纪及多家国产 GPU 企业分享。

[事实] 嘉宾强调，出货量不能直接代表有效算力，芯片性能、集群效率、软件适配和实际利用率同样重要。

[事实] DeepSeek 等团队已经针对国产卡进行架构优化，并发表了相关技术成果。

[推测] 在高端英伟达芯片有限的情况下，国产卡可能优先承担推理服务，以便把稀缺的高性能芯片留给训练和实验。

[27:47] **国产卡用于训练的现实障碍**

[事实] 华为等国产芯片使用自己的软硬件方案，而大量既有模型训练工具链建立在 CUDA 生态之上。

[事实] 推理的适配范围相对有限，训练则涉及大量实验、损失曲线分析、算子实现和基础设施排障，迁移难度更高。

[事实] 通过增加芯片数量可以弥补部分单卡性能差距，但也会提高集群规模、调度、能耗和通信方面的要求。

[推测] 国产卡短期更容易在推理端扩大使用，要全面承担前沿模型训练仍需持续完善软件生态。

[30:50] **去 CUDA 化与 AI 辅助迁移**

[事实] 国内外厂商都在尝试减少对 CUDA 的依赖，包括自研芯片、兼容层和新的训练软件栈。

[事实] 节目提到，AI 可以帮助把已有 CUDA 代码迁移到其他芯片平台，从而明显缩短部分适配工作的周期。

[事实] 嘉宾区分了有限范围的代码迁移与未知问题探索：前者适合 AI 自动化，后者仍需要深厚的工程经验。

[推测] AI 能加速国产平台追赶成熟生态，但无法自动解决前沿训练中尚未出现过的新问题。

[33:39] **海外算力渠道继续收紧**

[事实] 节目讨论了通过海外数据中心使用先进芯片训练国产模型的做法，以及相关合规限制正在加强。

[事实] 嘉宾称，部分东南亚数据中心原本服务于中国企业，限制加强后可能面临需求下降。

[事实] 对芯片、许可证和实际用户的识别仍可能引发持续的技术与合规对抗。

[推测] 如果进口芯片和海外训练渠道同时收紧，国内模型厂商可能面临一到两年的研发节奏压力。

[36:36] **Agent 推高 Token 与算力需求**

[事实] Agent 会持续规划、调用工具并长时间工作，其 Token 消耗远高于普通对话。

[事实] 随着 Agent 工作时间和任务范围扩大，模型服务对推理芯片的需求也会同步增加。

[推测] 即使失去中国市场，海外头部厂商仍可能依靠自身训练和 Agent 业务消化大量新芯片。

[推测] 如果海外厂商率先进入更高能力阶段，国内外模型差距可能因算力复利而进一步扩大。

[39:11] **国产芯片是主要破局方向**

[事实] 节目认为，不能把希望寄托在外部限制自行放松，长期仍需发展国产芯片和配套生态。

[事实] 嘉宾提到华为 910C 已可承担部分推理任务，即使性能不及最新英伟达芯片，也能释放更高端芯片用于其他工作。

[事实] Mac Studio 适合个人本地运行大模型，但在推理效率和大规模服务方面不如专业 GPU。

[推测] 在英伟达芯片持续稀缺的情况下，国产卡可能逐渐成为国内推理市场的主力硬件。

[42:15] **国产计算生态仍缺少统一平台**

[事实] 当前模型厂商通常分别与华为、壁仞、天数智芯等芯片厂商开展适配合作。

[事实] 各家拥有不同的软件栈和商业利益，尚未形成类似 CUDA 的统一计算平台。

[事实] 阿里等大厂已经开始使用自研 GPU 参与模型训练，国产算力问题正在进入企业核心决策层。

[推测] 更现实的顺序可能是先让各类国产卡可用，再推动形成获得多方认同的兼容框架。

[45:48] **产业优势与核心短板**

[事实] 嘉宾认为，国内在资金、人才、数据、电力和基础设施建设方面并非没有优势，最突出的问题仍是先进芯片。

[事实] 乌兰察布等地区具备电力、气候和快速建设数据中心的条件，标准化机房可以迅速部署。

[事实] 高端芯片制造涉及全球产业链，国产光刻设备和先进制程产能仍是关键制约。

[推测] 外部限制短期会造成困难，长期也可能迫使产业加速自研芯片、训练平台和完整供应链建设。

[49:02] **不应把算力困局视为终局**

[事实] 节目通过国际局势变化的历史案例说明，技术竞争环境并非静止不变。

[事实] 嘉宾认为，海外模型虽然更强，但许多实际工作并不需要最前沿的模型能力。

[推测] 国内在追赶基础模型的同时，如果能把现有模型广泛用于产业升级，创造的经济价值可能不低于单纯提升模型榜单成绩。

[51:00] **开源模型与低成本推理服务**

[事实] 国外 API 成本较高，而开源模型可以由第三方优化部署，从而显著降低使用价格。

[事实] 节目举例称，一些 Coding Agent 服务以较低订阅价格提供额度更高的 DeepSeek 或其他开源模型调用。

[事实] 对管理系统和传统业务逻辑等常见开发任务，DeepSeek 等现有模型通常已经够用；前沿 Agent 系统才更依赖最高能力模型。

[推测] 企业选择模型时，应按任务难度、成本和数据要求匹配方案，而不是默认使用最昂贵的模型。

[52:51] **应用落地比盲目追强更重要**

[事实] 嘉宾认为，中国市场更需要解决 AI 渗透率和使用方法问题，把模型真正用于各行各业。

[事实] 国内企业过去在互联网应用和商业模式创新方面积累了经验，可以继续发挥应用层优势。

[事实] 用户可以选择阿里、腾讯等平台提供的 DeepSeek 服务，也可以寻找第三方部署商、超算中心或自行部署。

[推测] 在基础算力受限的阶段，通过应用创新、资源调度和低成本部署扩大 AI 使用，可能成为更现实的竞争路径。

[55:13] **生态普及、芯片产能与光刻机瓶颈**

[事实] 节目指出，国产芯片生态缺少类似 Google Colab 的低门槛试用环境，不利于开发者学习和主动适配。

[事实] 国产卡数量有限时，厂商会优先服务大型客户，难以向普通开发者免费开放算力。

[事实] 嘉宾把先进芯片制造能力和光刻设备视为最终需要突破的关键环节。

[推测] 如果产能和制造设备取得突破，中国在电力、土地和基础设施方面的优势才可能转化为大规模 AI 算力。

## 播客点评/总结

本期的价值在于，它没有停留在“DeepSeek 为什么限额”的产品层讨论，而是把免费聊天、训练数据、Agent 生态、GPU 供应和国产替代串成了一条完整链路。普通聊天与 Agent 数据价值的区分尤其清晰，有助于理解模型厂商为何把资源投向 Coding Agent、SDK 和 Harness。

节目也提供了较丰富的产业观察，包括芯片代际、集群规模、国产卡适配和推理部署等。不过，部分芯片数量、市场份额及厂商内部策略来自嘉宾转述或公开文章，转录中没有给出可核验来源；相关数字更适合作为趋势参考，而非精确结论。

[推测] 这期节目适合关注大模型产业、AI Infra、国产 GPU、Agent 产品以及企业 AI 落地的听众。它最有启发性的结论不是简单唱多或唱空国产算力，而是承认硬件差距，同时强调开源生态、工程优化和应用渗透仍然存在现实机会。
