# 从开源创业到企业级 Agent：持续学习如何重塑组织与软件

## 概览

本期播客对话 AFK 创始人何嘉琛，回顾其参与创办 AFFiNE、与尤雨溪合作建设相关基础设施公司，以及转向企业级 Agent 创业的经历。他认为，AFFiNE 早期抓住了多模态工作空间的需求，但随着 AI 从编辑器内的助手演变为无处不在的自主 Agent，固定的软件界面逐渐成为限制，促使团队重新选择方向。

何嘉琛将 AFK 定位为具有持续学习能力的企业级 Agent：它不仅替单个员工执行任务，还能贯通员工、软件和业务流程，在组织范围内积累经验、复用结果，并让管理者看到公司的真实运行状态。相比彼此隔离的 Personal Agent，这种共享而又千人千面的 Agent 更强调组织协同、知识沉淀和成本透明。

讨论进一步延伸到 Agent 产品形态、工作流工具的衰退、小模型蒸馏、软件的动态生成，以及 AI 对企业组织结构的改造。何嘉琛判断，模型能力提升正在削弱固定工作流、传统 SaaS 和通用软件的价值，而未来的竞争重点将转向端到端交付、持续学习，以及谁能更有效地将 AI 智能转化为企业收益。

## 分段落总结

[00:19] **何嘉琛的创业经历与 AFFiNE 的得失**

[事实] 何嘉琛介绍自己曾学习深度学习与天体物理，后来退学创业，参与创办过开源 AI 文档与知识库产品 AFFiNE、与尤雨溪合作的基础设施公司，以及面向企业的 AFK。

[事实] 他认为 AFFiNE 早期做对的事情，是在合适时间提出多模态工作空间，让文档、画布、数据处理及 AI 检索与生成进入统一环境。

[事实] AFFiNE 后期面临的问题是，随着 Agent 自主性增强，固定编辑工具和编辑环境逐渐变成约束，产品形态从画布式软件转向跨环境、无处不在的 Agent。

[事实] 他将创业带来的最大回报概括为成长：创业者需要依次理解技术、产品、市场、人际协作与商业变现。

[05:45] **AFK：具备持续学习能力的企业级 Agent**

[事实] AFK 被描述为一个主打 Continuous Learning 的企业级 Agentic System，不依赖单一界面，可以通过聊天、协作软件、电话等渠道主动联系用户并接管工具。

[事实] 何嘉琛认为，只给每位员工配置独立 Personal Agent，可能把原本来自员工的信号和噪声同时放大，却无法形成组织层面的学习与协同。

[事实] AFK 的方案是让全公司使用同一个高并发 Agent，同时为每个人保留独立记忆和运行环境，并在所有员工、软件及业务界面上持续学习。

[事实] 他称这种持续学习可以让企业追踪代码、API、会议与客户沟通等业务细节，并通过参数化模型沉淀企业自身的知识产权。

[08:20] **Agent 产品形态趋于稳定**

[事实] 何嘉琛回顾 Agent 过去两年的产品变化，包括 GUI、TUI、CLI、Artifact 和 Personal Agent 等不同形态。

[事实] 他认为 Proactive Agent 已不再依赖特定 UI 或 UX，而是像人一样可以通过多种终端和渠道被找到，因此产品形态正在趋于固化。

[事实] 他将 AFK 的目标概括为 Fully Autonomous Agent：始终在线、跨环境运行，并能主动推进任务。

[事实] 在他的描述中，Agent 的核心能力不是拥有某个应用界面，而是能够同时调度浏览器、计算机、CLI、MCP 与多个操作系统级环境中的工具。

[13:01] **面向个人与面向企业的 Agent 有何不同**

[事实] 何嘉琛认为，消费级 Personal Agent 是平台型机会，但 AI 产品中的用户规模未必能形成传统互联网式的数据与网络效应，模型本身的能力提升往往更具决定性。

[事实] 在企业场景中，员工工作存在大量重复，Agent 之间以及人与 Agent 之间的共同学习可以减少重复劳动和信息损耗。

[事实] 他判断消费级 Agent 的竞争会延伸到供应链、交易入口和平台关系，创业公司不仅要补贴商品和 Token，还可能遭到现有服务平台封禁。

[事实] 企业级 Agent 的价值更直接，可以通过降低成本、增加产出、追踪 Token 投入与业务结果来更快实现商业变现。

[推测] AFK 选择企业市场，不只是技术路线选择，也是小团队为了避开消费平台战争、缩短价值验证周期而采取的商业策略。

[16:37] **Personal Agent 对既有平台入口的挑战**

[事实] 对话双方认为，如果 Agent 成为用户的统一入口，出行、外卖和电商平台可能退居后台供应商，其品牌与用户入口价值会受到冲击。

[事实] 现有大型平台不会甘愿从入口变成供应商，也会进入 Personal Agent 市场，因此新创业公司与成熟平台之间可能出现激烈竞争。

[事实] 何嘉琛指出，重构消费供应链需要很大的业务体量，这也是消费级 Agent 战争难度较高的原因。

[推测] 即使最终仍由现有平台占据主要市场，竞争过程也可能促使平台增加补贴并改善用户体验。

[18:30] **为什么企业客户愿意开放更多权限**

[事实] 何嘉琛认为，Personal Agent 需要大量上下文和系统权限，在消费场景中很难划定用户信息边界，也容易引起隐私担忧。

[事实] 企业负责人则可能主动允许 Agent 接入业务、财务、产品研发和 Token 使用数据，因为端到端自动化能够直接减少人力成本并提高管理透明度。

[事实] 他表示，只要向管理层展示 AI 的实际能力，大客户往往比供应商更有动力改造自身系统，让 AI 获得更多上下文并执行更多操作。

[事实] 因此，相比消费市场中 Agent 与用户之间的权限博弈，企业市场可能拥有更自然的早期采用条件。

[21:12] **AI Coding 之外的组织工作流重构**

[事实] 何嘉琛指出，AI Coding 提高了工程师的生产力，但产品经理、设计师与工程师之间仍存在角色和信息壁垒，单纯增加编程工具无法解决整个组织的问题。

[事实] 他以自己的团队为例，设计师借助 Artifact 直接查看和修改真实代码，交付物可以是上线功能、UI、宣传视频或用户引导，而不再只是设计稿。

[事实] 他认为产品经理可能转变为定义功能逻辑的工程师，设计师则成为面向界面交付的工程师，各角色共同面对以代码为底层的统一系统。

[事实] 他警告，为每个人单独配置 AI 可能制造更多“AI 垃圾”：例如产品经理生成数百页 PRD，工程师再让 AI 将其压缩成一句需求，反而跳过了真正的业务沟通。

[事实] 他认为面向统一代码库、实时构建和实时预览的协作方式，可能成为 AI 时代的标准开发范式。

[25:13] **从固定工作流转向模型内能力**

[事实] 何嘉琛认为，AI 从辅助打字发展到辅助决策后，人类使用 Agent 的抽象层级随之提高，组织也应从各角色使用不同工具转向共同面向同一套底层系统。

[事实] 他判断，随着模型能力增强，工作流、Skill、System Prompt 等外挂组件的生命周期会缩短，因为模型会直接吸收原本由这些组件补足的能力。

[事实] 他表示，过去的开发平台主要是在给模型“补短板”，而模型能力达到一定水平后，过多外挂甚至可能产生副作用。

[事实] 对于确定性和复用问题，他认为解决方式正在从模型外的固定工作流，转向更强的指令遵循、缓存、记忆及模型蒸馏。

[事实] 他称高频工具调用与稳定结果可以通过 KV Cache、Prompt Cache 或小模型蒸馏被保留，比僵化工作流更灵活。

[31:01] **共享 Agent 如何形成企业级持续学习**

[事实] 何嘉琛将 AFK 与独立 Personal Agent 的主要差异归结为组织范围内的缓存命中、经验共享和持续学习。

[事实] 如果一家公司的一百名员工分别使用独立 Agent，同一份代码可能被重复读取一百次；共享 Agent 则可以复用同事此前完成任务时积累的结果。

[事实] AFK 的 Agent 面向全公司运行，但具有高并发和千人千面的能力，既保留个体差异，也能汇总组织经验。

[事实] 共享 Agent 可以观察哪些员工的工作方式更有效，帮助其他成员复用这些做法，并向管理者提供统一的业务进展和流程改进建议。

[事实] 何嘉琛认为，这使企业能够把分散的 AI 使用行为连接成学习、反馈与改进的闭环。

[33:25] **创业公司训练模型的机会为何重新出现**

[事实] 何嘉琛曾参与国内一个万亿参数以上多模态 Agentic Model 的训练，并因此一度不看好创业公司训练大模型，因为这需要大量算力、人才和科学的数据合成流程。

[事实] 他认为，前沿实验室在算力、人才密度和工程体系上明显占优，创业公司很难依靠训练通用大模型与其竞争。

[事实] 到 2026 年，训练成本下降且模型架构变化，使创业公司不再需要追求通用基准第一，而可以训练小模型，为强模型提供记忆、低成本复现和快速响应能力。

[事实] 他将这种机会描述为把大模型经过长推理得到的结果，蒸馏成无需复杂推理即可快速输出的 System 1 模型。

[推测] 这一模式把创业公司的模型竞争从“训练更聪明的通用模型”转变为“更有效地吸收客户场景中的经验”。

[37:16] **AFK 的两类小模型**

[事实] AFK 训练的第一类模型是 Task Routing Model，用于记录先进模型完成任务时的工具调用轨迹、结果和用户偏好，再以更低成本复现任务。

[事实] 当先进模型存在多条可行路径时，小模型会学习用户偏好的执行路线；何嘉琛把这种能力称为模型的“肌肉记忆”。

[事实] 他将先进大模型比作大脑皮层，将这类小模型比作脑干、脊髓或植物神经：任务初次执行需要复杂推理，多次执行后则可以转化为快速、低成本的条件反射。

[事实] 第二类是约 20B 至 40B 参数的企业内部 Work Model，重点服务于操作系统、动态软件及企业特定任务，并减少通用闭源模型在安全限制方面的约束。

[40:02] **动态软件、模型普惠与 Agent 的爆发点**

[事实] 何嘉琛判断，AI 会端到端改变操作系统、网络和应用层逻辑，并为不同任务和设备动态生成高度定制的软件。

[事实] 他认为，只要 AI 能理解软件功能并获得 API 规范，就可能逆向或重写功能相同的软件，因此传统软件本身的壁垒正在减弱，更多功能会转移到模型智能中。

[事实] AFK 近期计划继续通过最好的模型和算法帮助企业提高价值创造效率，并从新增价值中获取利润。

[事实] 他预计开源模型会加速追赶，未来两三年 AGI 级模型的供给可能更加充裕，届时企业端和消费端的软件及商业规则将面临更激烈的重构。

[事实] 双方认为 Agent 过去发展较慢，是因为只有端到端完成任务才能创造价值；近期关键能力逐渐补齐，Agent 正在跨越商业化临界点。

[推测] 如果通用模型继续覆盖视频、语音、机器人控制等原本相对独立的能力，单点 AI 产品也可能受到通用 Agent 系统的挑战。

[44:59] **创业团队、人才成长与长期回报**

[事实] 主持人提到，AFFiNE 过往团队成员后来成为创业者、技术负责人，或进入大型公司担任重要研发岗位。

[事实] 何嘉琛认为，把真正想做事的聪明人聚集起来，并提供比大公司更少限制的环境，可以显著加快共同成长。

[事实] 他承认创业成功受时机和运气影响，并非每家公司都能上市，但个人能力、市场价值和下一次成功概率的提高也是重要回报。

[事实] 他总结自己的用人原则，是与聪明、善良、能够坚持且勇敢的人一起创业，尝试足够有挑战和意义的目标。

[事实] 他以 AFFiNE 前成员创办新项目、获得融资、成为 Cloudflare Principal Engineer，以及相关公司被收购等经历，说明创业团队的价值也体现在人才的后续发展上。

## 播客点评/总结

本期最有价值之处，是没有把企业级 Agent 简化为“给员工增加一个聊天机器人”，而是把问题放在组织协同、信息损耗、权限接入、经验复用和商业回报的完整链条中讨论。尤其是“一百名员工加一百个隔离 Agent 可能放大噪声”的例子，清楚说明了个人效率与组织效率并不等价。

关于共享 Agent、持续学习和小模型“肌肉记忆”的讨论，为企业如何沉淀自身 AI 能力提供了较具体的框架：强模型负责复杂推理，小模型吸收稳定任务，组织级系统负责跨员工复用经验。它适合关注企业 AI、Agent 架构、组织改造和 AI 创业机会的产品经理、工程师、管理者与投资人。

本期的局限是，许多判断建立在嘉宾对模型能力、软件消亡和市场演化的强烈预期上，实际客户效果、成本数据、安全机制及部署难度没有得到详细展开。[推测] 因此，这些内容更适合作为前沿创业者的趋势判断和产品假设，而不应直接视为已经得到广泛验证的行业结论。
