# 全球大模型季报第9集：和广密聊，Coding是AGI第二幕、硅谷御三家真相、模型正成为新一代OS

## 概览

本期围绕 2026 年第一季度大模型行业的突变展开：节目认为，Coding 和 Agentic 能力把 AI 从“聊天机器人第一幕”推向“能干活的第二幕”，并正在成为 AGI 进程中的核心加速器。

讨论主线包括硅谷一线体感、Coding 为什么成为主线、Anthropic、OpenAI、Google 的战略组织差异，以及 Meta、XAI、国内模型公司的追赶路径。嘉宾反复强调，模型公司竞争不再只是 DAU、C 端流量或单个 benchmark，而是高价值任务、token usage、数据组织能力和持续交付 SOTA 模型的能力。

节目后半部分把模型类比为新一代操作系统：未来模型可能承载生活、工作、科研和 Agent 生态。同时，嘉宾也担心白领工作、初级岗位、SaaS 和服务业会受到冲击，人类知识和智力的市场价值可能被压缩。

## 分段落总结

[01:59] **本集议题与第一季度判断**

[事实] 主持人介绍，本期是“全球大模型季报”第九集，延续 2023 到 2026 年对大模型技术进步和趋势的记录。

[事实] 本期计划讨论硅谷体感、Coding 的新理解、硅谷“御三家”模型公司的战略组织文化、模型终极形态、失业通缩和投资。

[事实] 嘉宾认为过去一个季度最关键的转折，是 Anthropic 的 OPOS 4.5 到 4.6 带来的跨越，使 AI 从 Chat 问答进入 Agent 做高价值任务的阶段。

[推测] 节目把 2026 年第一季度视为 AI 从展示能力走向实际生产力的关键窗口。

[06:06] **硅谷一线体感：研究员开始少写代码**

[事实] 嘉宾说，前沿实验室的 AI researcher 和强程序员已经“基本上不写代码了”，工作方式变成 AI 写、人来审。

[事实] 他提到 Cloud Code 和 Codex 在很多任务上已接近公司 CTO 或首席架构师水平，一个 feature 可能两三次迭代就跑通。

[事实] 研发和研究的周期被压缩：过去一个想法跑通代码可能要两三周，现在可能一两天或两三天。

[推测] Coding Agent 正在放大顶尖研究者和工程师的生产力，并可能加速 AI 研究本身。

[09:19] **收入指标从 DAU 转向 Token Usage**

[事实] 嘉宾称 Anthropic 的 ARR 已超过 OpenAI，并认为少量高价值用户贡献的收入可能超过大量普通订阅用户。

[事实] 他认为当下更重要的指标不只是 DAU 或广告规模，而是超级开发者和目标用户的 token usage。

[推测] 如果 Coding 和 Agentic 需求持续增长，OpenAI 和 Anthropic 的收入曲线可能比 ChatGPT 当年的增长更陡。

[11:37] **Coding 为什么成为 AGI 主线**

[事实] 嘉宾提出“自然语言是对世界的描述，Code 是对 Solution 的描述”，并认为 Code 可以表达数字世界的绝大多数任务。

[事实] 他认为领先模型公司如果不重视 Coding，可能掉出第一梯队；只给自己用的 Coding Model 也不够，因为自家任务数据分布不够全。

[事实] 他把 Coding 类比为 GPU，认为没有领先 Coding Model 就像没有领先 GPU，会导致研发落后。

[推测] Coding 被视为 AGI 的加速器，不只是垂直应用或单一产品。

[16:09] **做好 Coding 的难点：组织、文化和数据**

[事实] 嘉宾说，多个 AI lab 近一到三个月才把 Coding 放到最高优先级，但真正做好并不容易。

[事实] 他认为最重要的两件事是组织文化和数据；Coding/Agentic 的数据包含任务、环境和评估，比 chatbot 文本数据复杂很多。

[事实] 嘉宾强调 Coding 有大量数据脏活苦活，而许多聪明研究员更想做 0 到 1 的突破。

[推测] Coding 能否做成，可能更多取决于战略聚焦和组织动员，而不是单点技术 know-how。

[20:51] **C 端窗口与高价值任务路线**

[事实] 嘉宾把 AGI 路线分成两条：一条追求 C 端流量，如 ChatGPT、Gemini、豆包；另一条追求高价值任务，以 Anthropic 为代表。

[事实] 他认为 ChatGPT 和 Google 忙于争夺 C 端窗口，因而错过了 Coding 窗口；Anthropic 可能也是因为 C 端机会较弱，被迫选择 Coding。

[推测] C 端、Chat、Agent 和 Code 未来大概率会融合，但塔尖用户的 token usage 可能比普通 DAU 更重要。

[22:18] **Anthropic 的战略胜利**

[事实] 嘉宾认为 Anthropic 在 2024 年夏天通过 Sonnet 3.5 获得 Coding 正反馈，此后专注 Coding，并放弃或弱化 C 端、多模态等方向。

[事实] 他认为 Anthropic 是 top-down 战略，创始人懂技术，团队稳定，重视数据，且有强 AGI mission。

[事实] 嘉宾称 Anthropic 不太神话某个环节，更像一个工业化体系，把模型、数据、工程和产品每个环节都做好。

[推测] Anthropic 的领先不是单纯模型能力领先，而是战略、组织、文化和产品专注共同作用的结果。

[26:16] **Anthropic 的产品感和护城河**

[事实] 嘉宾认为 Anthropic 的产品文化和 AI Native sense 很强，能把模型能力高效转化为产品体验。

[事实] 他提到 Cloud Code 没有选择 IDE 形态，而是选择终端形态，以承接模型能力增长带来的红利。

[事实] 他认为 Anthropic 的护城河取决于 Coding 难度系数，同时算力可能成为其实现高 ARR 的瓶颈。

[推测] Anthropic 面向高价格带塔尖用户的定位，可能带来更高客单价和更好的 margin，但也会面临 OpenAI、Google 追赶。

[31:11] **OpenAI：C 端领先后的战略转向**

[事实] 嘉宾认为 OpenAI 已把 Coding 放到最高优先级，GPT5.4 的 Coding 能力社区反馈很好，但 Agentic 能力仍弱一些。

[事实] 他提到 ChatGPT 在 C 端有九亿多周活和五六千万付费用户，但认为 Coding 可能比 Chatbot 大 10 到 100 倍。

[事实] 嘉宾推测 OpenAI 大约两三个月前才真正意识到 Coding 的重要性，此前忙于与 Google Gemini 争夺 C 端流量。

[推测] OpenAI 的优势在人才密度、资源和探索文化，短期被低估，但需要补上 Coding 与 Agentic 的执行短板。

[42:14] **OpenAI 的问题与可能反击**

[事实] 嘉宾批评 OpenAI 不够聚焦，Sam 作为 VC 出身容易“什么都想要”，多模态、Sora 等支线占用了资源。

[事实] 他认为 OpenAI 文化更重视 0 到 1 的突破，不够重视数据清理、产品运营等 1 到 100 的脏活累活。

[事实] 嘉宾判断 OpenAI 的 Coding 和 Agentic 能力大概率能追上 Anthropic，并认为即将发布的新模型 Spard 可能是真正意义上的 GPT-5。

[推测] OpenAI 如果把 Chat、Code、Agent 做成 all in one 平台，仍可能重新取得阶段性领先。

[47:16] **Google Gemini：资源最稳但短期误判 Coding**

[事实] 嘉宾认为 Gemini 3.0 当时被高估，benchmark 很高但实际体验和产品能力不足，C 端增长也不够持续。

[事实] 他认为 Google 过去更重视 C 端和多模态，忽视了 Coding，最近才把 Coding 提到公司最高优先级，已经晚了三四个月。

[事实] 嘉宾认为 Google 长期最稳，因为有算力、现金流、TPU、Workspace、操作系统和体系化运营能力。

[推测] Google 可能是“最领先的追随者”，短期需要调整，但长期掉队概率低。

[52:06] **能否跳过 Coding 直奔下一幕**

[事实] 嘉宾认为没必要跳过 Coding，因为 Coding 仍是基础能力；从 Chatbot 到 Coding Agent，再到 automated AI researcher，是当前更清晰的三幕主线。

[事实] 他总结硅谷御三家过去三年交替领先：OpenAI、Gemini、Anthropic 各有窗口，像“各领风骚 100 天”。

[推测] 模型公司未来可能成为科技投资主线，做不好模型或 AI 产品的科技公司会面临淘汰压力。

[54:17] **Meta、Manus 与 XAI 的挑战者位置**

[事实] 嘉宾认为 Meta TBD 已取代 XAI 成为硅谷四号种子选手，人才密度高，九到十个月做出了还不错的模型。

[事实] 他认为 Meta 产品战略尚不清楚，可能更适合做个人助理、个人朋友或低门槛 Agent 产品；中国团队在产品创新上强于 Meta。

[事实] 嘉宾认为 Manus 是 Harness 的早期代表，收入增长很快，被 Meta 收购后如何整合仍不清楚。

[事实] 他判断 XAI 短期有点掉队，核心团队离开、战略摇摆、过度依赖大规模预训练和算力，是主要问题。

[61:55] **Harness Engineering 的意义**

[事实] 嘉宾认为应把 AI Agent 当作一等公民，为它配置工作环境、电脑、信用卡等类似人类知识工作者的条件。

[事实] 他把 Harness 类比为 Agent 的管理学和组织环境，好的 Harness 能提升模型执行任务的下限。

[事实] Harness 让普通模型也能做高价值任务，并在顶级模型供给不足时让非 SOTA 或开源模型被用起来。

[推测] 工具公司未来可能从服务人类转向服务 Agent，核心指标也会从 DAU 转向 token usage、token value 和 margin。

[63:50] **国内模型公司与模型 OS**

[事实] 嘉宾认为国内 Kimi、MiniMax、智谱都在追求 Anthropic 的高价值任务路线，这在过去三到六个月逐渐成为共识。

[事实] 他认为豆包在 C 端做得最好，但 Coding 和 Agent 也不能输。

[事实] 嘉宾提出“模型可能就是新一代操作系统”，未来生活、工作、科研都可能由模型支撑，Agent 是其应用扩展方式。

[推测] 模型公司竞争进入工业化时代，胜负不再由单一人才或单一方法决定，而是组织、资源、数据、产品和战略的综合竞争。

[66:53] **Agent 路线图和社会冲击**

[事实] 嘉宾认为路线图更清晰、时间表更快，可能今年年底或明年初就有公司宣布实现 AGI。

[事实] 他认为前沿实验室看到的信息没有充分传递到社会，社会准备不足。

[事实] 嘉宾说，人类知识和智力正在变廉价，被压缩为模型能力、计算资源和 token。

[推测] AI 可能带来通缩、SaaS 和顾问服务需求下降、初级岗位减少，以及白领失业窗口。

[71:40] **人未来做什么**

[事实] 嘉宾说本期播客的大部分提纲已经由 Cloud Code 根据他的 notes 和过往框架辅助完成。

[事实] 他认为人未来仍可以去创造，尤其是有创造力、审美和 taste 的人，可能借助 AI 实现过去无法实现的想法。

[事实] 对听众的建议是：AI 取代的是不拥抱 AI 的人，积极拥抱 AI 的人可能成为受益者。

[推测] 个人或小团队的创造力会被新技术设施放大，一人公司和小团队产品可能更常见。

[72:51] **投资主线：持续做好 SOTA Model**

[事实] 嘉宾认为未来最好的三五家模型公司可能成为全球 GDP 的操作系统，每家都有极高价值空间。

[事实] 他认为 AGI portfolio 的关键，是投资能持续做好 SOTA Model 的公司，自己八九成精力都在模型主线上。

[事实] 他认为新模型公司要出现很难，因为需要持续三到五年每年数百亿美金投入、管理层认知和魄力、世界级 AI 科学家、GPU 和产品 go to market。

[推测] 模型基金或集中押注头部模型公司的策略，来自嘉宾对模型平台化和 GDP 自动化的强 belief。

[76:48] **AI 产品、机器人与应用公司机会**

[事实] 嘉宾列举头部 AI 产品收入：OpenAI、Anthropic、Cursor、Perplexity、11Labs、Suno、Manus、Lovable、GenSpark，以及医疗方向的 OpenEvidence、Abridge。

[事实] 他认为机器人和 AI for Science 可能是大模型之后的下一个大平台，机器人未来 6 到 18 个月可能出现质变。

[事实] 他提到机器人领域开始重视硬件、数据采集、第一视角数据、遥操作和手套数据，硅谷公司也开始在深圳招人。

[推测] AI 应用公司机会仍存在，但关键是能否跑通 token ROI，例如花 100 美金 token 能赚回 110 美金。

[80:56] **个人体感与结尾**

[事实] 嘉宾说自己过去一个季度从 ChatGPT 转向 Cloud Code 的中度用户，生产力确实提升，但还没达到塔尖开发者那种 token 消耗量。

[事实] 他表示自己很担心跟不上 AI 的进步，因为每天、每周变化都很快，学习压力很大。

[事实] 节目最后介绍《商业访谈录》和“语言集世界”公众号。

## 播客点评/总结

这期的价值在于，它不是单纯罗列模型发布或产品新闻，而是用 Coding 作为主线，把模型能力、组织战略、收入结构、产品形态和社会影响串在一起。尤其是“语言即世界，代码即方案”“Coding 像 GPU 一样是 AGI 加速器”这类表述，有助于理解为什么 Coding 不只是程序员工具。

亮点是嘉宾提供了大量一线体感和公司比较：Anthropic 的专注、OpenAI 的探索文化和不聚焦、Google 的资源与体系、Meta 的挑战者位置、XAI 的战略摇摆，都被放在同一个框架下分析。节目也反复提醒，模型竞争进入工业化阶段，数据、组织、算力和产品闭环的重要性正在上升。

局限是大量判断来自嘉宾个人观察、朋友反馈和趋势推演，部分数据和未来预测在转录稿中没有外部来源支撑。因此，关于 ARR、市场份额、AGI 时间表、失业比例和公司胜负的内容，更适合作为高密度观点参考，而不是确定事实。

[推测] 这期更适合关注 AI 投资、模型公司战略、开发者工具、Agent 产品和科技行业组织变化的听众；如果只想了解普通用户如何使用 AI，节目会偏宏观和产业判断。
